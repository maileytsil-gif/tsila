17. Troubleshooting
If you are experiencing problems related to your Native Instruments product that the supplied
documentation does not cover, there are several ways of getting help.
Before getting help please make sure you have downloaded the latest Maschine
software from Native Access.
How to get support
The Native Instruments website has a dedicated Support page that is designed to help you find
answers to your questions and resolve any issues as quickly as possible. To get Support, visit
https://support.native-instruments.com/hc/.
User forum
In the Native Instruments User Forum, you can discuss product features directly with other users
and with experts moderating the forum. Please be aware that the Technical Support team does not
participate in the forum. If you’re encountering an issue that can’t be solved by other users, contact
Native Instruments’ Technical Support team via the online support as described above. You can
reach the User Forum via: http://www.native-instruments.com/forum.
