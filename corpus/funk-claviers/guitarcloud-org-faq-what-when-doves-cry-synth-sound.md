# What is the When Doves Cry synth sound?

 The main keyboard part from When Doves Cry is played on Yamaha DX7, using the "Koto" patch (Patch 23, Rom 1A/Patch 22, Rom 3B). The solo is played on an Oberheim OB-Xa or OB-8.
