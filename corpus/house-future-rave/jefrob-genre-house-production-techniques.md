# Production Techniques & Sonic Signatures

## Deep House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Ableton Live / Logic Pro | Primary DAWs for deep house production |
| Juno-106 / Juno-60 (or emulations) | Warm pads, chord stabs |
| Rhodes/Wurlitzer (Keyscape, Lounge Lizard) | Jazz-inflected keys |
| Roland TR-909 (or samples) | Classic house kick and hi-hats |
| Korg Minilogue / Prologue | Warm analog bass and pads |
| Reverb plugins (Valhalla Vintage Verb) | Spacious, warm atmosphere |

### Signature Production Techniques

#### Warm Chord Stabs
- Jazz voicings (7ths, 9ths, 11ths) — never basic triads
- Rhodes/EP character preferred over bright piano
- Short, staccato hits on off-beats or syncopated positions
- Light chorus and plate reverb for warmth
- Velocity variation creates human feel

#### Deep Bass Programming
- Round, warm synth bass (not aggressive or distorted)
- Often uses simple sine or triangle waves with subtle saturation
- Follows the root note with passing tones; not overly complex
- Sidechain to kick (subtle 2–3 dB ducking)
- Mono below 120 Hz

#### Groove-Focused Drums
- Kick: warm, round, not clicky (50–60 Hz fundamental)
- Hi-hats: shuffled 16ths with swing (55–62%)
- Rimshot/clap on 2 and 4, but soft and wide
- Percussion: congas, shakers for groove depth
- Ghost notes on hats create movement

#### Spatial Design
- Generous reverb on non-bass elements
- Delay throws on vocal/key phrases (1/4 or dotted 1/8)
- Wide stereo field on pads and percussion
- Mono center: kick, bass, vocal lead
- Space IS the production — avoid over-filling

### Mix Characteristics
- Warm, spacious, never loud or aggressive
- Target -14 LUFS (streaming), -10 to -11 LUFS (club)
- Light bus compression (2 dB GR max)
- Generous low-mids (100–300 Hz warmth)
- Never harsh in the highs — rolled off above 14 kHz gently

## Tech House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Ableton Live | Dominant DAW (clip-launching workflow) |
| Native Instruments Massive/Serum | Bass design, stabs |
| Roland TR-909 / TR-808 samples | Core drum sounds |
| Arturia DrumBrute | Analog percussion |
| Splice sample packs | Vocal chops, percussion loops |
| iZotope Trash / Soundtoys Decapitator | Saturation on bass/drums |

### Signature Production Techniques

#### Percussive Groove Layering
- 5+ percussion channels: kick, clap, hats, shaker, ride, congas, rimshot
- Layer open and closed hats for rhythmic complexity
- Offbeat open hat is signature (909 sound)
- Congas/bongos panned for width
- Shaker at constant 16ths provides groove glue

#### Driving Bass
- 16th-note patterns common (arpeggiated, rolling)
- Punchy, mid-focused (not deep sub — presence at 100–200 Hz)
- Distortion/saturation for grit
- Sidechain to kick (fast attack, medium release)
- Often monophonic, single-note patterns

#### Vocal Chop Processing
- Short samples (1–4 words) looped rhythmically
- Pitch-shifted, time-stretched, reversed
- Heavy reverb/delay throws
- Used as rhythmic texture, not lyrical content
- Chopped and re-triggered on beat divisions

#### Functional Arrangement
- DJ-tool focus: 32-bar intros/outros with clean kick
- Minimal emotional content — energy is physical, not emotional
- Filter sweeps for transitions (short, 2–4 bars)
- Snare/hat rolls building into drops
- Elements add/subtract every 8–16 bars

### Mix Characteristics
- Punchy, clear, loud (-8 to -9 LUFS for DJ tools)
- Kick presence at 50–70 Hz (sub) and 2–4 kHz (click)
- Bass sits 80–200 Hz, cut above for clarity
- Percussion transients sharp and present
- Minimal reverb (dry, upfront sound)

## Progressive House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Ableton Live / Logic Pro | Long arrangement workflow |
| Spire / Sylenth1 / Serum | Layered pads, evolving textures |
| Valhalla Shimmer / VintageVerb | Atmospheric reverbs |
| Soundtoys EchoBoy | Modulated delays |
| Kilohearts Phase Plant | Complex sound design |
| FabFilter Pro-Q3 / Pro-MB | Surgical EQ, dynamic processing |

### Signature Production Techniques

#### Long-Form Arrangement
- Tracks 7–10 minutes standard (DJ tools)
- Elements evolve over 64–128 bars
- Builds are gradual — no sudden drops
- Breakdown = atmospheric section (pads, reverb, space)
- Return from breakdown builds over 16–32 bars

#### Layered Pad Design
- 3–4 pad layers at different octaves/timbres
- Each layer filtered differently — reveals through automation
- Slow LFO modulation on cutoff/pitch creates evolution
- Long attack, long release — pads breathe slowly
- Side-chain to kick keeps low end clean

#### Bass Progression
- Bass evolves melodically over 16–32 bars
- Arpeggiated patterns preferred over static bass
- Filter automation reveals harmonics gradually
- Bass sits between 40–150 Hz
- Multiple bass layers: sub + mid character

#### Atmospheric Processing
- Long reverb tails (4–8 seconds) on pads and FX
- Delay throws on key melodic moments
- Field recordings (nature, ambience) for texture
- Granular processing on melodic elements
- Automation-heavy: every element evolves over time

### Mix Characteristics
- Wide, spacious stereo field
- Clean low end (kick and bass well-separated)
- Smooth high frequencies (no harshness)
- Dynamic (8–12 dB range), breathing mix
- Target -10 to -12 LUFS (preserves dynamics for long sets)

## Funky House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| FL Studio / Logic Pro | Sample-based workflow |
| Turntables / vinyl | Disco sample sourcing |
| MPC / Maschine | Chopping disco breaks |
| Korg M1 / Triton patches | Classic funky stabs |
| Guitar amp sims | Funky guitar parts |
| Bass guitar (or emulation) | Disco-style basslines |

### Signature Production Techniques

#### Disco Sample Flipping
- Chop disco/funk records into one-shot stabs
- Replay or re-chop basslines with house groove
- Filter and EQ to sit in modern mix
- Keep the "feel" of the original but with electronic drums
- Layer original elements with new production

#### Funky Bassline Programming
- Octave jumps (root → octave up → root)
- Chromatic approach notes (half-step slides into root)
- Syncopated rhythm — hits on off-beats and anticipations
- Slap bass character (short, percussive, punchy)
- Fingerstyle warmth on sustained notes

#### Disco-Style Drum Programming
- Four-on-the-floor kick (909 or acoustic samples)
- Open hat on every offbeat (signature disco feel)
- Clap/snare on 2 and 4 with reverb tail
- Shaker/tambourine constant 16ths
- Congas for groove depth

#### Vocal Production
- Full vocal hooks (soulful, uplifting)
- Harmonized backing vocals
- Call-and-response patterns
- Gospel-influenced ad-libs
- Reverb and delay for space

### Mix Characteristics
- Warm, energetic, full-frequency
- Prominent bass (funky, mid-present)
- Wide, vibrant stereo image
- Punchy drums that groove
- Vocals upfront and clear

## Afro House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Ableton Live | Primary DAW for layered percussion |
| Native Instruments Kontakt | African percussion libraries |
| Arturia Pigments / Analog Lab | Pads, arpeggios |
| Eventide / Valhalla reverbs | Spatial depth |
| Percussion sample libraries | Djembe, talking drum, shakers |
| UAD plugins | Analog warmth on percussion |

### Signature Production Techniques

#### Polyrhythmic Percussion Layering
- 5–8 percussion channels minimum
- Each layer has unique rhythmic identity
- Pan wide for immersive field
- Velocity variation and timing offsets (humanize)
- Ghost notes on congas/bongos create groove depth
- Layers: kick, hat, shaker, conga, djembe, rimshot, tom, tambourine

#### Spiritual/Organic Elements
- Kalimba, marimba, mbira for melodic hooks
- Field recordings of African environments
- Vocal chants and call-and-response
- Organic instrument samples (not purely synthetic)
- Long reverb for spiritual depth

#### Deep Sub Bass
- Simple, repetitive sub patterns (1–2 notes)
- Sine wave or triangle sub
- Sidechain to kick (tight, 4–6 dB ducking)
- Mono below 120 Hz
- Bass supports groove — doesn't lead

#### Arrangement Philosophy
- Gradual builds over 32–64 bars
- Percussion layers enter one at a time
- Vocals/melodic elements appear mid-track
- DJ-tool focus: long intros/outros
- Filter automation for evolution

### Mix Characteristics
- Wide percussion field, mono bass/kick center
- Clean low end (kick + bass separated)
- Warm midrange (organic instruments)
- Crisp percussion transients
- Moderate loudness (-9 to -10 LUFS for DJ use)

## Jackin House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| FL Studio / Ableton Live | Sample-based workflow |
| MPC / Maschine | Chopping and re-sequencing |
| Vinyl / digital crates | Source material for samples |
| Roland TR-909 / 808 | Raw drum sounds |
| Basic synths (saw, square) | Stab sounds |
| Tape saturation plugins | Raw character |

### Signature Production Techniques

#### Sample-Heavy Construction
- Lift loops from disco/funk/soul records
- Chop and replay with house groove
- Layer multiple samples for density
- Filter heavily to fit modern mix
- Raw, unpolished aesthetic is valid

#### Raw Drum Programming
- 909 kick: punchy, round, not over-processed
- Hi-hats: 16ths with swing (55–60%)
- Open hat on offbeats (Chicago feel)
- Clap on 2 and 4 (dry, short)
- Pattern stays constant — groove IS the track

#### Jacking Groove Feel
- Tempo 124–128 BPM ("jacking" speed)
- Shuffle/swing essential (not straight 16ths)
- Bass hits anticipate or syncopate against kick
- Everything serves the physical groove
- Strip back to essentials — no filler

#### Lo-Fi Production Aesthetic
- Not over-produced — rawness is a feature
- Tape saturation on master
- Sample artifacts (vinyl noise, crackle) acceptable
- Short, looped elements (2–4 bar loops)
- Minimal arrangement — add/subtract layers

### Mix Characteristics
- Raw, punchy, not overly polished
- Bass forward in the mix
- Samples can be "crunchy" (bit-reduced or saturated)
- Kick punchy and present
- Overall: functional dance floor tool

## Soulful House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Logic Pro / Pro Tools | Vocal recording and production |
| Rhodes/Wurlitzer (Keyscape) | Soulful keys |
| Live musicians (bass, guitar, strings) | Organic warmth |
| Neve / SSL channel strips (or emulations) | Vocal processing |
| Lexicon / TC Electronic reverbs | Warm vocal space |
| Analog synths (Moog, Prophet) | Warm bass and pads |

### Signature Production Techniques

#### Vocal Production (Core Element)
- Full vocal performances (not samples — live singers)
- Gospel/R&B vocal style with runs and ad-libs
- Harmonized backing vocals (stacked, wide)
- De-essing and compression for clarity
- Reverb: plate or hall, warm character
- Vocal sits ON TOP of the mix (not buried)

#### Live Instrumentation
- Bass: often live bass guitar (warm, round)
- Keys: Rhodes/Wurlitzer with chorus
- Guitar: clean rhythm guitar stabs
- Strings: pad-like string arrangements
- Horns: occasional brass stabs for energy

#### Warm Drum Programming
- Kick: round, warm, not aggressive (acoustic feel)
- Percussion: congas, shakers, tambourine for organic groove
- Hi-hats: swung, human timing
- Ghost notes everywhere for groove depth
- Less "electronic," more "band" feel

#### Arrangement Philosophy
- Song-form structure (verse, chorus, bridge)
- Vocal drives the arrangement
- Instrumental breaks for DJ use (8–16 bars)
- Longer tracks (6–8 minutes) with extended intros/outros
- Energy builds through vocal intensity

### Mix Characteristics
- Warm, full, lush frequency spectrum
- Vocal-forward mix
- Bass warm and round (not subby or aggressive)
- Keys and guitars provide harmonic warmth
- Generous reverb on vocals and keys
- Target -11 to -13 LUFS (dynamic, breathing)

## UK Garage

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Cubase / Logic Pro / Reason | Classic UKG DAWs |
| Akai MPC2000 / MPC3000 | Chopping vocals, drums |
| Roland JP-8000 (Super Saw) | Signature pad sound |
| Korg Triton / Trinity | Orchestral stabs, pads |
| Sub bass generators | Deep 808-style sub |
| Time-stretching tools | Vocal manipulation |

### Signature Production Techniques

#### 2-Step Drum Programming
- NOT four-on-the-floor — kick on beat 1, ghost kick on "and" of 2
- Snare/clap on beat 2 (not 2 and 4 like house)
- Shuffled hi-hats (skippy, complex patterns)
- Ghost kicks create the "skipping" feel
- Swing amount: 60–65% (heavy shuffle)

#### Chopped Vocal Technique
- Time-stretch vocals to fit BPM
- Chop into syllables and re-sequence
- Pitch up (female vocal character common)
- Layer multiple chops for rhythmic patterns
- Todd Edwards "micro-sampling" — tiny fragments create melody

#### Bass Design
- Deep sub bass (30–60 Hz) — sine wave dominant
- Reese bass stabs (detuned saws, filtered) for mid-bass
- 808-style sub with envelope shaping
- Bass hits syncopated with 2-step pattern
- Wobble or pitch-bend on bass notes for movement

#### Melodic Elements
- Super Saw pads (JP-8000 character)
- Orchestral stabs (Korg Triton presets)
- Piano riffs (classical garage piano runs)
- String pads for emotional sections
- Brass stabs for energy (disco-influenced)

### Mix Characteristics
- Sub-bass heavy (huge low end below 60 Hz)
- Crisp, detailed highs (shuffled hats must be clear)
- Vocals pitched up and present
- Wide stereo on pads, mono on sub
- Dynamic — shuffled groove needs dynamic range
- Target -10 to -12 LUFS (club)

## Electro House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| FL Studio / Ableton Live | Primary DAWs |
| NI Massive / Sylenth1 / Serum | Big lead synths |
| Sausage Fattener / OTT | Aggressive compression |
| Soundtoys / FabFilter | Creative effects |
| Ableton's Operator | FM bass design |
| Waves L2/L3 | Loud mastering |

### Signature Production Techniques

#### Big Synth Lead Design
- Supersaw leads (5–7 voices detuned)
- Massive unison stacks for width
- Filter automation (open on drops, closed in builds)
- Sidechain to kick for pumping effect
- Layered: sub layer + mid layer + top layer

#### Drop Construction
- Build: rising noise, snare rolls, filter opening
- 1–2 beats of silence before impact
- Drop: kick + bass + lead simultaneously
- Sidechain pumping creates rhythmic energy
- Fill every frequency band on the drop

#### Bass Design
- Distorted, aggressive bass (100–300 Hz dominant)
- FM synthesis for metallic character
- Resampled and processed through distortion chains
- Sidechain creates pumping against kick
- Mono below 150 Hz, width above

#### Arrangement (EDM-Influenced)
- Build → Drop → Breakdown → Build → Drop
- 8–16 bar builds with rising energy
- Drops are 16–32 bars of maximum energy
- Breakdowns strip to melodic/atmospheric elements
- Shorter than traditional house (4–6 minutes)

### Mix Characteristics
- LOUD (-6 to -8 LUFS for club/festival)
- Heavily compressed and limited
- Wide stereo on leads and effects
- Sub bass tight and punchy
- Bright, aggressive highs
- Minimal dynamic range (4–6 dB)

## Bass House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Ableton Live / FL Studio | Primary DAWs |
| Serum / Massive X | Wobble bass, sound design |
| Ableton Operator | FM bass synthesis |
| OTT (multiband compression) | Squashed bass character |
| Soundtoys Decapitator | Bass saturation |
| Sausage Fattener | Aggressive bus processing |

### Signature Production Techniques

#### Wobble Bass Design
- Serum wavetable scanning for movement
- LFO on cutoff at various rates (1/4, 1/8, triplets)
- OTT multiband compression for "in your face" bass
- Distortion/saturation layers for character
- Layered: sub (sine, clean) + mid (wobble, dirty) + top (presence)
- Resample and process for unique textures

#### G-House Influence
- Pitched-down vocal samples (gangsta rap aesthetic)
- Dark, minimal grooves with heavy bass
- Less "drop-oriented" than bass house
- Groove-focused with attitude
- 4/4 kick with simple hat patterns

#### Drop Design
- Hard-hitting: silence → kick + bass impact
- Bass fills the frequency spectrum on drops
- Sidechain pumping creates rhythmic bounce
- Risers and sweeps leading into drops
- "Bassline" approach — melodic bass patterns

#### Drum Programming
- Punchy kick (909-based, tight sub, clicky top)
- Simple hat patterns (not complex like tech house)
- Clap/snare on 2 and 4
- Minimal percussion — bass IS the focus
- Ghost kicks for groove depth

### Mix Characteristics
- Bass-forward mix (bass IS the hook)
- Loud (-7 to -9 LUFS)
- Heavily compressed bass bus
- Tight low end (sub + mid bass well-separated)
- Bright top end for contrast with dark bass
- Sidechain creates dynamic movement

## Chicago House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Roland TR-707 / TR-808 / TR-909 | THE drum sounds (or faithful samples) |
| Roland TB-303 | Acid bass (some tracks) |
| Roland Juno-106 / SH-101 | Pads, basslines |
| Korg Poly-800 / Poly-61 | Cheap synth stabs |
| Reel-to-reel tape | Recording medium (warmth, saturation) |
| Basic 4-track recorders | Bedroom production |

### Signature Production Techniques

#### Raw Drum Machine Programming
- TR-707: crisper, more hi-fi than 808 (characteristic Chicago sound)
- TR-909: punchier kick, metallic hats
- TR-808: deeper sub kick, more boom
- Patterns: simple, mechanical, repetitive — the "jack" groove
- No swing typically — straight, driving, grid-locked
- Raw output — minimal processing on drums

#### Jacking Groove Construction
- Four-on-the-floor kick with no variation
- Open hat on every offbeat (essential)
- Clap on 2 and 4 (dry, snappy)
- Pattern loops indefinitely — hypnotic repetition
- Groove comes from simplicity, not complexity

#### Synth Stabs and Chords
- Simple synth pads (Juno-106 character)
- Organ stabs (church organ, B3 style)
- Basic chord voicings (triads, occasional 7ths)
- Stabs on offbeats for rhythmic drive
- Minimal processing — raw synth output

#### Vocal Approach
- Continuous chanting ("jack your body," "move your body")
- Repetitive, hypnotic, rhythmic
- Raw recording quality (no polish)
- Call-and-response with the crowd
- Spoken word or preacher-style declarations

### Mix Characteristics
- Raw, lo-fi, warm
- Drum machine output often straight to tape
- Minimal EQ or compression
- Mono or narrow stereo
- Lo-fi character is genre-defining (not a flaw)
- Warm, saturated from tape

## Ghetto House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Roland TR-808 | THE drum machine for ghetto house |
| Basic samplers (E-mu, Akai) | Vocal sample triggering |
| FL Studio (Fruity Loops) | Production tool for later era |
| Cheap microphones | Vocal recording (raw quality) |
| 4-track / cassette recorders | Lo-fi recording chain |
| Basic sequencers | Pattern programming |

### Signature Production Techniques

#### Aggressive 808 Patterns
- Fast tempo (125–135 BPM) — driving and relentless
- Kick pattern: four-on-the-floor with occasional syncopation
- 808 toms for fills and accents
- Cowbell patterns (Dance Mania signature)
- Hi-hats: fast 16ths or triplets
- Minimal variation — repetition is the point

#### Vocal-Centric Production
- Explicit, repetitive vocal chants (defining element)
- Short phrases looped every 2–4 bars
- Often recorded raw/unprocessed
- Multiple vocal hooks layered
- Call-and-response between vocal samples
- Vocal IS the melody — no other melodic elements needed

#### Minimalist Approach
- 3–4 elements maximum (kick, hat, vocal, maybe one synth)
- No pads, no complex arrangements
- Stripped to absolute essentials
- Track = loop with slight variations
- Short tracks (3–4 minutes)

#### Raw Production Aesthetic
- Lo-fi recording quality (intentional)
- Clipping and distortion acceptable
- No mastering polish expected
- Bedroom/basement production sound
- Equipment limitations as creative constraints

### Mix Characteristics
- Raw, loud, aggressive
- 808 kick dominant in mix
- Vocals clear but not polished
- Narrow stereo (mono-compatible)
- Heavy limiting/clipping
- Lo-fi: -6 to -8 LUFS (slammed loud)

## UK Funky

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Logic Pro / Reason | UK production DAWs |
| Akai MPC | Percussion programming |
| African/Latin percussion samples | Tribal elements |
| Sub bass generators | UK bass culture low-end |
| Vocal choppers | R&B vocal manipulation |
| Synth stabs (Korg, Roland) | Hook elements |

### Signature Production Techniques

#### Broken Syncopated Rhythm
- NOT standard 4/4 — syncopated kick pattern
- Heavy swing (60–65%) with shuffle
- Influence from soca, Afrobeats, and garage
- Kick on 1, then syncopated ghost kicks
- Percussion carries the groove (not the kick)

#### Tribal Percussion Layering
- Congas, bongos, shakers, hand drums
- 3–5 percussion layers creating polyrhythmic web
- Each element syncopated differently
- African and Caribbean rhythmic influence
- Panned wide for immersive percussion field

#### UK Bass Culture Low-End
- Deep sub bass (30–60 Hz fundamental)
- Bass enters mid-track for energy step-up
- Bass patterns syncopated with drums
- Reese-style mid-bass for texture
- Sub wobble on longer notes

#### Vocal and Hook Design
- Choppy R&B vocal cuts
- Short, rhythmic vocal phrases
- Pitched and time-stretched
- Hooks are percussive, not melodic
- MC culture influence (occasional)

### Mix Characteristics
- Sub-heavy (UK bass culture foundation)
- Crisp percussion transients
- Wide percussion stereo field
- Dry, upfront mix (minimal reverb)
- Target -9 to -11 LUFS

## Gqom

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| FL Studio | Primary DAW for gqom producers |
| Basic sample packs | Percussion hits, impacts |
| Laptop/basic setup | Minimal equipment aesthetic |
| Low-frequency synths | Drone bass design |
| Distortion/saturation plugins | Dark character |
| Basic reverbs | Eerie atmospheric design |

### Signature Production Techniques

#### Dark Drone Bass
- Sustained, low-frequency drone (NOT melodic bass)
- Sine/triangle wave at 40–60 Hz, sustained
- Minimal pitch movement — static or slow shift
- Distortion for dark character
- NO melodic content — intentional absence

#### Fractured Percussion
- Heavy kick on the 4/4 grid (foundation)
- Percussion above is broken, fractured, off-grid
- Industrial/metallic percussion textures
- Sparse — space between hits is essential
- Toms and impacts replace melodic elements

#### Hypnotic Repetition
- Loop-based: 2–4 bar patterns repeated extensively
- Minimal variation (subtle changes every 16–32 bars)
- Repetition creates trance-like/hypnotic state
- No builds, no drops — flat energy
- Track length 4–6 minutes of sustained groove

#### Lo-Fi Dark Aesthetic
- Deliberately raw production
- Distortion and saturation on everything
- Dark reverb tails (eerie, not beautiful)
- No brightness — low-pass filtered aesthetic
- Equipment limitations embraced as character

### Mix Characteristics
- Dark, murky, low-frequency dominated
- Kick and drone bass dominate mix
- Percussion present but filtered
- Very narrow stereo field
- Heavily compressed
- Target -8 to -10 LUFS

## French Touch

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Akai MPC / E-mu SP-1200 | Disco sample chopping |
| Turntables + vinyl | Sourcing disco/funk records |
| Analog compressors (1176, LA-2A) | Extreme sidechain and bus compression |
| Analog filters (Moog, Korg MS-20) | Filter sweeps |
| Roland TR-909 | House drums underneath |
| Phaser/Flanger pedals | Disco sample processing |

### Signature Production Techniques

#### Disco Sample Manipulation
- Lift loops from 70s/80s disco, funk, boogie records
- Filter heavily (low-pass) — only reveal through automation
- Phase/flanger processing for movement
- Chop into new rhythmic patterns
- Layer multiple samples for harmonic richness

#### Extreme Sidechain Compression
- THE signature sound of French Touch
- 8–12 dB ducking triggered by kick (not subtle)
- Everything sidechained: pads, samples, bass, vocals
- Creates the "pumping" rhythmic feel
- Fast attack, medium release (release IS the groove)

#### Dramatic Filter Sweeps
- Low-pass filter closed in verses/builds
- Filter opens for chorus/peak sections
- Sweep over 4–16 bars for dramatic build
- Filter position = song structure
- Resonance boost at cutoff for screaming filter sound

#### Saturated, Compressed Mix
- Analog saturation on bus (tape, tube, transformer)
- Heavily compressed (bus compression 4–6 dB GR)
- Loudness through saturation, not just limiting
- Warm, "hot" sound — pushing gear into distortion
- Vinyl-like warmth from analog processing chain

### Mix Characteristics
- Warm, saturated, compressed
- LOUD (-7 to -9 LUFS)
- Pumping sidechain creates rhythmic dynamics
- Bass prominent (disco funk bass character)
- Filtered highs until "opened" sections
- Mono-compatible (club-focused)

## Lo-Fi House / Outsider House

### Key Hardware & Software
| Tool | Usage |
|------|-------|
| Cassette tape recorders | Tape saturation, warble |
| Roland TR-606 / TR-707 / Volca | Lo-fi drum machines |
| Cheap samplers (SP-404, Volca Sample) | Sample mangling |
| Ableton Live (with degradation plugins) | Production + destruction |
| Vinyl records + turntable | Sample sourcing |
| RC-20 Retro Color / Izotope Vinyl | Tape/vinyl emulation |

### Signature Production Techniques

#### Tape Saturation and Degradation
- Record through cassette tape (or emulate convincingly)
- Tape warble (pitch modulation) on melodic elements
- Hiss and noise as intentional texture
- Bit-crushing for digital lo-fi character
- Bouncing audio multiple times for cumulative degradation

#### Unquantized Drum Programming
- Slightly off-grid timing (5–15ms drift)
- Human feel from imprecise placement
- Drum machine patterns with added swing/drift
- NOT sloppy — subtle humanization
- Classic house patterns underneath the lo-fi processing

#### Filtered Chord Loops
- Sample chords from vinyl (jazz, soul, disco)
- Heavy low-pass filtering (muffled, warm)
- Saturate and compress for warmth
- Loop 2–4 bars with slight variation
- Vinyl crackle and noise from source material

#### DIY Aesthetic
- Bedroom production is the point
- Imperfection as artistic choice
- Limited gear = creative constraints

### Signature Production Techniques

#### Unquantized Percussion
- Drums placed by feel, not grid
- 2-step rhythm implied but loosened/broken
- Hi-hats drift in timing (human, imprecise)
- Ghost notes at very low velocity (barely audible)
- Swing: 55–65% but inconsistent (changing per beat)

#### Pitched Vocal Chops
- Short vocal snippets (1–3 syllables)
- Pitched up or down (often formant-shifted)
- Layered with reverb and delay
- Rhythmic vocal patterns (not lyrical)
- Signature emotional quality — melancholic, distant

#### Spatial/Atmospheric Design
- Cavernous reverbs (5–10 second tails)
- Vinyl crackle as constant texture
- Field recordings (rain, urban ambience, static)
- Wide stereo field (immersive, cinematic)
- Multiple reverb sizes creating depth layers

#### Reese Bass Processing
- Detuned sawtooth waves (classic reese)
- Heavy low-pass filtering (warm, dark)
- Subtle movement from detuning/chorus
- Sub layer added underneath for weight
- Automation: filter opens and closes slowly

#### Half-Time/Double-Time Feel
- 130–140 BPM but FEELS half-time
- Implies both UKG shuffle AND half-time simultaneously
- Kick sparse — not on every beat
- Spacious — lots of gaps in the rhythm
- Ambiguity between tempos is the aesthetic

### Mix Characteristics
- Wide, spacious, reverb-heavy
- Sub bass present but not aggressive
- Highs detailed but soft (vinyl crackle, air)
- Very dynamic (10–14 dB range)
- Quiet, intimate loudness (-12 to -14 LUFS)
- Mono compatibility less critical (headphone music)
