# Recherche house — Axe 2 : six producteurs de référence (Guetta, MORTEN, Garrix, Chris Lake, Jauz, Dom Dolla)

Date : 2026-09-24. Skill cible : `house-future-rave-bass-house-production` (Ableton Live 12 + Serum 2).

## Méthode, légende et limites

- **Réseau** : seul `raw.githubusercontent.com` (curl) et `github.com` (WebFetch) étaient joignables ; tout autre site est bloqué. Les sites presse (SOS, MusicTech, MusicRadar, Attack, DJ Mag, Billboard, EDM.com, Tunebat, Beatport, Wikipedia) n'ont donc été vus **qu'à travers les résumés de 15 recherches web** (quota épuisé : 15/15). Ces résumés sont étiquetés **[DOC-EXTRAIT]** ; ils sont exploitables mais **aucune citation n'a pu être vérifiée sur la page d'origine** — toutes les URL correspondantes sont listées en §10 et dans `urls-axe2.json` pour récupération depuis le Mac.
- **Étiquettes** : **[DOC]** = document lu en entier (GitHub raw ou corpus local) ; **[DOC-EXTRAIT]** = résumé de recherche web ; **[HEUR]** = note communautaire non sourcée (fiche de dépôt GitHub, template, dataset d'app) ; **[NON VÉRIFIÉ]** = connaissance générale ou hypothèse que les sources accessibles n'ont pas confirmée. Les tonalités issues des « audio features » Spotify sont notées **[DOC-Spotify]** (clé 0=do … 11=si ; mode 1=majeur, 0=mineur ; algorithme, donc erreurs possibles sur la tierce ou le relatif).
- **Aucune citation inventée** : quand le texte exact n'est pas lisible, la phrase est paraphrasée et signalée « (paraphrase) ».
- **Outil GitHub MCP** restreint au dépôt `tsila` : les lectures ont été faites en `curl` sur raw (URL exactes indiquées).

### Sources locales déjà utilisables (lues)

- `corpus/cuivres/amen-sessions-01-house.md` [HEUR-lu] : house 118–128 BPM, tonalités mineures par défaut (la, fa, sol, do, ré mineur ; dorien fréquent), club edit 5–7 min / radio 3–4 min, −9 à −7 LUFS ; sous-genres : future house 124–128 (« metallic, pitched-bass drops, EDM structure »), bass house 126–130 (« aggressive mid-bass, dubstep influence »).
- `corpus/cuivres/amen-sessions-09-edm-and-future-bass.md` [HEUR-lu] : big room 126–132 BPM mineur −6/−5 LUFS ; future house 124–128 mineur −7/−6 ; arrangement EDM universel (intro 16 mesures, build, silence 1 mesure, drop 32 mesures, break, build 2, drop 2, outro ; 3:00–3:30 ; « the drop is often sparser than the build »).
- `corpus/cuivres/jefrob-house-sound-design.md` [HEUR-lu] : section « Bass House » — kick 909 serré (sub 50 Hz, clic 3–5 kHz), wobble bass Serum (LFO sur cutoff, OTT, distorsion, 3 couches sub 30–60 Hz / mid 80–500 Hz / top 500 Hz–3 kHz, resampling), samples vocaux G-house pitchés −2 à −4 demi-tons, sub sinus mono, percussions simples.
- Déjà versés par les autres agents dans `corpus/house-future-rave/` (non dupliqués ici) : `bitwize-genre-bass-house-readme.md`, `bitwize-genre-future-house-readme.md`, `bitwize-genre-edm-readme.md`, `jefrob-house-artists-and-history.md`, `edm-midi-studio-genres-future-rave-extrait.md` (future rave chiffré : 126 BPM, mineur, swing 0, accords quinte/add9/sus4, basse offbeat en croches, arpège en doubles, lead « festival »), `gaku52-bpm-tempo-ja.md` (Future House 128, Bass House 128, Tech House 128, House 125).
