## Typical Arrangement Structures

### Deep House

#### 1. Warm Groove Standard (6–7 min)
```
Intro (16–32 bars) → Groove A (32 bars) → Build (8–16 bars) →
Main (32–64 bars) → Breakdown (16 bars) → Main B (32 bars) → Outro (16–32 bars)
```
Classic deep house. Warm, rolling, groove-focused with subtle peaks.

#### 2. Vocal Showcase (6–7 min)
```
Intro (32 bars) → Groove (32 bars) → Vocal Entry (16 bars) →
Vocal Main (32–64 bars) → Breakdown / Vocal Solo (16 bars) → Main B (32 bars) → Outro (32 bars)
```
Built around a soulful vocal. Breakdown features stripped-back vocal over pads.

#### 3. Late Night Minimal (7–8 min)
```
Intro (32 bars) → Groove A (64 bars) → Groove B (64 bars) →
Peak (32–48 bars) → Outro (32 bars)
```
Extended grooves, minimal structural contrast. Hypnotic, after-hours style.

#### 4. Jazz-Inflected (5–6 min)
```
Intro (16 bars) → Chord Groove (32 bars) → Solo/Riff Section (32 bars) →
Full Arrangement (32 bars) → Breakdown (16 bars) → Return (32 bars) → Outro (16 bars)
```
Borrows from jazz structure — introduction of themes, solo section, full band.

---

### Tech House

#### 1. Functional DJ Tool (6–7 min)
```
Intro (16–32 bars) → Loop A (32 bars) → Build (8 bars) →
Drop A (32 bars) → Break (8–16 bars) → Drop B (32–64 bars) → Outro (16–32 bars)
```
Punchy drops, brief breaks, mix-friendly.

#### 2. Percussive Roller (6–7 min)
```
Intro (32 bars) → Groove A (64 bars) → Groove B / Intensified (64 bars) →
Outro (32 bars)
```
Two extended grooves, minimal structural markers. Continuous rolling energy.

#### 3. Vocal Chop Driver (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → Vocal Chop Entry (16 bars) →
Full Drop (32–48 bars) → Break (8 bars) → Drop B (32–48 bars) → Outro (16 bars)
```
Vocal samples drive the energy. Chop entry signals the build toward the drop.

#### 4. Festival Tech (5–6 min)
```
Intro (16 bars) → Build (16 bars) → Drop A (32 bars) →
Break (8–16 bars) → Build (8 bars) → Drop B (32 bars) → Outro (16 bars)
```
Shorter, punchier structure for festival/mainstage tech house.

---

### Progressive House

#### 1. Slow Burn (7–9 min)
```
Intro (32 bars) → Groove (32 bars) → Build (32 bars) →
Peak A (32–64 bars) → Breakdown (16–32 bars) → Peak B (64 bars) → Outro (32 bars)
```
Classic progressive. Long builds, evolving textures, dramatic contrast between breakdown and peak.

#### 2. Continuous Evolution (8–10 min)
```
Intro (32 bars) → Phase A (64 bars) → Phase B (64 bars) →
Phase C / Peak (64 bars) → Descent (32 bars) → Outro (32 bars)
```
No clear drops. Elements evolve continuously. Close to melodic techno sensibility.

#### 3. Layered Payoff (7–8 min)
```
Intro (32 bars) → Layer 1 (32 bars) → Layer 2 (32 bars) →
Layer 3 / Build (32 bars) → Full Density (64 bars) → Outro (32 bars)
```
Each section adds one element. The payoff is hearing everything together.

#### 4. Double Peak (8–9 min)
```
Intro (32 bars) → Build A (32 bars) → Peak A (32 bars) →
Breakdown (32 bars) → Build B (32 bars) → Peak B (64 bars) → Outro (32 bars)
```
Two peaks with long emotional breakdown between them. Influenced by trance structure.

---

### Funky House

#### 1. Disco-Influenced Standard (5–6 min)
```
Intro (16–32 bars) → Groove (32 bars) → Funk Break (16 bars) →
Main (32–64 bars) → Breakdown (16 bars) → Main B (32 bars) → Outro (16–32 bars)
```
Classic funky. Disco-style bassline drives everything. Funk break = percussion-only moment.

#### 2. Vocal Party (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → Vocal Hook Entry (8 bars) →
Vocal Main (32–48 bars) → Instrumental Drop (16 bars) → Vocal Return (32 bars) → Outro (16 bars)
```
Party-focused, vocal hook is the star.

#### 3. Extended Roller (6–7 min)
```
Intro (32 bars) → Groove A / Bassline (64 bars) →
Groove B / Horn or String Stab (64 bars) → Outro (32 bars)
```
Long rolling groove with disco-era instrument stabs added in the second half.

#### 4. Call-Response (5–6 min)
```
Intro (16 bars) → Bassline (32 bars) → Horn/Stab Response (32 bars) →
Combined Full (32–48 bars) → Break (8–16 bars) → Peak (32 bars) → Outro (16 bars)
```
Funky musical dialogue between bass and melodic stabs.

---

### Afro House

#### 1. Polyrhythmic Journey (6–8 min)
```
Intro (16–32 bars) → Percussion Build (32 bars) → Groove A (32–64 bars) →
Breakdown / Chant (16–32 bars) → Groove B (32–64 bars) → Outro (16–32 bars)
```
Polyrhythmic percussion dominates. Breakdown features call-and-response vocals.

#### 2. Tribal Epic (7–9 min)
```
Intro (32 bars) → Layer A / Drums (32 bars) → Layer B / Bass + Perc (32 bars) →
Full Tribal (64 bars) → Chant Section (32 bars) → Peak (32–64 bars) → Outro (32 bars)
```
Extended, layered build to full tribal density.

#### 3. Organic Groove (6–7 min)
```
Intro (16 bars) → Kalimba/Marimba (32 bars) → Drum Entry (16 bars) →
Full Groove (64 bars) → Percussion Solo (16 bars) → Return (32 bars) → Outro (16 bars)
```
Organic instruments lead. Drums serve the melody rather than the other way around.

#### 4. Spiritual Build (7–8 min)
```
Intro / Atmosphere (32 bars) → Rhythm Entry (32 bars) → Vocal Entry (16 bars) →
Full Spiritual (64 bars) → Breakdown (16 bars) → Peak Intensity (32–48 bars) → Outro (32 bars)
```
Atmosphere-first. Spiritual/chant vocals over polyrhythmic drums.

---

### Jackin House

#### 1. Raw Jack (5–6 min)
```
Intro (16 bars) → Jack Groove (32 bars) → Sample Drop (8 bars) →
Main (32–64 bars) → Break (8 bars) → Main B (32 bars) → Outro (16 bars)
```
Raw, sample-heavy. Short sections, punchy. Chicago-influenced.

#### 2. Sample Collage (5–7 min)
```
Intro (16 bars) → Sample A (32 bars) → Sample B (32 bars) →
Combined (32–48 bars) → Strip (8 bars) → Peak (32 bars) → Outro (16 bars)
```
Multiple vocal/instrument samples layered progressively.

#### 3. Relentless Jack (4–6 min)
```
Intro (16 bars) → Full Jack (64 bars) → Switch (8 bars) →
Full Jack B (64 bars) → Outro (16 bars)
```
Near-continuous energy. One swap in the middle of the bass/sample.

#### 4. Chicago Throwback (5–6 min)
```
Intro (16–32 bars) → Groove (32 bars) → Vocal Chant Section (32 bars) →
Groove B (32 bars) → Peak (16–32 bars) → Outro (16–32 bars)
```
Nods to classic Chicago jacking house.

---

### Soulful House

#### 1. Vocal-Driven Standard (6–7 min)
```
Intro (16–32 bars) → Groove (32 bars) → Verse (16 bars) →
Chorus/Hook (32 bars) → Verse 2 (16 bars) → Chorus B (32–48 bars) → Outro (16–32 bars)
```
Strong vocal narrative over warm house production.

#### 2. Gospel Build (6–7 min)
```
Intro (32 bars) → Groove (32 bars) → Vocal Entry (16 bars) →
Build to Praise (32 bars) → Full Gospel Peak (32–64 bars) → Outro (32 bars)
```
Gospel-influenced. Builds to an uplifting vocal peak.

#### 3. Instrumental Soul (5–7 min)
```
Intro (16 bars) → Rhodes/Keys Groove (32 bars) → Build (16 bars) →
Full Arrangement (64 bars) → Breakdown / Keys Solo (16 bars) → Return (32 bars) → Outro (16 bars)
```
No prominent vocal. Rhodes piano and warm pads carry the soul.

#### 4. Late Night (7–8 min)
```
Intro (32 bars) → Groove A (64 bars) → Vocal Interlude (16 bars) →
Groove B (64 bars) → Outro (32 bars)
```
Extended, intimate. Vocal appears briefly then returns to instrumental warmth.

---

### UK Garage

#### 1. 2-Step Standard (4–5 min)
```
Intro (8–16 bars) → Verse (16 bars) → Build (8 bars) →
Chorus/Drop (16–32 bars) → Verse 2 (16 bars) → Chorus B (16–32 bars) → Outro (8–16 bars)
```
Pop-influenced structure with skippy 2-step rhythms.

#### 2. MC-Driven (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → MC Section A (32 bars) →
Drop (16–32 bars) → MC Section B (32 bars) → Drop B (16–32 bars) → Outro (16 bars)
```
MC vocal flow drives the arrangement.

#### 3. Dub Plate Special (4–5 min)
```
Intro (16 bars) → Rewind Section (32 bars) → Drop A (32 bars) →
Break (8–16 bars) → Drop B (32–48 bars) → Outro (8–16 bars)
```
Designed for live dubplate culture. Rewind-friendly drop entry.

#### 4. Bassline Roller (5–6 min)
```
Intro (16 bars) → Sub Bass Groove (32 bars) → Build (8–16 bars) →
Full Garage (32–48 bars) → Strip (8 bars) → Sub Return (32 bars) → Outro (16 bars)
```
Sub bass dominates. Skippy drums over deep wobbling bass.

---

### Electro House

#### 1. Big Room Standard (4–5 min)
```
Intro (8–16 bars) → Build (16–32 bars) → Drop A (16–32 bars) →
Breakdown (16–32 bars) → Build (8–16 bars) → Drop B (16–32 bars) → Outro (8–16 bars)
```
Clear build-drop structure. Massive synths, aggressive drops.

#### 2. Festival Anthem (4–5 min)
```
Intro (8 bars) → Theme/Hook (16 bars) → Build (16 bars) →
Drop A (32 bars) → Breakdown (16 bars) → Build (16 bars) → Drop B (32 bars) → Outro (8 bars)
```
Front-loads the hook. Designed for maximum crowd reaction.

#### 3. Extended DJ Mix (6–7 min)
```
Intro (32 bars) → Groove (32 bars) → Build (16 bars) →
Drop (32–48 bars) → Breakdown (16 bars) → Build (16 bars) → Drop B (32–48 bars) → Outro (32 bars)
```
Mix-friendly version with extended intro/outro.

#### 4. Progressive Electro (6–7 min)
```
Intro (16 bars) → Build Phase A (32 bars) → Build Phase B (32 bars) →
Massive Drop (32–64 bars) → Outro (16–32 bars)
```
One massive buildup leading to a single extended drop.

---

### Bass House

#### 1. Wobble Standard (4–5 min)
```
Intro (8–16 bars) → Build (8–16 bars) → Drop A (16–32 bars) →
Breakdown (8–16 bars) → Build (8 bars) → Drop B (16–32 bars) → Outro (8–16 bars)
```
Wobble-bass drops with quick builds. Short functional breakdowns.

#### 2. G-House Groove (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → Bass Build (16 bars) →
Bass Drop (32–48 bars) → Break (8 bars) → Drop B (32 bars) → Outro (16 bars)
```
Groovier, more restrained. G-house influence with deeper bass.

#### 3. Festival Bass (3–4 min)
```
Intro (8 bars) → Build (16 bars) → Drop A (16–32 bars) →
Mini-Break (4–8 bars) → Drop B (16–32 bars) → Outro (8 bars)
```
Ultra-compact for maximum festival impact.

#### 4. Extended Roller (5–6 min)
```
Intro (16 bars) → Build (16 bars) → Drop A (32 bars) →
Groove Section (32 bars) → Build (8 bars) → Drop B (32 bars) → Outro (16 bars)
```
Adds a groove section between drops for more DJ versatility.

---

### Chicago House

#### 1. Jacking Standard (5–7 min)
```
Intro (16–32 bars) → Groove A (32–64 bars) → Vocal Chant Section (32 bars) →
Groove B (32–64 bars) → Outro (16–32 bars)
```
Continuous rhythmic vocal chants over raw drum machine grooves.

#### 2. Organ Jam (5–6 min)
```
Intro (16 bars) → Beat (32 bars) → Organ Entry (16 bars) →
Full Jack (64 bars) → Outro (16 bars)
```
Hammond organ or synth organ over 909 drums. Simple, raw.

#### 3. Extended Acid House (6–8 min)
```
Intro (32 bars) → 303 Groove (64 bars) → Vocal/Chant Layer (32 bars) →
Acid Peak (64 bars) → Outro (32 bars)
```
Chicago acid house lineage. 303 drives the arrangement.

#### 4. Warehouse Stripped (4–5 min)
```
Intro (16 bars) → Full Groove (64–96 bars) → Outro (16 bars)
```
Minimal structure. One groove, long duration, raw and unpolished. True warehouse style.

---

### Ghetto House

#### 1. Vocal Hook Driver (3–5 min)
```
Intro Beat (8–16 bars) → Main Groove (32–64 bars) →
Vocal Hook Intensification (16–32 bars) → Peak (16–32 bars) → Outro (8 bars)
```
Hyper-repetitive vocal loops every 2–4 bars. Direct, fast, minimal variety.

#### 2. Party Blast (3–4 min)
```
Intro (8 bars) → Full Energy (32–48 bars) → Vocal Acceleration (16 bars) →
Peak (32 bars) → Outro (8 bars)
```
Ultra-short, maximum energy from the start. No subtlety.

#### 3. Extended Club (4–5 min)
```
Intro (16 bars) → Groove A (32 bars) → Vocal Entry (8 bars) →
Peak A (32 bars) → Break (4–8 bars) → Peak B (32 bars) → Outro (8–16 bars)
```
Slightly longer for DJ use with brief break.

#### 4. Battle Track (2–3 min)
```
Intro (4–8 bars) → Full Assault (32–48 bars) → Outro (4–8 bars)
```
For dance battles. Immediate full energy, ultra-short.

---

### UK Funky

#### 1. Percussive Standard (5–6 min)
```
Intro (16 bars) → Percussive Groove (32 bars) → Bass Entry (16 bars) →
Main Body (32–64 bars) → Breakdown / Strip (8–16 bars) →
Main Return (32 bars) → Outro (16 bars)
```
Syncopated groove with broken rhythmic hooks. Abrupt section deletions common.

#### 2. Tribal Build (5–7 min)
```
Intro (16 bars) → Tribal Percussion (32 bars) → Build (16 bars) →
Full Tribal + Bass (64 bars) → Percussion Solo (16 bars) → Peak (32 bars) → Outro (16 bars)
```
Tribal percussion focus with UK bass culture low-end.

#### 3. MC Flow (4–5 min)
```
Intro (16 bars) → Beat (32 bars) → MC Section (32 bars) →
Drop (32 bars) → MC Section B (16 bars) → Drop B (32 bars) → Outro (8–16 bars)
```
MC vocal flow over funky broken beats.

#### 4. Carnival Energy (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → Horn/Stab Entry (16 bars) →
Full Carnival (64 bars) → Strip (8 bars) → Return (32 bars) → Outro (16 bars)
```
Festival/carnival energy with brass and percussion layers.

---

### Gqom

#### 1. Hypnotic Standard (5–7 min)
```
Intro (16–32 bars) → Percussive Matrix A (64 bars) →
Drone/Atmosphere Shift (16 bars) → Matrix B (64 bars) → Outro (16–32 bars)
```
Zero melodic buildup. Heavy fractured percussion with sparse eerie layers.

#### 2. Minimal Pulse (5–6 min)
```
Intro (16 bars) → Pulse A (64 bars) → Pulse B (64 bars) → Outro (16 bars)
```
Two phases of the same dark pulse. Differences are percussive only.

#### 3. Dark Extended (6–8 min)
```
Intro (32 bars) → Sparse Phase (32 bars) → Dense Phase (64 bars) →
Peak Weight (64 bars) → Outro (32 bars)
```
Gradually increases percussive density over a longer timeline.

#### 4. Club Functional (4–5 min)
```
Intro (16 bars) → Full Gqom (64–96 bars) → Outro (16 bars)
```
Minimal structure. One sustained dark groove.

---

### French Touch

#### 1. Filter Drama (5–6 min)
```
Intro (16 bars) → Filtered Loop A (32 bars) → Filter Open Build (8–16 bars) →
Main (32–64 bars) → Breakdown / Filter Close (16 bars) →
Filter Open Main B (32 bars) → Outro (16 bars)
```
Filter position defines the structure. Open = energy, closed = breakdown.

#### 2. Disco Sample Journey (6–7 min)
```
Intro (16 bars) → Sample A Filtered (32 bars) → Sample A Open (32 bars) →
Sample B Entry (32 bars) → Full Combined (32–48 bars) → Outro (16 bars)
```
Multiple disco samples introduced via filtering. Combined at peak.

#### 3. Sidechain Pump (5–6 min)
```
Intro (16 bars) → Light Pump (32 bars) → Heavy Pump (32 bars) →
Full Pump Peak (32–64 bars) → Release (16 bars) → Outro (16 bars)
```
Sidechain intensity increases as the arrangement progresses.

#### 4. Extended Mix (7–8 min)
```
Intro (32 bars) → Groove (32 bars) → Filter Build (16 bars) →
Main (64 bars) → Breakdown (16 bars) → Main B (32 bars) → Outro (32 bars)
```
DJ-extended version with longer intro/outro.

---

### Lo-Fi House / Outsider House

#### 1. Warm Groove Standard (5–7 min)
```
Intro (16–32 bars) → Groove A (32–64 bars) → Filtered Bridge (8–16 bars) →
Main Groove (32–64 bars) → Variation / Shift (16–32 bars) → Outro (16–32 bars)
```
Intentionally saturated. Tape warble over classical house grid.

#### 2. Late Night Session (6–8 min)
```
Intro (32 bars) → Loop A (64 bars) → Loop B (64 bars) →
Loop C (32 bars) → Outro (32 bars)
```
Three loops, each slightly different. Warm, hazy, hypnotic.

#### 3. Bedroom Producer (4–5 min)
```
Intro (16 bars) → Main Loop (64 bars) → Variation (32 bars) →
Return (32 bars) → Outro (16 bars)
```
Short, DIY aesthetic. One main loop with a variation.

#### 4. Vinyl Dig (5–6 min)
```
Intro / Crackle (16 bars) → Sample A (32 bars) → Sample B (32 bars) →
Combined (32–48 bars) → Outro / Crackle (16 bars)
```
Sample-based. Two vinyl samples layered progressively.

### Future Garage

#### 1. Cinematic Standard (5–6 min)
```
Intro / Atmosphere (16–32 bars) → Groove Establishment (16–32 bars) →
Main A (32 bars) → Breakdown / Vocal (16–32 bars) →
Main B (32 bars) → Outro / Dissolution (16–32 bars)
```
Melancholic, organic. Unquantized percussion, spatial atmospheres.

#### 2. Ambient Journey (6–8 min)
```
Ambient Intro (32 bars) → Rhythm Entry (16 bars) → Groove A (32 bars) →
Atmospheric Bridge (16 bars) → Groove B (32–64 bars) → Ambient Outro (32 bars)
```
Bookended by pure atmosphere. The groove emerges and dissolves.

#### 3. Vocal Fragment (5–6 min)
```
Intro (16 bars) → Groove (32 bars) → Vocal Chop Entry (16 bars) →
Vocal Main (32–48 bars) → Breakdown (16 bars) → Groove Return (32 bars) → Outro (16 bars)
```
Pitched vocal chops as the primary melodic content.

#### 4. Half-Time Drift (5–7 min)
```
Intro (32 bars) → Half-Time Groove A (32–64 bars) →
Half-Time Groove B (32–64 bars) → Dissolution (32 bars) → Outro (16 bars)
```
Everything at half-time feel. Glacial movement, maximum space.
