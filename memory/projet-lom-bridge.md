## Pièges appris (à recopier dans le skill technique quand confirmés dans Live)
- `FakeSong.undo()` des tests remet clips + paramètres + notes d'un coup : **hypothèse** sur Live, à confirmer avec § 4b de `live_suite.py`.
- `/load` ne détecte pas un hot-swap sur une **autre** piste si le nombre de devices y reste le même (comparaison par nombre) ; sur la piste cible, comparaison par `_live_ptr` (fiable).
- `/notes` n'écrit ni ne compare probabilité, déviation de vélocité, release.
- Toutes les commandes d'écriture sont autorisées en HTTP (`lom.py serve`) ; seuls `/py /set /call /reload` restent bloqués sans `--unsafe`.
- `journal.jsonl` : pas de rotation.
- Le mémo d'usage à jour est `.claude/skills/ableton-live-session/references/bridge.md` ; la référence complète du protocole est `lom-bridge/README.md`.
