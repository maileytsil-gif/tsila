# Techno — Rumble Bass / Low Texture

## Architecture
Kick sec + return rumble + éventuellement basse tonale séparée.

## Workflow [HEUR]
1. Send du kick vers reverb/delay.
2. Saturer/clipper le retour.
3. Filtrer la queue pour contrôler highs et sub extrême.
4. Sidechain du rumble par le kick sec.
5. Ajuster note/résonance si le rumble devient tonal.

## Outils
ValhallaRoom/Supermassive/Delay ou Ableton Reverb/Echo ; Roar/Trash/Saturn 2 pour caractère ; Pro-C 3/Ableton Compressor pour ducking ; Utility pour contrôle mono.

## Règle
Le rumble est un instrument séparé, pas une excuse pour laisser une reverb full-range sur le kick direct [HEUR].
