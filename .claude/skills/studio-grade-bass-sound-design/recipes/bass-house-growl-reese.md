# Bass House — Growl / Reese

## Architecture
`SUB clean + MID growl/reese + optional attack/noise`.

## Serum 2 [HEUR]
- SUB sine routé Direct [DOC].
- OSC A wavetable harmonique ; OSC B seconde couleur ou mod source.
- unison léger/modéré uniquement sur MID.
- filtre notch/BP/LP selon caractère.
- LFO 1 principal : 1/4, 1/8 ou 1/16 ; assigné à WT/filter/FM/drive dans proportions différentes.
- LFO 2 secondaire : micro-variation ou fin de phrase.
- saturation puis EQ ; resampling recommandé après mouvement réussi.

## Processing
- Trash/Roar pour destruction parallèle.
- Saturn 2 pour saturation multibande contrôlée.
- Pro-Q 4 spectral dynamics pour pics mobiles.
- Pro-C 3 sidechain kick.
- ValhallaDelay très filtré pour réponses/fills, jamais comme sub principal.

## Tests
Chaque position LFO doit garder une fondamentale perceptible ou être compensée par le SUB.
