# Acid / Resonant Bass

## Intention
Saw/square, filtre résonant, accents et slides.

## Patch [HEUR]
- source saw ou square ; mono legato.
- LP 12/18/24 ; resonance modérée à forte.
- ENV filter courte ; accents via velocity/macros.
- glide 20–120 ms selon pattern.
- saturation après filtre, parfois avant pour autre caractère.

## Serum 2
Tester filtres ladder/state-variable documentés [DOC]. Utiliser Drive/Fat selon le type choisi [DOC].

## Processing
Saturn 2/Roar pour coloration ; Pro-Q 4 dynamique si resonance devient agressive ; Delay filtré très court possible.

## Test
La resonance doit servir le groove sans transformer chaque note en pic incontrôlé.
