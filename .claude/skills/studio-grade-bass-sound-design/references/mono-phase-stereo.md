# Mono, phase et stéréo

## Sub
[HEUR] Le fondamental doit généralement rester cohérent au centre. Dans Ableton, Utility `Bass Mono` peut convertir la zone basse en mono [DOC].

Ne pas fixer le seuil à une valeur universelle. Tester 70, 90, 110, 130 Hz ou autre selon le patch, puis écouter ce qui disparaît [TEST].

## Layering
Deux oscillateurs/layers proches peuvent s'annuler ou gonfler selon leur phase. Le problème se juge sur le signal somme, pas sur la beauté de chaque couche en solo [TEST].

## Kick + bass
Si la combinaison perd du poids alors que chaque piste seule est forte :
1. vérifier timing/enveloppe ;
2. inverser polarité à titre de diagnostic ;
3. déplacer légèrement le timing seulement si musicalement acceptable ;
4. utiliser analyse/Phase si nécessaire ;
5. ne pas compenser automatiquement avec +6 dB de sub.

## Width
Créer la largeur au-dessus du fondamental : unison léger, chorus, microdelay, reverb, M/S saturation. Vérifier correlation/mono [TEST].
