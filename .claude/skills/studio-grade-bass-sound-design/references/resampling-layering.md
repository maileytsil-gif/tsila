# Resampling et layering

## Pourquoi resampler
[HEUR]
- figer un mouvement réussi ;
- éditer silence/attaque avec précision ;
- inverser, découper, repitcher ;
- réduire CPU ;
- éviter qu'une automation complexe dérive.

Serum 2 peut exporter la dernière note/accord vers la DAW par drag audio [DOC]. Ableton permet évidemment l'enregistrement/resampling interne [DOC].

## Règle de layering
Layer 1 = fonction principale. Ajouter Layer 2 seulement pour une fonction absente.

Exemples :
- SUB sine + MID growl ;
- SUB + donk attack ;
- MID reese + noise click ;
- clean bass + distorted parallel.

Éviter trois subs ou trois saws faisant le même travail.
