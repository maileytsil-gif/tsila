# Electronic Percussion Taxonomy

| Famille | Identité | Moteur typique | Paramètre musical clé |
|---|---|---|---|
| click/tick | impulsif, sec | Drum Sampler / Operator | placement |
| rim/clave | court, tonal | sample / DS Clang / Operator | pitch + decay |
| metallic | inharmonique | DS FM / Operator / Serum FM | ratios + decay |
| zap/laser | pitch gesture | Operator / Serum | pitch env |
| bleep | tonal court | Operator / Collision / Serum | scale degree |
| electro tom | tonal + pitch env | DS Tom / Operator / Serum | tune + decay |
| noise burst | non tonal | DS/Serum noise | filter + env |
| synthetic shaker | dense micro-events | noise/sample | pattern + velocity |
| glitch | fragmenté | resample/Granular | edit rhythm |
| granular tick | texture micro | Serum Granular | position/window |
| spectral hit | transformed | Serum Spectral | spectral motion |
| hybrid hit | sample+synth | Drum Sampler + synth | layer roles |

Ne pas confondre identité sonore et rôle de groove : un laser peut être un fill, un accent ou un hook rythmique selon son placement.
