# Layering, Phase & Stereo

## Layering
Maximum utile habituel : `TRANSIENT + BODY + TEXTURE + TAIL`.
Chaque layer doit apporter un attribut audible unique.

## Phase
Pour percussions courtes, le décalage de quelques samples peut modifier le peak et la sensation d'attaque. Vérifier mono/polarité et éviter d'aligner visuellement au détriment de l'écoute.

## Stereo
- transient principal : souvent stable/centré ;
- texture/tail : peut être plus large ;
- hats/percs hautes : largeur possible, mais vérifier corrélation ;
- tom grave : partie basse plus centrée.

## Règle
Si la largeur fait disparaître l'attaque en mono, réduire largeur ou séparer transient/body du tail.
