# Drum Bus Processing

## Avant le bus
Le pattern, les niveaux et les envelopes doivent déjà fonctionner.

## Chaîne courte `[HEUR]`
`corrective EQ if needed → saturation/color → glue/compression → optional clipper`.

## Ableton Drum Buss `[DOC]`
Conçu pour body/caractère/glue des groupes de drums. Tester Soft/Medium/Hard selon besoin. Ne pas activer Comp + Drive + autre compressor par défaut.

## Parallel bus
Pour agressivité Bass House/Techno, préférer souvent une parallèle saturée/écrasée mélangée sous le dry plutôt que détruire tous les transients du bus principal.

## Validation
- bypass level matched ;
- peak vs perceived loudness ;
- kick séparé si le bus le fait pomper ;
- mono ;
- vocal/hook présent.
