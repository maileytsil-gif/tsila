# Toms / Rims / Claves

## Tom
Sine/triangle avec pitch envelope court. Tuner le body lorsque clairement tonal. Garder le grave compatible avec l'ownership kick/bass.

## Rim/Clave
Impulsion courte + résonance/tonal body. DS Clang, sample, Operator ou Collision.

## Groove
Tech/Minimal: rims/claves peuvent jouer la syncopation principale. Bass House: utiliser plus parcimonieusement pour laisser le call-response de basse respirer.
