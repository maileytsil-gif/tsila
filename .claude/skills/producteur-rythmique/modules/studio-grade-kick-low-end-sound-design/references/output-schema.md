# Format de réponse du skill

## Cible
Style, BPM, tonalité, rôle du kick, modèle low-end (A/B/C/D).

## Patch source
Moteur, oscillateur/sample, pitch envelope, amplitude envelope, transient, phase/retrigger.

## Architecture
CLICK / PUNCH / BODY / SUB / SPACE avec fonction de chaque couche.

## Traitement
Pour chaque plugin : `nom → raison → réglage de départ [HEUR] → critère d'arrêt`.

## Intégration
Basse, ducking, phase, mono/stéréo, rumble éventuel.

## Validation
Solo, kick+basse, mix complet, mono, petits systèmes, A/B level-match.

## Incertitudes
Paramètres/réponses [TEST] à confirmer dans le vrai Set.
