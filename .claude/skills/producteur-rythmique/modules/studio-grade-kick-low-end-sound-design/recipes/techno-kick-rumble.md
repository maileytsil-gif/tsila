# Recipe — Techno kick + rumble [HEUR]

**Objectif :** kick sec central + fondation spatiale séparée.

## Kick sec
- Fundamental : 42–55 Hz.
- Pitch start : +12 à +36 st.
- Drop : 30–90 ms.
- Tail sec : 180–350 ms.

## Rumble séparé
1. Send/duplicate du kick.
2. ValhallaRoom / VintageVerb / Supermassive / ValhallaDelay à 100% wet.
3. Distortion : Roar, Trash, Saturn 2, J37 ou Supercharger GT selon texture.
4. Pro-Q 4 / EQ Eight : retirer ce qui masque le transient et sculpter le grave.
5. Pro-C 3 / Ableton Compressor sidechain depuis kick sec.
6. Utility : largeur/mono check.

Le rumble doit disparaître suffisamment sous le kick pour que chaque impact reste lisible.
