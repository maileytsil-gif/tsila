# Recipe — Minimal House 808-derived kick [HEUR]

**Objectif :** rond, profond, discret en haut, groove souple.

- Fundamental/tail : 45–55 Hz.
- Pitch start : +12 à +24 st.
- Pitch drop : 35–75 ms.
- Amp decay : 180–350 ms.
- Click : faible à modéré.
- Harmonics : légère saturation seulement si petits systèmes perdent le grave.

Chaîne courte suggérée :
`Serum 2/Operator → Saturn 2 ou Saturator léger → Pro-Q 4 → Utility`

Option Waves : R-Bass très léger si la traduction est insuffisante.

Validation : le tail doit soutenir le groove sans devenir une bassline concurrente.
