# Index des familles de sons — Serum 2 / Ableton Live 12

Utiliser cet index avant de construire un patch. Les recommandations sont un **choix d'architecture**, pas un classement absolu.

| Famille | Serum 2 — moteur de départ | Ableton — moteur de départ | Alternatives utiles |
|---|---|---|---|
| Synthé | Wavetable | Drift / Wavetable | Meld, Operator |
| Nappe | Granular / Wavetable | Granulator III / Meld | Wavetable, Rack |
| Drone | Granular / Spectral, tracking off si utile | Granulator III Cloud | Wavetable, Meld |

## Différence pad / nappe
- **Pad** : instrument harmonique jouable ; l'accord et la réponse au clavier priment.
- **Nappe** : couche d'ambiance/texture ; l'évolution et l'espace peuvent primer sur l'articulation instrumentale.

## Différence stab / pluck
- **Stab** : accent court, souvent accordal, conçu pour le groove.
- **Pluck** : articulation pincée, souvent mélodique, dont le decay/timbre reproduit une sensation de corde pincée ou équivalent synthétique.

## Différence riser / drone
- **Riser** : trajectoire dirigée vers un événement futur.
- **Drone** : état soutenu ; le mouvement interne n'implique pas nécessairement une destination.
