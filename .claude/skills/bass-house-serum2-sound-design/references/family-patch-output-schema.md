# Schéma de sortie d'un patch — v5

Quand ce skill conçoit un son, rendre les éléments suivants dans cet ordre :

1. **Famille** : synthé, nappe, drone, stab, riser, impact, pluck, pad ou keys.
2. **Sous-type** : nom v5 exact ou hybride clairement décrit.
3. **Fonction dans l'arrangement** : où, quand et avec quels éléments le son dialogue.
4. **Instrument/moteur** : Serum 2 ou device Ableton et raison du choix.
5. **Voix** : mono/poly, retrigger, glide/unison si utile.
6. **Sources/couches** : `CORE`, `BODY`, `ATTACK`, `AIR`, `TEXTURE`, `TAIL` selon nécessité ; oscillateurs/sample/grain/spectral + accordage relatif.
7. **Amplitude** : profil d'enveloppe.
8. **Timbre/routage** : filtre, routing, warp/FM/texture ; expliquer chaque voie.
9. **Mouvement** : enveloppes, LFO, automation et rôle de chacun.
10. **FX** : ordre et fonction ; distinguer coloration, espace et contrôle dynamique.
11. **Macros** : 4–8 contrôles d'intention avec plages musicales sûres.
12. **Test MIDI/audio** : phrase, longueur et contexte permettant de vérifier le patch.
13. **Risques** : phase, CPU, grave, résonance, queue, voice stealing, masking.
14. **[TEST] Bridge** : paramètres à découvrir dans Live avant exécution automatisée.

Les valeurs chiffrées non tirées d'une spécification officielle doivent être présentées comme **points de départ [HEUR]**.
