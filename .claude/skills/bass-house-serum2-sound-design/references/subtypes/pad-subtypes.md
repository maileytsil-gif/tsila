# Pad — sous-types professionnels v5

Le pad reste un **instrument harmonique jouable**. S'il devient surtout texture, utiliser la logique Nappe.

## 1. Warm analog pad
**Rôle** : accords doux, chaleureux, stables.

**Serum** : Wavetable formes simples, léger detune, LP, mouvements très lents.  
**Ableton [DOC]** : Analog ou Drift.  
**HEUR** : Attack 80 ms–2 s, Release 0.5–4 s ; modulation faible de pitch/filter.  
**Macros** : `WARMTH`, `TONE`, `ATTACK`, `RELEASE`, `WIDTH`, `SPACE`.  
**Test** : triades serrées et voicings ouverts ; éviter boue 200–500 Hz.

## 2. Airy pad
**Rôle** : soutien léger avec présence haute.

**Serum** : Wavetable CORE + Noise/AIR layer ; high-pass texture.  
**Ableton** : Wavetable + Chorus/Hybrid Reverb.  
**HEUR** : le core reste centré ; air plus large.  
**Macros** : `CORE↔AIR`, `TONE`, `WIDTH`, `SPACE`, `MOTION`.  
**Test** : mono ; accords toujours lisibles.

## 3. Digital evolving pad
**Rôle** : pad synthétique moderne, mouvement de table/matrice audible.

**Serum [DOC]** : Wavetable + LFO/ENV/macros.  
**Ableton [DOC]** : Wavetable ou Meld.  
**HEUR** : deux mouvements différents : lent global + per-note envelope subtile.  
**Macros** : `MORPH`, `MOTION`, `TONE`, `WIDTH`, `SPACE`.  
**Test** : 16 mesures ; éviter boucle LFO trop évidente.

## 4. Granular cinematic pad
**Rôle** : accord stable + texture de film.

**Serum** : Wavetable CORE + Granular TEXTURE.  
**Ableton [DOC]** : Instrument Rack : core + Granulator III ; Granulator III est adapté aux pads/textures.  
**HEUR** : texture -12 à -24 dB sous le core comme point de départ, puis ajuster à l'oreille.  
**Macros** : `TEXTURE`, `GRAIN`, `SIZE`, `MOTION`, `SPACE`.  
**Test** : mute texture ; l'accord doit rester suffisant.

## 5. Dark / dystopian pad
**Rôle** : tension sombre, dissonance contrôlée, ambiance techno/cinéma.

**Serum** : Spectral/Granular comme layer, filtres band/notch, micro-detune.  
**Ableton [DOC]** : Meld + Roar/Corpus possible.  
**HEUR** : introduire 1 élément d'instabilité à la fois (pitch, filter, distortion, intervalle).  
**Macros** : `DARKNESS`, `TENSION`, `GRIT`, `MOTION`, `SPACE`.  
**Test** : harmonie complète ; vérifier que les tensions ne créent pas une tonalité involontaire.

## 6. Vocal / formant-like pad
**Rôle** : sensation de voyelle/choeur synthétique sans exiger un sample vocal réaliste.

**Serum** : Wavetable/Spectral + filtres formant-like selon options disponibles ; noise/air discret.  
**Ableton** : Wavetable/Meld + Auto Filter Vowel en traitement [DOC].  
**HEUR** : morph lent entre deux zones de formant ; éviter resonance extrême.  
**Macros** : `VOWEL`, `AIR`, `TONE`, `MOTION`, `SPACE`.  
**Test** : notes hautes ; contrôler sifflantes/harshness.

## 7. Rhythmic/pulsed pad
**Rôle** : accord soutenu animé par une pulsation.

**Serum** : amp/filter LFO ou clip/automation selon besoin.  
**Ableton** : Wavetable/Meld + modulation Live.  
**HEUR** : profondeur <100 % pour garder sensation de pad ; si le signal tombe totalement à zéro et devient très court, il se rapproche d'un stab/gate.  
**Macros** : `PULSE`, `DEPTH`, `RATE`, `TONE`, `SPACE`.  
**Test** : groove avec kick ; ne pas confondre pulsation et sidechain externe.
