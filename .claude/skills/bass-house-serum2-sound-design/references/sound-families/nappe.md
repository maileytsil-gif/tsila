# Famille — Nappe / couche atmosphérique

## Fonction
Couche soutenue qui remplit l'espace, souvent plus texturale qu'un pad classique. Une nappe peut être tonalement floue, bruitée, granulaire ou spectrale et sert fréquemment à créer profondeur, continuité ou tension.

## Serum 2
- [DOC] **Granular** : les grains permettent d'étirer et recombiner un sample pour créer des textures évolutives et atmosphériques ; ce moteur peut être plus coûteux en CPU.
- [DOC] **Spectral** : utile pour resynthétiser un sample et dissocier certaines caractéristiques de temps/fréquence.
- [DOC] **Wavetable** : pertinent pour une nappe plus synthétique avec évolution de position dans la table.
- [DOC] Le routage permet d'envoyer les sources vers Filter 1/2, Main, Direct, None et vers les bus ; exploiter cela pour séparer une couche claire d'une couche traitée.

## Ableton Live 12
- [DOC] **Granulator III** : Ableton le décrit comme particulièrement adapté aux pads et textures ; le mode Cloud vise les drones/textures expérimentales.
- [DOC] **Meld** : deux couches/moteurs et modulation interne favorisent les textures complexes.
- [DOC] **Wavetable** : adapté aux timbres évolutifs.
- [DOC] **Instrument Rack** : chaînes parallèles et jusqu'à 16 macros permettent de réunir couche tonale, bruit/textures et espace.

## Profil de conception [HEUR]
- Attaque : généralement lente à moyenne ; relâchement long mais pas automatiquement gigantesque.
- Filtrer le grave de la composante diffuse afin de laisser le kick/sub respirer.
- Utiliser une modulation lente non parfaitement synchronisée pour éviter une boucle trop évidente.
- Combiner une couche définie et une couche diffuse plutôt que d'élargir tout le signal.
- La reverb doit renforcer la profondeur ; comparer toujours avec la queue coupée pour vérifier que le timbre de base fonctionne.

## Effets Ableton utiles [DOC → usage HEUR]
- **Chorus-Ensemble** : largeur/mouvement de couche.
- **Echo** : deux lignes de delay et modulation ; utile pour mouvement spatial.
- **Hybrid Reverb / Reverb** : profondeur et queue.
- **Auto Filter** : mouvement spectral via LFO/envelope follower.

## Macros [HEUR]
`DARK↔BRIGHT`, `MOTION`, `GRAIN`, `AIR`, `WIDTH`, `SPACE`, `DISTANCE`.

## Validation
Écouter seule puis sous kick/basse. Vérifier mono, grave sous 120–150 Hz, densité de queue et CPU. Si la nappe masque l'harmonie, réduire d'abord densité/sustain avant d'EQ excessivement.
