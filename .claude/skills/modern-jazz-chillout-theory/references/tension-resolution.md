# Tension → Resolution

## [DOC]
Berklee montre qu'une ligne peut mettre l'accent sur une tension puis la résoudre vers une note d'accord, et que la syncopation peut rendre cette ligne plus vivante. Source : https://www.berklee.edu/berklee-today/summer-2014/tension-and-resolution

## Application Jazz-Funk `[HEUR]`
- cible forte sur une subdivision faible ;
- approche chromatique juste avant la cible ;
- résolution parfois après la barre de mesure ;
- ne pas résoudre chaque tension immédiatement : varier le délai de résolution.

Schéma : `APPROACH → TENSION → TARGET → REST`.
