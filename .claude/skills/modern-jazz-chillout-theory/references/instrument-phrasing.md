# Instrument Phrasing

## Rhodes / piano électrique
- attaques moyennes, notes tenues ponctuelles ;
- stabs 2–4 notes ;
- voicing supérieur = mini-mélodie ;
- laid-back possible pour chill/neo-soul `[HEUR]`.

## Clav / guitare funk
Herbie Hancock décrit avoir joué le Clavinet rythmiquement, comme une guitare, sur Head Hunters. Source : https://www.herbiehancock.com/music/discography/album/head-hunters/
- articulation courte ;
- 16e et ghost articulations ;
- motif répétitif avec micro-variations.

## Bass
- motif répétitif ;
- chromatic approach vers root/3/5 ;
- notes mortes/ghost ;
- variations de fin de 2e/4e mesure.

## Horn / synth brass
- attaques communes ;
- phrase courte ;
- intervalles 4e/5e/6e efficaces ;
- silence après accent principal.

## Synth lead
- moins de notes, plus de bend/filter expression ;
- réutiliser la même cellule rythmique sur plusieurs degrés.
