# Chromatic Approaches & Enclosures

## [DOC]
Le cursus d'improvisation Berklee traite approches chromatiques simples, doubles et résolution vers chord tones/chord-scale motifs. Source : https://online.berklee.edu/courses/basic-improvisation

## Vocabulaire `[HEUR]`
Pour une cible T :
- below → T ;
- above → T ;
- above, below → T ;
- below, above → T ;
- diatonic neighbor + chromatic neighbor → T.

## Jazz-Funk
Utiliser surtout en pickup ou fin de cellule. Éviter 8 notes chromatiques d'affilée si le groove n'est pas déjà clair.
