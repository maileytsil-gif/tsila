# Jazz-Funk Rhythm Grid

## Matrice de départ `[HEUR]`
- grille : 1/16 ;
- densité lead : 4–9 attaques par mesure selon tempo ;
- notes longues : 1–3 points d'ancrage ;
- ghost notes : vélocité et longueur réduites ;
- pickups : dernière 16e ou dernier 1/8 avant un accord/phrase ;
- accents : ne pas suivre automatiquement les temps forts.

## Exercices
1. Une seule note, 8 cellules rythmiques différentes.
2. Trois notes pentatoniques, même cellule pendant 4 mesures.
3. Déplacer la cellule d'une 16e à chaque répétition.
4. Enlever toutes les notes sur beat 1 pendant 4 mesures.
5. Construire une réponse qui ne commence qu'après le beat 2.
