# Recipe — Chill-Out / Downtempo

`[HEUR]`
- 65–105 BPM ;
- 2–4 accords maximum sur 4–8 mesures ;
- maj7/9, m7/9, 6/9, sus/add9 ;
- basse simple/pédale ;
- Rhodes/pad avec voice leading ;
- mélodie rare, longue respiration ;
- percussions feutrées ;
- automation de texture plutôt que multiplication de notes.
