# Modern Jazz / Chill-Out / Jazz-Funk Theory — v16

Ce skill sert lorsque le brief demande : **jazz moderne, jazz-funk, neo-soul, chill-out, downtempo, broken beat, fusion, Rhodes sophistiqué, accords riches, phrasé funky ou improvisation contrôlée**.

## Hiérarchie de preuve
- `[DOC]` : concept ou fonction documenté par Berklee/Ableton ou une source de référence.
- `[ATTRIB]` : approche explicitement décrite par un musicien dans une interview.
- `[ANALYSIS]` : synthèse analytique du corpus.
- `[HEUR]` : règle de travail proposée.
- `[TEST]` : à valider par écoute/jeu réel.

## Pipeline obligatoire

### 1. Verrouiller le langage harmonique
Choisir 1–2 axes maximum :
- `EXTENDED_TERTIAN` : maj7, m7, 9, 11, 13 ;
- `QUARTAL_MODAL` : empilements de quartes, modalité ;
- `UPPER_STRUCTURE` : triades supérieures sur dominante/accord étendu ;
- `NEO_SOUL_VOICE_LEADING` : guide tones, inversions, notes communes ;
- `STATIC_MODAL` : pédale + couleurs Dorian/Mixolydian/Lydian ;
- `CHROMATIC_COLOR` : accords d'approche, passing chords, tensions résolues.

Lire `references/harmony-core.md`, `modern-voicings.md` et `voice-leading.md`.

### 2. Choisir le time-feel avant les notes
Pour Jazz-Funk et Chill, définir :
- grille dominante : 8e / 16e / triplet / broken ;
- centre du temps : `ON_TOP`, `CENTER`, `LAID_BACK` ;
- subdivision et swing ;
- rôle des silences ;
- rapport kick/snare/bass/keys.

Lire `references/jazz-funk-phrasing.md` et `laid-back-microtiming.md`.

### 3. Construire le phrasé Jazz-Funk
Ordre :
`RHYTHMIC CELL → RESTS → ACCENTS → NOTE SET → CHROMATIC APPROACH → ARTICULATION → VARIATION`.

Le phrasé ne doit pas être une gamme continue. Partir d'une cellule rythmique de 1/2 à 2 mesures, souvent sur grille de doubles-croches `[HEUR]`, puis déplacer/contracter/étendre le motif.

### 4. Palette de notes
Base :
- pentatonique majeure/mineure ;
- blues note ;
- chord tones + tensions disponibles ;
- Dorian/Mixolydian/Lydian selon l'harmonie ;
- approches chromatiques simples/doubles ;
- enclosures autour d'une note cible.

Ne pas chromatiser au hasard : la note cible doit rester claire.

### 5. Phrasé par instrument
Lire `references/instrument-phrasing.md`.
- **Rhodes/keys** : stabs syncopés, dyades/voicings courts, réponses de 2–5 notes.
- **Synth lead** : motif court, pitch/velocity expressifs, espace entre phrases.
- **Bass** : répétition + variations, anticipations, ghost notes, approches chromatiques.
- **Horn-like** : attaques franches, appels courts, accents communs, réponses.
- **Guitar/clav** : subdivisions 16e, notes étouffées/ghost, attaques courtes.

### 6. Harmonie moderne et chill-out
Pour Chill/Downtempo : privilégier `[HEUR]` :
- voix supérieures lentes ;
- basses simples/pédales ;
- maj7/9, m7/9, sus2/4, add9, 6/9 ;
- mouvement interne minimal ;
- ambiguïté modale contrôlée ;
- espace entre changements d'accords.

Lire `references/chillout-harmony.md` et `chillout-melody-space.md`.

### 7. Ableton Live workflow
Lire `references/ableton-live-workflow.md`.
- Groove Pool pour tester le feel sur MIDI/audio warpé `[DOC]` ;
- Humanize de Live 12 seulement comme variation légère, jamais comme substitut au placement intentionnel `[DOC+HEUR]` ;
- séparer timing des notes, vélocité, longueur et articulation ;
- créer 3 versions : `TIGHT`, `POCKET`, `LOOSE`, puis A/B à volume égal.

### 8. Validation
Le résultat doit répondre oui à :
- peut-on reconnaître le motif sans l'harmonie ?
- la phrase respire-t-elle ?
- les accents donnent-ils le groove ?
- les chromatismes résolvent-ils vers une cible ?
- le comping laisse-t-il de l'espace à la basse et au lead ?
- le laid-back reste-t-il cohérent avec le downbeat ?
- l'accord riche sonne-t-il mieux qu'une triade simple dans ce contexte ?

## Règle d'originalité
Les artistes du corpus servent à comprendre **feel, harmonie, espace, hook et groove**. Ne jamais transcrire/reproduire un solo, riff ou voicing propriétaire comme sortie par défaut.
