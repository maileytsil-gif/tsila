## 1. Structures types

### 1.1 Versions club (extended) `[HEUR, appuyé sur les fiches citées ; minutes calculées, pas mesurées]`

| Genre (BPM) | Grille en mesures | Total | Durée |
|---|---|---|---|
| **Future rave** (126–128) | intro 32 · break 1 (thème filtré, accords) 16 · build 16 · **drop 1** 32 · breakdown 32 (nappe, voix, lead exposé) · build 16 · **drop 2** 32 (+1 couche) · outro 32 | 208 | 6:30 à 128 ; longueurs propres au genre `[NON VÉRIFIÉ]` |
| **Bass house** (126–128) | intro 16 · intro B 16 · build 16 · **drop 1** 32 · breakdown 16 · build 16 · **drop 2** 32 · outro 16 | 160 | 5:00 à 128 |
| **Tech house** (125–127) | intro 16–32 · loop A 32 · build 8 · **drop A** 32 · break 8–16 · **drop B** 32–64 · outro 16–32 | 160–208 | 5:00–6:30 à 126 |
| **Future house** (124–128) | intro 16 · build 16 · **drop 1** 32 · breakdown 16 · build 16 · **drop 2** 32 · outro 16 | 144 | 4:30 à 128 |
| **Big room** (128–130) | intro 8–16 · thème 16 · build 16 · **drop A** 32 · breakdown 16 · build 16 · **drop B** 32 · outro 8–16 | 144–160 | 4:30–5:00 |
| **House de club** (122–126) | drums 16 · +basse 16 · +accords 16 · +voix 16 · breakdown 16 · build 16 · main 64 · reduced 24 · outro 16 | 200 | 6:27 à 124 ; **additif, sans drop** |

Règles transversales `[DOC amen]` : chaque frontière sur un multiple de 8 depuis la mesure 1 (16 de préférence) ; intro et outro sans contenu plein spectre pour laisser la place à l'autre disque ; le sommet entre 60 et 75 % de la durée ; le point le plus bas juste avant le plus haut.

### 1.2 Versions radio et streaming (2:30–3:30)

- Intro 4–8 mesures, pas de build initial, premier drop avant 45 s à 1:00, outro court ; **mêmes blocs internes** que le club mix `[DOC Harmonix : Memories, Feel So Close, Take Over Control]`.
- Grille type à 128 : intro 4–8 · thème 16 · build 8 · **drop 1** 16–32 (m. 29–37, soit 0:52–1:08) · break 16 · build 8 · **drop 2** 32 · outro 4 → 104–112 mesures ≈ 3:15–3:30. Pour un drop avant 45 s : intro 4 + thème 8 + build 8 = 20 mesures = 37,5 s `[HEUR]`.
- Bass house festival : intro 8 · build 16 · drop A 16–32 · mini-break 4–8 · drop B 16–32 · outro 8 → 3–4 min `[DOC JefroB]`.
- Pourquoi : le streaming récompense les titres courts mais pénalise un démarrage lent `[DOC-EXTRAIT]`.

| **Everytime We Touch** (129, 4:50) | intro 8 · chorus 16 · verse 16 · chorus 16 · inst 16 · verse 16 · chorus 16 · inst 16 · breakdown 8 · inst 16 · outro 12 | Version club : drops instrumentaux de 16, breakdown de 8 avant le dernier drop |
| SHM **Don't You Worry Child** (130, 3:30) | … prechorus 8 · **chorus 8 à 0:52** · inst 8 · … | Refrain chanté 8 + drop instrumental 8 : la cellule de 16 mesures de la house de festival vocale |

Procédure pour obtenir un minutage sans l'inventer : audio de référence dans la piste REF, warp au BPM annoncé, un repère par changement (`lom.py locator`), puis `arrangement_map.py`.

## 2. Dispositifs

### 2.1 Build

| Dispositif | Recette | Source |
|---|---|---|
| Longueur | 8 normal, **16** pour le drop principal en festival et bass house, 8 pour le second, 4 pour un reset ; tech house : breakdown + build = 8 au total | `[DOC amen, Fearvox, JefroB ; DOC-EXTRAIT EDMProd]` |
| Empiler au moins quatre dimensions | densité rythmique (snare roll 1/8 × 4 mesures → 1/16 × 2 → 1/32 × 1 → 1/64 sur le dernier temps), hauteur (riser bruit passe-bande 200 Hz → 8 kHz, ou ligne d'une octave), volume, registre (**passe-haut du mix jusqu'à 400–800 Hz sur les 4 dernières mesures : la basse disparaît**), harmonie (V, ♭VI ou sus tenu), espace (reverb et delay qui montent puis coupés net), stéréo (rétrécir avant le drop), timbre ; « ne monter que le volume ne produit rien » | `[DOC amen]` |
| Hats accélérés | m. 33–36 croches ; 37–40 doubles ; 41–43 doubles + ratchets ; 44 roll 1/32 → crash | `[DOC Fearvox]` |
| Kick retiré | 4–8 mesures avant le drop, ne garder que basse filtrée, nappes, riser | `[DOC Fearvox]` |
| Voix | chops en appel-réponse (bass house) ; fragment seul dans le gap | `[DOC bitwize, amen]` |
| Accord suspendu | sus4 sur les deux derniers temps, résolu au drop | `[DOC Fearvox]` |
| **Le gap** | 1/16–1/8 = stutter ; **1 temps = standard** ; 2 temps = dramatique ; 1 mesure = très dramatique ; contenu : rien, queue de reverb, fragment vocal, sub-drop (sinus 80 → 25 Hz), downlifter, tape-stop ; deux vrais silences par morceau, pas plus | `[DOC amen]` |
| Premier temps du drop | impact (kick + bruit + reverb inversée) + crash + sub-drop + mix complet, sur le même échantillon | `[DOC amen]` |

### 2.2 Drop

- **Couches** : big room = kick + sub + un motif de lead ; bass house = « la basse est le lead », drop dépouillé à kick + basse ; future house = basse FM + chops ; future rave = lead + basse roulante + stabs, trois couches actives. Le drop est souvent **plus vide** que le build : le contraste vient du retour du grave et du timbre, pas de la densité `[DOC amen, bitwize, Fearvox]`. Six à dix éléments simultanés, jamais plus `[DOC amen]`.
- **Toutes les 8 mesures** : deux mesures d'appel, deux de réponse, escalade aux mesures 13–16 ; « changer quelque chose toutes les 4 » ; bass house : une variation de 2 mesures toutes les 8 ; la mesure 16 ou 32 finit par un fill ou une coupure.
- **Drop 2** dépasse le premier **sans être plus fort** : +1 élément, +1–2 demi-tons, lead à l'octave, autre motif de batterie, contre-mélodie, image plus large, voix, ou un breakdown précédent plus petit ; bass house : nouveau lead, couche de percussion ou hook vocal ; « le contraste doit être timbral, pas de niveau » `[DOC amen, Fearvox]`.
- Variantes : halftime drop, empty drop (sub + hat), false drop (résolution calme puis vrai drop 8 mesures plus tard), double drop, switch-up, vocal drop `[DOC amen]`. Guetta pop-EDM : drop instrumental de **8 mesures** après un refrain chanté de 16 `[DOC Harmonix]`.
- Échecs : pas de gap ; seul le volume monte ; build plus dense que le drop (amincir les médiums du build, grossir le grave du drop) ; drop 2 identique ; tout à 10 (baisser les autres sections de 6 dB et plus).

### 2.3 Breakdown

Batterie retirée ou pulsation douce, mélodie ou voix exposée avec reverb, **nouvelle matière harmonique ou réharmonisation**, **−6 à −10 LU sous le drop**, 16–32 mesures en dance, 8–16 en pop ; tech house : 8 (à 16) ; bass house : 8–16, fonctionnel `[DOC amen, JefroB, Fearvox]`. Sidechain aussi sur les nappes (« tout le morceau respire ») ; sans kick, garder le pompage par un **kick fantôme** muet qui déclenche le sidechain `[HEUR]`. Réglages « standard house pump » : seuil −20 dB, 6:1, attaque 0,5–1 ms, release 150–200 ms ; « hard bass house pump » : 8:1 à 10:1, release 100–150 ms `[DOC Fearvox]`. Le breakdown est un **événement de médiums** : ôter le sub et l'extrême aigu, leur retour est la récompense ; on ne peut pas ouvrir une bande qu'on n'a jamais fermée.

### 2.4 Transitions `[DOC amen]`

Riser 1–8 mesures · downlifter 1–2 mesures au **début** de la nouvelle section · impact sur le un · sub-drop 1–2 temps · cymbale inversée · reverb inversée · snare roll 1–4 · balayage de filtre 4–32 · silence 1–2 temps (« le plus fort ») · tape stop · rewind · stutter · coupure de batterie 1 mesure · crash + kick · ad-lib vocal · delay throw · montée de bruit blanc · pitch bend du mix · gate de la dernière mesure. Transition composée type : filtre 8 + roll 4 + riser 2 + silence 1 temps + impact + crash + sub-drop + mix complet ; « trois à cinq dispositifs par couture est normal ». Filtre à automatiser **sur un bus**, pas piste par piste (`../../live-automation/SKILL.md`).

### 2.5 Section × élément (bass house et future rave, club, 160 mesures à 128) `[HEUR d'après Fearvox et amen]`

| Élément | Intro A m1–16 | Intro B m17–32 | Build 1 m33–48 | **Drop 1** m49–80 | Breakdown m81–96 | Build 2 m97–112 | **Drop 2** m113–144 | Outro m145–160 |
|---|---|---|---|---|---|---|---|---|
| Kick | filtré | ✅ | ✅ puis retiré 4–8 mes. | ✅ | ❌ (ou pulsation) | ✅ puis retiré | ✅ | ✅, seul à la fin |
| Hats | croches dès m1, open m9 | ✅ | 1/8 → 1/16 → 1/32 | ✅ constants | ❌ | accélération | ✅ | puis ❌ |
| Clap / snare | ❌ | m17 | ✅ + roll | ✅ | ❌ | ✅ + roll | ✅ | ✅ |
| Percussions | ❌ | m25 | ✅ | ✅ (+1 couche à m65) | ❌ | ✅ | ✅ (+1) | ♻ |
| Sub | ❌ | ❌ | ❌ (passe-haut) | ✅ mono | ❌ | ❌ | ✅ | ❌ |
| Basse mid | ❌ | filtrée < 300 Hz | ♻ | ✅ **le hook**, variation 2 mes. / 8 | ❌ | ♻ | ✅ variante | ❌ |
| Accords / nappe / stab | ❌ | ❌ | filtré | ✅ | ✅ exposé, reverb, sidechain fantôme | ♻ | ✅ | ❌ |
| Lead | ❌ | ❌ | ❌ | ✅ | mélodie seule | ❌ | ✅ + contre-mélodie ou +12 | ❌ |

| Filtre de bus | LP fermé qui s'ouvre sur 16 | ouvert | HP 20 → 500–800 Hz sur 4 mes. | HP → 20 Hz en 1 mes. | HP léger | HP montant | plein | LP qui se ferme sur 16 |

**Test de soustraction** : à chaque bloc de 8, au moins un élément du bloc précédent disparaît `[DOC amen]`. Courbe d'énergie en pourcentage à tracer **avant** d'écrire : intro 20–30 · thème 30–40 · build 40 → 90 · drop 100 → 85 · thème 2 35–50 · build 2 50 → 95 · drop 2 100 · outro 50 → 0 `[DOC Resource2Skill]`. Grille spectrale : le sub (20–60 Hz) absent en intro, build et breakdown, présent au drop ; 6–12 kHz absent en intro et outro ; « si les hats sont à pleine brillance dès la mesure 1, le refrain n'a plus de montée disponible » `[DOC amen]`.

## 3. Méthode professionnelle, calée sur les huit étapes de l'utilisateur

| Étape | Ce que font les pros | Source |
|---|---|---|
| 1 Cadre : Sauver sous, tempo, tonalité, **structure avec repères** | Référence au même tempo, compter les mesures de chaque section, noter tous les 8 mesures quels éléments jouent ; blocs vides nommés et **courbe d'énergie dessinée** avant toute note ; « écrire la section la plus forte en premier » | `[DOC-EXTRAIT Sounds of Ibiza ; DOC R2S, amen]` |
| 2 Instruments : kick, basse, lead | Chris Lake commence par le grave, en tirant kicks et basses d'autres projets avant de réécrire ; « groove, puis basse, puis harmonie, puis mélodie, puis FX » ; « la relation kick-basse **est** le mix » | `[DOC-EXTRAIT MusicRadar ; DOC amen]` |
| 3 Passage central de 8 mesures | **Composer le drop d'abord**, puis dériver chaque section par soustraction ; copier la boucle de 8 sur les drops puis remonter vers l'intro en retirant | `[DOC-EXTRAIT EDMProd, PML ; DOC amen]` |
| 4 Arrangement | Neuf points : tempo, tonalité, longueur → courbe par 8 → sections sur multiples de 8 → boucle du drop → soustraction → une section vraiment contrastante → transitions à chaque couture → test de soustraction → quelque chose change toutes les 8, quelque chose de gros toutes les 16 ou 32 | `[DOC amen]` |
| 5 Mix | Après l'arrangement (« les problèmes spectraux sont presque toujours des problèmes d'arrangement ») ; référence à niveau égal ; Garrix mixe et masterise 98 % de ses sorties lui-même, ne délègue que s'il bloque « plutôt sur le son que sur le mixdown » | `[DOC amen ; DOC-EXTRAIT SOS]` |
| 6 Automations | « Automate inside notes, not only between them » ; « ça sonne amateur mais rien n'est faux → automatiser quelque chose » ; filtre sur bus | `[DOC amen]` |
| 7 Voix | Future rave : voix « meticulously placed » ; LUCKY (Guetta & MORTEN, 2025) : texte écrit avec une IA ; bass house : la voix est un élément de production de 1–4 mesures verrouillé sur kick et basse | `[DOC-EXTRAIT ; DOC bitwize]` |
| 8 Export, livraison | § 4 | |

**Finir.** Garrix : « finishing tracks is a challenge » ; une fois que le label valide, il passe en « finishing mode » ; beaucoup de titres jamais sortis parce que finir prend du temps `[DOC-EXTRAIT]`. Guetta sur le duo : « Morten came with this sound… I have more experience in making chords and melodies and structuring records » `[DOC-EXTRAIT]`. Chris Lake : autodidacte sur portable, « I've released music that I've only monitored on laptop speakers » `[DOC-EXTRAIT]`. Garder des banques de kicks et de basses de projets précédents (`../../drums-signature/SKILL.md`).

**Pièges compilés** `[DOC amen, bitwize, Fearvox]` : accumulation sans soustraction ; build qui ne monte que le volume ; drop plus dense mais pas différent ; second drop identique ; 90 s d'intro en streaming ; spectre plein dès la mesure 1 ; sub en breakdown ; riser partout ; queues de reverb sur le drop ; transitions hors grille ; plus de dix éléments ; supersaws à cinq notes (trois suffisent) ; juger sans égaliser les niveaux ; mixer fatigué ; en house de club, une structure build/drop est de l'EDM ; bass house : « too much going on ».

## 4. Livraison

| Version | Contenu | Longueur |
|---|---|---|
| **Original / club mix** (extended) | intro et outro DJ 16–32 (bass house 16), deux drops, breakdown complet | 4:30–6:30 ; tech house jusqu'à 8 |
| **Radio edit** | intro 4–8, pas de build initial, premier drop < 45 s–1:00, outro court, mêmes blocs internes | 2:30–3:30 |
| **Extended depuis un radio edit** | intro 16 et outro 32–48 en soustraction ; parfois un drop instrumental ajouté après chaque refrain | +1:00 à +3:30 |
| **Instrumental** | sans voix, mêmes automations | = original |
| **Acapella** | voix seule, sèche et avec effets | |
| **Stems** | drums, bass, music, FX, vocals ; **depuis la mesure 1** ; 24 bits, même fréquence ; nommage `Artist_Title_Version_BPM_Key_Date` ; « quand un label demande un intro plus court ou un vocal-up, les stems rendent la demande gérable » `[DOC-EXTRAIT]` | = original |
| **Premaster** | crête ≈ −6 dBFS, sans limiteur | |
| Contrôles avant envoi | mono, téléphone, bas volume, sub mono, ≤ −1 dBTP, A/B à niveau égal, intro et outro adaptés à la destination | |

Dans Live : Sauver sous **avant** toute modification ; un repère par section plus « FIN export » ; un seul Set avec deux zones d'export plutôt que deux Sets, pour garder les automations alignées `[HEUR]` ; radio edit depuis le club mix par Edition › Sélectionner boucle → Supprimer Zone temporelle (clips, automations et repères se déplacent ensemble), puis `arrangement_map.py` et « FIN export » recalé ; extended depuis un radio edit par Créer › Insérer Silence puis duplication des clips voisins ; stems par Exporter Audio, « toutes les pistes individuelles », ou par les bus `BUS - …` pour les cinq stems groupés ; historique dans `memoire-projet`.

## 5. Contradictions, et ce que le skill décide

1. **House avec ou sans drop** : la house de club est additive, la house de festival, la bass house, la future house et la future rave sont en build/drop. Demander la cible avant de choisir le schéma.
2. **Longueur du build** : 8 en tech house, 16 en festival et bass house pour le premier, 8 pour le second.
3. **Silence avant le drop** : distinguer « kick retiré » (4–8 mesures) et « gap » (1–2 temps).
4. **Drop 2 plus long** : radio, même longueur ; club, il peut s'allonger (48 contre 32 chez amen).
5. **Intro DJ** : 16 (bass house, future rave, Harmonix extended), 32 (tech house), jamais 64 sauf DJ tool demandé.
6. **Durée bass house** : 3:30–5:00 streaming, 5–7 DJ.
7. **Étiquettes Harmonix** : un « chorus » est un refrain chanté, un « inst » est un drop ; ne pas compter un chorus comme un drop sans écouter.
