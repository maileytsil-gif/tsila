# Carte documentaire — Composition

Cette carte montre comment les sources sont réellement utilisées par le skill.

| Règle du skill | Type | Source officielle | Utilisation |
|---|---|---|---|
| Décrire une référence par attributs plutôt que la transcrire | DOC | Ableton *Catalog of Attributes* | Originalité et analyse structurée |
| Écouter par couches et par courts segments | DOC | Ableton *Active Listening* | Séparer sound/harmony/melody/rhythm/form |
| Créer des variations par modifications successives | DOC | *Creating Variation 2* | Développer un motif sans perdre l'identité |
| Utiliser silence/bruit comme matériau | DOC | *Silence and Noise* | Tension, impacts, respiration |
| Construire une trajectoire d'énergie | DOC | *Dramatic Arc* | Organisation du morceau |
| Employer événements ponctuels avec parcimonie | DOC | *Unique Events* | Fills, impacts et signatures |
| Construire par soustraction | DOC | *Arranging as a Subtractive Process* | Intro, break, outro à partir du noyau |
| Distinguer Transform et Generate | DOC | Live 12 MIDI Tools | Utilisation sûre des outils MIDI |
| Bassline = fonction harmonique + motif rythmique | DOC | Ableton Learning Music | Priorité au rythme et relation aux drums |
| Drop 4–8, sections 8/16/32, call-and-response Bass House | HEUR | Pratique de production | Point de départ, jamais vérité officielle |
