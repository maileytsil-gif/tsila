# Composition du drop électronique

## Le drop comme payoff

[HEUR] Considérer le drop comme un **refrain instrumental**. Il doit répondre à trois questions :
1. Quel est le hook ?
2. Quel est le groove ?
3. Quel contraste le rend satisfaisant après le build/break ?

## Architecture minimale

- kick ;
- bass/sub ;
- hook principal ;
- réponse ou variation ;
- percussion/air ;
- espace négatif.

## Call-and-response

[ANALYSIS] Dans Bass House, la phrase peut être répartie entre plusieurs timbres. La composition ne se limite alors pas à la hauteur : articulation, silence et timbre font partie de la syntaxe.

Créer d'abord un dialogue A/B en rythme sur une seule hauteur. Ensuite :
- changer registre ;
- changer timbre ;
- modifier une note cible ;
- ajouter pitch bend ou automation.

## Build → drop

Tension possible :
- registre ascendant ;
- valeurs plus courtes ;
- subdivision accélérée ;
- réduction de sub ;
- suspension harmonique ;
- note pédale ;
- silence juste avant impact.

Le drop peut résoudre par **retour du bas**, non nécessairement par accord de tonique.
