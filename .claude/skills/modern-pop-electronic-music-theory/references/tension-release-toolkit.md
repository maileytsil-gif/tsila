# Toolkit tension / release

## Harmonie
- dominante ou accord instable ;
- suspension ;
- pédale ;
- note étrangère contrôlée ;
- retard de résolution.

## Mélodie
- montée de registre ;
- répétition insistante ;
- note de tension tenue ;
- saut plus large ;
- densification rythmique.

## Rythme
- subdivisions plus rapides ;
- anticipation ;
- fill ;
- suppression du kick ;
- silence.

## Arrangement
- retirer le sub ;
- réduire le spectre puis le rouvrir ;
- réduire la largeur puis l'élargir ;
- passer d'un élément sec à une queue longue puis couper avant impact.

## Principe

[HEUR] Le release doit résoudre **au moins un** axe de tension. Il n'a pas besoin de tout résoudre. Une progression peut rester suspendue tandis que le rythme et le low-end fournissent le payoff.
