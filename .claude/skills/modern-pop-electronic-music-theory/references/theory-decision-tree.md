# Theory decision tree

## Si le morceau semble plat
1. Le hook est-il mémorisable sans FX ? Sinon → `melody-hook-design.md`.
2. Le chorus/drop possède-t-il un nouveau registre ou une nouvelle densité ? Sinon → `song-form-energy.md`.
3. Le voice leading est-il trop statique ou trop sautillant ? → `voice-leading-inversions.md`.
4. La bassline crée-t-elle un contre-rythme ? → `bassline-harmony-counterpoint.md`.
5. Le rythme harmonique change-t-il trop peu ou trop ? → `rhythm-groove-harmonic-rhythm.md`.

## Si la progression semble banale
Ne pas changer immédiatement les accords. Tester dans cet ordre :
1. inversions ;
2. bass note différente ;
3. note commune/pédale ;
4. extension add9/sus ;
5. rythme harmonique ;
6. seulement ensuite substitution ou emprunt modal.

## Si la mélodie semble aléatoire
1. réduire à 2–5 notes ;
2. définir une cellule rythmique ;
3. fixer une note cible ;
4. créer répétition + variation ;
5. réserver une note haute pour le payoff.

## Si le drop manque d'impact
1. vérifier le contraste avec le build ;
2. supprimer un élément avant impact ;
3. clarifier le hook A/B ;
4. vérifier que le low-end revient réellement ;
5. modifier la composition avant de pousser le limiter.
