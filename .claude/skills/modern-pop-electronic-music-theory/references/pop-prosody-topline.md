# Topline, prosodie et relation texte/mélodie

[DOC] Berklee enseigne la prosodie comme l'alignement entre intention, paroles, mélodie et harmonie. Le contour et le rythme mélodiques peuvent soutenir la narration émotionnelle.

## Même sans écrire les paroles

Le skill doit réserver :
- place respiratoire ;
- valeurs longues pour mots importants ;
- accents mélodiques sur syllabes importantes ;
- répétitions adaptées au hook.

## Topline instrumental

Les mêmes principes s'appliquent à un lead synth :
- accents = notes structurantes ;
- syllabes = attaques/articulations ;
- respiration = silences ;
- prosodie = cohérence entre contour et émotion.

## Pré-chorus

[HEUR] Pour créer un lift :
- monter progressivement le centre du registre ;
- raccourcir les respirations ;
- accélérer le rythme harmonique ;
- repousser la résolution ;
- garder une note culminante pour le chorus.

Ne pas appliquer tous les leviers en même temps par défaut.
