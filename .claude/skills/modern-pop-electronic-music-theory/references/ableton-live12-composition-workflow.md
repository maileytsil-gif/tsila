# Ableton Live 12 — workflow de composition

## Scale Mode

[DOC] Une gamme peut être définie pour un clip. Live 12 peut alors afficher/folder la gamme et transmettre cette information à des MIDI devices/instruments scale-aware.

## Transformations vs Generators

[DOC]
- **Transformations** : modifient du MIDI existant.
- **Generators** : créent du nouveau matériau.
- avec Scale Mode, les paramètres de pitch peuvent utiliser les degrés de la gamme.

## Workflow recommandé

1. définir tonalité + Scale Mode ;
2. écrire une progression simple manuellement ;
3. utiliser Chord/Scale pour tester voicings, pas pour décider l'émotion à votre place ;
4. enregistrer/figer le résultat MIDI si besoin d'édition note par note ;
5. créer 3 variations avec Transformations ;
6. sélectionner à l'écoute ;
7. créer bassline indépendante ;
8. créer hook ;
9. arranger en blocs fonctionnels ;
10. seulement ensuite enrichir avec sound design.

## Outils utiles

- Chord : intervalles/accords à partir de notes ;
- Scale : remapping vers une gamme ;
- Arpeggiator : distribution rythmique des notes ;
- Pitch/Random : variations, avec prudence ;
- MIDI Transformations/Generators : exploration contrôlée.

[TEST] Tout MIDI généré doit être considéré comme matière première. Le skill doit pouvoir expliquer pourquoi les notes conservées servent la chanson.
