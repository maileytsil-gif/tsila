# Forme & trajectoire d'énergie

[DOC] Ableton décrit la forme comme l'assemblage de motifs en sections, souvent groupés en multiples de 4, 8 ou 16 mesures selon les genres.

## Pop

Fonctions typiques :
- intro : établir monde/identité ;
- verse : information et retenue ;
- pre-chorus : accélération/tension ;
- chorus : payoff/hook central ;
- post-chorus : hook résiduel ;
- bridge : rupture / nouvelle perspective ;
- final chorus : retour amplifié ou transformé.

## Electro/House

- intro DJ ;
- groove/verse ;
- break ;
- build ;
- drop ;
- variation/drop B ;
- outro.

## Carte d'énergie

Attribuer 0–10 à chaque section sur :
- densité rythmique ;
- densité harmonique ;
- registre ;
- largeur ;
- sub ;
- activité mélodique ;
- tension.

[HEUR] Le build n'a pas besoin de monter sur tous les axes. Un axe peut augmenter tandis qu'un autre diminue pour laisser de la marge au drop.
