# Controlled variation matrix

When the user asks for alternatives, do not return unrelated ideas. Keep a seed and vary one axis at a time.

| Axis | Low change | Medium change | High change |
|---|---|---|---|
| Harmony | inversion | one chord substitute | modal/borrowed reframe |
| Rhythm | note length | anticipation/syncopation | new cell |
| Melody | ending note | contour change | new motif |
| Bass | octave | approach note | hook bassline |
| Register | ± octave one voice | new top note | repartition layers |
| Color | add9/sus | 7th/omit 5th | pedal/upper structure |
| Form | repeat | 4th-bar variation | new B phrase |

Default delivery for four variants:
- **A — safest**: same harmony, better voice leading.
- **B — more emotional**: one color/borrowed change.
- **C — more club**: simpler harmony, stronger bass rhythm.
- **D — more distinctive**: altered top-line rhythm or pedal strategy.
