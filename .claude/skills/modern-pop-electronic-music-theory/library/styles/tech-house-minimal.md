# Minimal / Tech House — progression / melody / voicing library

**Canonical example key:** G Dorian  
**Starter BPM:** 126 [HEUR]  
**Primary function:** Groove-first; one/two-chord modal vamps, bass rhythm more important than harmonic density.

## Progression seeds [HEUR]

- **i–IV** → `Gm – C` — Dorian color via major IV.
- **i–♭VII** → `Gm – F` — minimal modal loop.
- **i pedal** → `Gm` — single-chord vamp; variation via voicing/filter/bass.
- **i–IV–i–♭VII** → `Gm – C – Gm – F` — slightly wider Dorian loop.
- **i–ii** → `Gm – Am` — Dorian step movement; use sparse voicings.
- **i–v** → `Gm – Dm` — neutral minor frame.

## Canonical MIDI starter

The included clips are original templates, not track transcriptions.

- `chords.mid` — four-bar harmonic frame or vamp.
- `bass.mid` — style-oriented bass rhythm.
- `motif.mid` — intentionally simple motif seed.

## What to vary first

1. Bass note length and micro-syncopation.
2. One/two-note harmonic color.
3. Percussive relationship to the chord stab.

## Validation

- Can the hook be recognized on a plain piano/sine sound?
- Does each section have a distinct function without requiring a new progression?
- Are bass and chord registers separated?
- Is at least one musical parameter intentionally repeated?
