# Exercice 03 — 8 variantes de hook

Écrire un motif de 1 mesure. Produire :
1. même pitch, autre rythme ;
2. même rythme, autre fin ;
3. octave supérieure ;
4. dernière note tenue ;
5. une note supprimée ;
6. contour inversé ;
7. réponse sur mesure 2 ;
8. version réduite à 2–3 notes.

Choisir à l'aveugle après level-match.
