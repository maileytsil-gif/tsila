# Blueprint — Techno / 132 BPM / Kick + Rumble

## North Star
Relentless pulse with a distinct dry kick, controlled generated rumble, evolving texture and restrained harmonic information.

## Routing
- Kick skill owns dry transient/body.
- Rumble is a separate processing path and not merely an overlong kick.
- Bass skill only adds an independent bass if arrangement leaves room.
- Sound design uses drone/noise/metallic texture for evolution.
- Arrangement changes density, filtering and texture over long phrases.
- Mix protects kick transient and manages rumble decay/mono/phase before loudness.
