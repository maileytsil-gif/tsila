# Macro Orchestration

Use stable intention macros where possible:

- `TONE` — brightness / filter balance
- `MOTION` — modulation depth/rate
- `BITE` — upper-mid aggression / distortion emphasis
- `WEIGHT` — perceived body/low-mid/sub contribution without uncontrolled level rise
- `WIDTH` — stereo energy above the protected low band
- `SPACE` — reverb/delay send or wetness
- `ATTACK` — transient emphasis / envelope snap
- `VARIATION` — secondary timbral/rhythmic mutation

## Arrangement automation strategy

- Intro: reduced `TONE`, `WIDTH`, `WEIGHT` as needed.
- Build: automate `MOTION`/`TONE`/`SPACE`; avoid making every macro rise together.
- Pre-drop: often reduce `SPACE` or create silence before impact.
- Drop: restore `WEIGHT`/`ATTACK`; use `BITE` only if it improves articulation.
- Variation: change one macro family per phrase before adding new layers.

All ranges are `[TEST]` until verified on the actual rack/plugin instance.
