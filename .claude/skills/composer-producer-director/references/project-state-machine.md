# Project State Machine

`IDEA → CORE_LOOP → SIGNATURE_LOOP → ARRANGEMENT → PREMIX → MIX → DELIVERY`

## IDEA
Theory and identity only. Avoid detailed plugin chains.

## CORE_LOOP
Lock groove, harmony, hook and low-end ownership.

## SIGNATURE_LOOP
Add final-ish kick/bass identity and principal sound design.

## ARRANGEMENT
Create contrast, transitions, section functions and second-order variations.

## PREMIX
Clean obvious collisions; consolidate layers; freeze/print only when useful and authorized.

## MIX
Balance/phase/dynamics/spectrum/stereo/space.

## DELIVERY
Premaster/master checks, translation and export requirements.

## Regression rule
If a later phase exposes a structural problem, return to the earliest phase capable of solving it. Do not patch a composition problem at mastering.
