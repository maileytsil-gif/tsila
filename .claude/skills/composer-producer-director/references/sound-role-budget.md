# Sound Role Budget

Every sound must own one primary role.

| Role | Function | Typical elements |
|---|---|---|
| CORE | identity / hook | bass hook, vocal, lead, stab |
| FOUNDATION | pulse / weight | kick, sub, main bass |
| SUPPORT | harmony / glue | pad, keys, secondary pluck |
| MOTION | movement | arp, rhythmic modulation, percussion texture |
| AIR | high-frequency openness | hats, noise, top layer |
| SPACE | depth | reverb/delay returns, atmosphere |
| TRANSITION | change marker | riser, downlifter, reverse, fill |
| IMPACT | punctuation | impact, crash, sub hit |

## Budget rule

- 1 primary CORE at a time.
- 0–2 secondary hooks depending on section.
- Foundation must remain simpler than the combined support layers.
- If two sounds occupy the same role, either merge, alternate or differentiate them by rhythm/register/timbre.
- Silence is an allocated resource, not an absence of production.
