# Evidence Policy

The Director inherits evidence from the specialist skills and does not invent new manufacturer claims.

- Use `[DOC]` only when the underlying specialist reference documents it.
- Use `[ATTRIB]` only for a creator statement that exists in the producer/theory corpus.
- Use `[ANALYSIS]` for cross-track conclusions.
- Use `[HEUR]` for recommended values, genre conventions and creative defaults.
- Use `[TEST]` for anything that must be listened to, measured, or verified on the user's installed versions.

For plugin parameters and Live/Serum behavior, defer to the specialist documentation maps. If a capability is not verified, the Director must downgrade it to `[TEST]` rather than guessing.
