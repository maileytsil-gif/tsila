# Validation v18

Le validateur contrôle :
- conformité des exemples aux JSON Schemas ;
- provenance des patterns `[DOC]/[ATTRIB]` ;
- parsing et présence de notes dans les MIDI ;
- dépendances des BridgeAction batches ;
- nettoyage des anciens changelogs/validations de la racine.

Il ne valide pas la qualité musicale ni le fonctionnement réel du bridge dans Ableton : ces points restent `[TEST]`.
