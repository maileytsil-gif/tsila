# Provenance v18

Chaque règle documentée qui devient donnée structurée doit porter un `source_id` résolu dans `source-registry.json`.

- `[DOC]` / `[ATTRIB]` → au moins un source_id obligatoire.
- `[ANALYSIS]` → sources recommandées si l'analyse dépend d'un corpus.
- `[HEUR]` → adaptation proposée ; ne pas la ré-étiqueter comme tradition canonique.
- `[TEST]` → comportement ou valeur à vérifier dans le projet réel.
