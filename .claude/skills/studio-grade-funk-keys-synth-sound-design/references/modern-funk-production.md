## Approcher le « son Vulf » avec les natifs [HEUR/TEST]
1. Comp → **Compressor** Peak, ratio élevé, release court (« les releases courts provoquent le pumping » [DOC manuel Live]) ou Log ; ou **Drum Buss** (Comp fixe + Crunch).
2. Lo-Fi digital → **Redux** (Rate, Bits, Shape) ; analog → **Saturator** Analog Clip ou **Vinyl Distortion** ; bruit → Vinyl Crackle ou Erosion.
3. Wow/Flutter → **Chorus-Ensemble** Vibrato à 0,5–1,3 Hz, Amount faible.
4. Tilt → EQ du sidechain du Compressor/Glue ; Mix → Dry/Wet.
Comparer à niveau égal ; aucun réglage « signature » de Vulfpeck n'est documenté.
