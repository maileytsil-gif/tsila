# Wurlitzer 200A (Electric W) avec son trémolo de gain

## Cible
`COMPING / médium C3–C5 / soul, néo-soul, Vulfpeck (« 1612 » au 206A) / mono`

## Faits qui fixent le patch [DOC openwurli, DOC-W]
Anche frappée devant un **pickup électrostatique** ; bark = non-linéarité capacitive (anche plus proche = plus fort **et** plus dur) ; spectre inharmonique (f2/f1 ≥ 6,27) ; « vibrato » = **trémolo de gain à ≈ 5,6 Hz fixe**, profondeurs 0 / 1,4 / 2,6 / 4 / 7,6 dB, qui **module le gain du préampli** (donc la distorsion), asymétrique (dips 2,5 ms, remontée 35 ms), **mono** ; 64 notes A1–C7.

## Electric [TEST]
Pickup Model **W** ; P Distance bas + P Amp In haut (bark de captation) ; M Force < Vel élevé ; F Tone Vol bas (pas de tonebar) ; Noise Amount un peu plus présent (feutre) ; F Release très court ; M Stiffness ≈ 65, Force ≈ 70 [HEUR].

## Chaîne
`Electric → Saturator (Analog Clip, léger : le trémolo module la distorsion, donc la saturation est AVANT) → Auto Pan-Tremolo (Tremolo, Rate 5,6 Hz non synchro, Square adouci ou Shark Tooth, Vintage on, Amount ≈ 2,6–4 dB) → Compressor RMS 2–3:1 → room courte`. Garder la piste mono (Utility Width 0 %). Recette FM alternative : STK Wurley — paire 1:4 + paire à fréquence fixe 510 Hz, decays 0,15–0,25 s, vibrato 8 Hz → Operator avec C et D en Fixed 510 Hz [DOC / TEST].

## Alternatives
