# Basse « Chameleon » (ARP Odyssey) — filtre 12 dB résonant et drive

## Cible
`BASSE / vamp Bbm7 – Eb7 (Bb dorien) / jazz-funk 90–100 BPM / 12 notes répétées`

## Recette MusicRadar sur Korg ARP Odyssey [HEUR-extrait]
2 scies à fond, Osc 2 légèrement désaccordé ; filtre **Rev1 = 2 pôles 12 dB**, cutoff ≈ ¼, **résonance presque max**, **Drive ON** ; ADSR → filtre ≈ ¾ : attaque quasi min, decay court, un soupçon de sustain, release court ; VCA sur AR (attaque rapide, release court) ; **KBD CV → filtre 50 %** ; S/H → filtre bas pour la saleté. Caractère : « deux scies désaccordées, filtre qui descend, résonance qui pète, decay rapide » [HEUR-extrait].
