# Stabs Oberheim / Prophet (« 1999 », « Operator », stabs 24K Magic)

## Cible
`STAB ou synth brass / 100–120 BPM / accords 3–4 notes 48–72 / BRASS/STAB ACCENTS : sur le un et les pushes`

## Faits [HEUR-extrait / DOC-EXTRAIT]
Prince « 1999 » : OB-X puis OB-Xa, intro OB-Xa + ARP Omni-2 ; méthode : **presets** puis « ouvrir le filtre à fond » ; LFO → VCO pour la ligne chorale ; plusieurs couches de chorus ; reconstruction OB-Xd : résonance 40 %, drive +6 dB, reverb 10 % aigus non amortis. Midnight Star « Operator » : quatre Prophet-5 (presets bass, trumpet, keys). « 24K Magic » : stabs « probablement OB-X ou Prophet-5 », recréés sur Prophet-6 ; synth brass sur Juno-106. Données lisibles : presets OB-Xd « Comp Horns OB-Xa » (pulses + hard sync, 24 dB, cutoff 0,136, env 0,41) et patchs Surge « OB-8 Jump » (9 + 8 voix scie, 12/20 cents, LP 12 dB, cutoff 2,8 kHz, gate) — `../../../../corpus/synthes-vintage/`, `corpus/cuivres/` [DOC fichiers, HEUR communautaires].

## Analog [HEUR/TEST]
Osc 1 Saw, Osc 2 Saw Detune +8–12 cents (ou Rectangle + Sync ratio 11 st pour le « Comp Horns ») ; Unison 2 voix Detune faible ; LP **2e ordre (12 dB, « section ») ou 4e**, cutoff 1,5–3 kHz (« brighten »), résonance 30–40 %, Drive Sym 1 ; Fil Env A 0 D 200–400 ms S 40–60 % ; Amp A 0 D 0 S 100 % R 300–400 ms ; Vibrato Rate 5 Hz Amt < MW ; LFO lent → pitch faible pour la « chorale ».

## Serum 2
Voir `../../studio-grade-brass-sound-design/recipes/analog-poly-brass-80s.md` (régimes stab/pad/lead Juno-106, variante « Jump »).

## Chaîne
`→ Chorus-Ensemble Ensemble 1 Hz 60 % → Chorus-Ensemble Classic 0,3 Hz 30 % (deux couches) → Saturator Analog Clip +6 dB compensés → Reverb plate 1 s 10 %, aigus non amortis → API-2500 4:1 attaque 3 ms release 0,1 s`.

## Jeu
Stabs sur le un et les pushes (grille Rhodes), 3–4 notes, vélocité ≥ 100, gate 30–50 % ; renversements variés d'un overdub à l'autre (Prince : « overdubs multiples avec différents renversements » [HEUR-extrait]).

## Tests [TEST]
Mono : deux chorus superposés ne creusent pas · stab net à 30 % de gate · niveau compensé après drive.
