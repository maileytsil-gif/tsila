# Synth bass P-Funk (« Flash Light »), Minimoog et descendants

## Cible
`BASSE (SYNTH BASS OWNS GRAVE) / 100–110 BPM / E1–E3 (40–64), sauts d'octave / swing 16ths 57–59 %`

## Faits et recettes [HEUR-extrait sauf mention]
Trois (ou quatre) Minimoog chaînés joués par Bernie Worrell ; glide, bend et molette font le son ; Osc 1 32' scie, Osc 2 16' scie légèrement haut, Osc 3 triangle Lo en modulation ; filtre bas ; enveloppes immédiates et courtes (Reverb) ; Attack (Wavetable) : Mono, glide 45 ms, Semi −12, release 15–20 ms, « Swing 16ths 59 ». Contours du Minimoog = ADSD [DOC SS8].

## Drift (natif, relisible) [TEST]
Osc 1 Saw, Osc 2 Saw Oct −1 (ou Rectangle) Detune léger ; Voice Mode **Mono**, Mono Thickness bas, **Legato on, Glide 45 ms** ; filtre **Type II 24 dB**, Frequency 150–400 Hz, Resonance 25–35 %, Env 2 → LP +60–80 % ; Env 1 A 0, D 200–400 ms, S 0–20 %, R 20 ms ; Drift (variation) ≈ 20 % pour « plusieurs unités ».

## Analog [TEST]

## Serum 2 [TEST]
OSC A scie −12 st, OSC B scie ou pulse 25–40 % −24/−12 st, fine ±10 cents, Sub 30 % ; MG Low 24, 150–400 Hz, résonance 25–35 % ; Env 2 → cutoff +70 %, D 80–250 ms, S 0 ; Env 1 A 0–2 ms, D 300 ms, S 30 %, R 20 ms ; MONO + LEGATO, porta 45 ms, `PortaScaled` on ; pitch bend ±12 pour les « drop and recover » de Worrell.

## Chaîne
`Instrument → Saturator (Bass Shaper, Threshold −20 dB) → Compressor RMS 3:1 attaque 10–30 ms (opto-like, comme le CLA-3A de Ronson) → Utility Bass Mono < 120 Hz`. Propriété du grave et sidechain : `../../kick-bass-equilibre/SKILL.md`.

## Jeu
Grille synth bass (`../references/playing-voicings-midi.md`) : doubles-croches syncopées, sauts d'octave, dead notes (vél. 30), approche chromatique par en dessous glissée ; basse −5 à −10 ms devant le kick ; bend manuel sur une note par phrase.
