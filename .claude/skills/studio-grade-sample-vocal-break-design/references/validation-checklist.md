# Validation Checklist

- [ ] source et rôle identifiés ;
- [ ] Warp mode choisi après A/B, pas par habitude ;
- [ ] aucun click sur les cuts ;
- [ ] syllabes importantes lisibles ;
- [ ] pitch du vocal compatible avec la tonalité si tonal ;
- [ ] formants naturels ou volontairement stylisés ;
- [ ] low end retiré des longues queues si nécessaire ;
- [ ] delay/reverb ne masquent pas le downbeat du drop ;
- [ ] stutters gardent le groove ;
- [ ] FX chain justifiée fonction par fonction ;
- [ ] dry conservé ;
- [ ] resample nommé/versionné ;
- [ ] mono check ;
- [ ] level-matched A/B ;
- [ ] licence/source vérifiée si externe.
