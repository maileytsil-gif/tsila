# Sample Selection & Preparation

## Sélection
Un bon sample pour le rôle cible possède au moins une qualité dominante :
- rythme ;
- caractère timbral ;
- information mélodique ;
- texture ;
- parole/phonème ;
- transient ;
- espace.

## Préparation
1. conserver le fichier original ;
2. vérifier BPM/key si pertinents ;
3. nettoyer le start point ;
4. ajouter micro-fades aux coupes ;
5. corriger les warp markers seulement là où l'oreille l'exige ;
6. normaliser uniquement si cela sert le workflow — ne pas confondre normalisation et bon gain staging ;
7. noter la fonction dans le nom du fichier.

## [DOC] Browser Live
Le navigateur Live peut préécouter les loops synchronisés, afficher BPM/key et transposer la préécoute vers une tonalité choisie / la scale du Set.
