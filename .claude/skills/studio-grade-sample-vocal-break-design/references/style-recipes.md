# Style Recipes — Sample / Vocal Break

## Minimal House
- micro-vocal ou spoken shot ;
- peu de pitch ;
- short filtered delay ;
- micro-slices décalées ;
- laisser beaucoup de silence.

## Tech House
- phrase courte répétable ;
- chop syncopé ;
- delay throw 1/4 ou 1/8 selon groove ;
- filtered build ;
- cut net pré-drop.

## Bass House
- shot comme call ou answer ;
- octave/formant variation ;
- stutter 1/8→1/16 ou buffer accéléré `[HEUR]` ;
- granular/reverse tail ;
- interaction explicite avec bass call-response.

## Future House
- vocal plus tonal/émotionnel ;
- warp propre ;
- harmonized/pitched chops ;
- large reverb dans le break, tail réduit avant drop ;
- post-chorus vocal motif possible.

## Techno
- vocal comme texture/commande ;
- repeats, band-pass, distortion ou granular stretch ;
- intelligibilité facultative ;
- long atmospheric tail possible si le kick return reste propre.

## Electro
- edits plus abrupts ;
- buffer/stutter/pitch jumps ;
- resampling destructif ;
- contrastes dry ↔ hyper-processed.
