# Bridge Macro Map — Sample / Vocal / Break

Macros stables suggérées :
- `CHOP` — densité/stutter/slicing variation ;
- `PITCH` — transposition contrôlée ;
- `FORMANT` — caractère vocal si plugin exposé ;
- `STRETCH` — amount/rate ou proxy créatif ;
- `FILTER` — cutoff/resonance macro ;
- `SPACE` — delay/reverb send ;
- `FREEZE` — capture/freeze state ;
- `DESTROY` — lo-fi/distortion/granular amount.

## Règle bridge
Ne pas supposer qu'un paramètre VST tiers est contrôlable : Discover → Resolve → vérifier paramètre exposé → automation test → restauration.

## Automation phrase
Exemple intentionnel :
`Bars 49–52: SPACE 20→55%, FILTER opens; bar 52 beat 4: CHOP rises; last 1/8: SPACE→0 and FREEZE off before drop.`

Le bridge traduit l'intention vers les paramètres réellement disponibles.
