# Stage Gates — v18

Les gates dépendent de la branche. Les invariants communs :
- **Identity** : projet descriptible sans plugin.
- **Style/Groove Lock** : si culturel/Detroit/Jazz, la logique temporelle est explicite avant timbre.
- **Musical Core** : harmony/bass/hook fonctionnent avec sons neutres.
- **Low-end** : ownership explicite, mono stable.
- **Sound Roles** : un CORE principal, support hiérarchisé.
- **Arrangement** : fonctions de sections distinctes.
- **Transitions** : frontière plus claire, downbeat préservé.
- **Mix** : chaque processeur a un problème nommé.
- **Compile** : specs validés par schéma et invariants.
- **Execution** : capacités bridge découvertes, readback + rollback possibles.
- **Translation** : écoute/mono/petit système/référence level-matchée.
