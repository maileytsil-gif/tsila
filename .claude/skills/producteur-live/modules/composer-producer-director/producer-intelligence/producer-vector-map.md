## Comment utiliser la matrice

Ne pas additionner les scores pour désigner un « meilleur ». Sélectionner **le vecteur utile au morceau** :
- manque de mémorisation → Hook immédiat ;
- drop trop chargé → Minimalisme ;
- bass house trop statique → Nouveauté timbrale + Micro-edit ;
- morceau qui s'arrête/redémarre sans fluidité → Continuité club ;
- break sans émotion → Mélodie/émotion ;
- arrangement sans identité → Vocal central ou identité timbrale, pas les deux au maximum par défaut.
