# Bundles abstraits pour le projet de l'utilisateur

Ces bundles n'imitent aucun artiste. Ils combinent des axes étudiés.

## BH-01 — Groove-first Future Bass House
- bassline syncopée/mélodique ;
- drop assez minimal ;
- stab court comme ponctuation ;
- 1 hook principal ;
- 1–2 réponses timbrales.
**Références d'étude :** Oliver Heldens, FISHER, Dom Dolla.

## BH-02 — Rhythmic Sound-Design Bass House
- sub stable séparé ;
- mid-bass FM/warp mobile ;
- call-and-response ;
- silences intentionnels ;
- resampling/micro-edits.
**Références d'étude :** Skrillex, avec continuité house empruntée aux références groove-first.

## FH-01 — Melodic Future House
- progression émotionnelle simple ;
- pluck/stab ou chord hook ;
- basse rebondissante ;
- macro d'ouverture pour build ;
- drop plus lumineux que le break.
**Références d'étude :** Don Diablo, Martin Garrix, Oliver Heldens.

## CH-01 — Commercial House Crossover
- topline/vocal central ;
- groove facile à lire ;
- arrangement compact ;
- synthé simple mais mémorisable ;
- transition claire entre break et drop.
**Références d'étude :** David Guetta, Calvin Harris, Tiësto.

## MH-01 — Melodic Club House
- core tech-house solide ;
- break vocal/émotionnel ;
- ear candy ajouté tard ;
- drop qui retrouve rapidement le groove.
**Références d'étude :** John Summit, Dom Dolla.

## Utilisation
Choisir un bundle, puis le personnaliser avec : tonalité, progression, rythme de hook, type de basse, famille de synthé et 1 élément sonore propre au projet.
