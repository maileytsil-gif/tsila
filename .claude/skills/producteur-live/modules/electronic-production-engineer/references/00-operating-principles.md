# Operating principles

## Critical listening frame
Evaluate five families before reaching for plugins:
1. Construction: spectral role, horizontal placement, width, depth, relief, density and section contrast.
2. Balance: spectral balance, gain hierarchy and dynamic balance.
3. Definition: separation, masking, transient readability and timbral identity.
4. Stability: mono compatibility, phase/correlation, center stability and low-end consistency.
5. Reverberation: amount, decay, frequency content, depth and coherence.

## Signal-flow rule
Trace the actual path first: source -> instrument/sampler -> track devices -> rack -> group -> sends/returns -> mix bus -> master. Fix gain or routing at the earliest sensible stage.

## Least-destructive hierarchy
When a problem is heard, consider in this order:
1. arrangement/silence,
2. sample or patch choice,
3. note/timing/length/envelope,
4. level/pan,
5. EQ or spectral dynamics,
6. compression/transient control,
7. saturation/clipping,
8. master-stage correction.

## Comparison discipline
- Level-match references and processor bypasses.
- Compare like sections: drop-to-drop, break-to-break.
- Make small changes, then re-evaluate in context.
- Solo is for diagnosis; decisions are made in the mix.
- A louder version is not automatically better.

## Uncertainty labels
Use: `MEASURED`, `HEARD/OBSERVED`, `INFERRED`, `STARTING POINT`.
Never report exact LUFS, true peak, frequency, key, BPM, phase or gain reduction without actual measurement or a reliable source.
