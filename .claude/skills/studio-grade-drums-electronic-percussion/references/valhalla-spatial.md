# Valhalla — Space for Percussion

## ValhallaRoom `[DOC]`
True stereo algorithmic reverb, rooms/chambers/plates/large spaces. Les ressources du produit incluent explicitement short drum rooms et gated reverbs.

### Applications `[HEUR]`
- room courte partagée pour coller un kit ;
- chamber/plate pour clap/snare ;
- espace plus long uniquement comme événement d'arrangement.

## VintageVerb `[DOC]`
Modes numériques historiques, plate/room/ambience/nonlin etc. Très utile pour clap/snare rétro ou gated-like aesthetics.

## ValhallaDelay `[DOC]`
Tape/BBD/Digital/Ghost/Pitch/Reverse Pitch et diffusion. Utiliser pour fills, ping-pong percussif, reverse pitch echo ou ear-candy.

## Règle low-end
High-pass/Lo Cut les returns de percussion lorsque les graves n'apportent rien. Ne pas laisser un tail stéréo masquer kick/bass.
