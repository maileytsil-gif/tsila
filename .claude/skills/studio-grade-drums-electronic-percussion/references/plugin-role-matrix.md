# Plugin Role Matrix

| Problème / intention | Outil prioritaire | Alternative | Règle |
|---|---|---|---|
| attack trop mou/fort | Waves Smack Attack | NI Transient Master / Neutron TS | un seul shaper d'abord |
| sustain/tail excessif | Smack Attack / Transient Master | envelope source | corriger à la source si possible |
| harsh hat variable | Pro-Q 4 dynamic/spectral | Neutron EQ | dynamique avant notch statique extrême |
| harmonics/body | Saturn 2 | Saturator/Roar/Neutron Exciter | level-match |
| glue drum bus | Drum Buss / Pro-C 3 | NI bus tools | 1–2 dB GR souvent suffisant `[HEUR]` |
| creative kit sampling | Battery 4 | Drum Rack + Drum Sampler | choisir selon workflow |
| short room | ValhallaRoom | Ableton reverb | send/return préféré |
| gated/80s tail | VintageVerb | Room/Hybrid Reverb | filtrer le low end |
| pitch/reverse echo | ValhallaDelay | Echo | automation ponctuelle |
| transient+sustain spectral separation | Neutron | manual parallel | vérifier latency/CPU |

Aucun outil n'est obligatoire. Utiliser l'option native si elle accomplit la même fonction plus simplement.
