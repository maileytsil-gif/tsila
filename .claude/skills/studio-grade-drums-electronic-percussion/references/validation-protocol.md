# Validation Protocol

1. **Pattern-only** : kit avec sons neutres.
2. **Envelope** : tails n'empiètent pas inutilement.
3. **Mono** : attaques et body restent solides.
4. **Kick/Bass context** : aucun fill/tom ne vole le low-end principal.
5. **Hook/Vocal context** : hats/claps ne masquent pas les consonnes/lead.
6. **Level match** : chaque plugin doit gagner en qualité, pas seulement en volume.
7. **Small speaker** : groove encore lisible sans sub.
8. **Section A/B** : variation perceptible mais identité conservée.
9. **No bus test** : le kit fonctionne avant bus processing.
10. **Export** `[TEST]` : vérifier transients et tails après bounce/resampling.
