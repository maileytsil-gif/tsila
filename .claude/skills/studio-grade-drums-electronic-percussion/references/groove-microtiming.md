# Groove & Microtiming

## Ordre de construction
1. placement ;
2. longueur ;
3. vélocité ;
4. accent ;
5. microtiming ;
6. timbre ;
7. variation.

## Principes `[HEUR]`
- Kick/sub peuvent rester rigides pendant que hats/percs portent le swing.
- Un offbeat hat doit rester une ancre ; les ghost percs peuvent être davantage déplacées.
- Le groove vient souvent d'une asymétrie contrôlée : une percussion légèrement tardive, une autre plus courte, une variation de vélocité.
- Les fills ne doivent pas détruire le downbeat suivant.
- Pour A/B, déplacer un seul rôle à la fois.

## Validation `[TEST]`
Écouter sans regarder la grille. Si le groove paraît moins bon dès que l'affichage est caché, revenir au placement avant de changer le sound design.
