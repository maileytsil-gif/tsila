# Glitch / Micro-Percussion

1. Créer ou choisir une source forte.
2. Resampler.
3. Couper en fragments courts.
4. Réordonner selon le groove.
5. Ajouter reverse/stutter/granular seulement sur quelques événements.
6. Varier 1 paramètre par phrase.

Serum Sample/Granular ou Drum Sampler conviennent. Le random doit rester borné par le rôle rythmique.
