# Hybrid Sample + Synth Percussion

Architecture :
- sample = détail/texture/realism ;
- synth = pitch/envelope/consistency.

Exemples :
- clap sample + noise synth tail ;
- rim sample + sine resonance ;
- metal sample + FM transient ;
- foley click + tuned body.

Bouncer/resampler lorsque le résultat est validé pour simplifier CPU et phase.
