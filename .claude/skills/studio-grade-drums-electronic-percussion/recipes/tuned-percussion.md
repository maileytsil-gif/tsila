# Tuned Percussion

Moteurs: Collision, Operator, Serum 2, sample+pitch.

## Règles
- tuner la partie soutenue/tonale ;
- utiliser les degrés de la tonalité ou une tension consciente ;
- raccourcir le decay si la percussion devient une seconde mélodie non désirée ;
- vérifier collision avec stab/pluck/vocal.

Exemples: glass ping, mallet, resonant hit, electro tom, metallic note.
