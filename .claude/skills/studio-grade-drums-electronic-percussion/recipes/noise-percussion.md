# Noise Percussion

Familles: synthetic shaker, hiss tick, brushed hit, gated burst, noise clap layer.

## Source
DS/Serum Noise/filtered sample. Le filtre + envelope créent l'identité autant que le type de bruit.

## Variation
Vélocité, cutoff, decay et start position peuvent varier légèrement; garder une ancre stable dans le pattern.
