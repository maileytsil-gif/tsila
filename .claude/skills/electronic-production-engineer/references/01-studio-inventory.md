# Studio inventory and preferred tool roles

## Core platform
- Ableton Live 12 Suite: main DAW, arrangement, routing, automation, resampling and mix environment.
- Mac mini M4.
- Focusrite Scarlett 8i8 Mk3.

## Controllers / composition
- Akai APC64: Ableton session/scene control, clips, step sequencing, touch faders, device/macros, automation, performance.
- Native Instruments Maschine MK3 + Maschine 3: drums, groove, sampling, slicing, pattern generation, probability/euclidean features, performance.
- Native Instruments Komplete Kontrol A49 + Komplete Kontrol plugin: keyboard performance, NKS browsing/mappings, scales/chords/arpeggiation, instrument control.

## Instruments / sound design
- Serum 2: primary deep sound-design synth, including Sample, Granular, Spectral and wavetable-resampling workflows.
- Ableton Simpler/Sampler: core slicing, one-shot, multisample and sample-to-instrument design tools.
- Native Instruments / Komplete ecosystem through Komplete Kontrol when useful.
- Ableton native instruments/effects, especially Roar, Drum Buss, Hybrid Reverb, Compressor, Glue Compressor, Auto Filter/EQ Eight and Limiter.

## Precision / dynamics
- FabFilter Pro-Q 4: surgical/dynamic EQ, M/S and phase-aware work.
- FabFilter Pro-C 3: compression/sidechain when appropriate.
- oeksound soothe3: moving resonance/harshness control and spectral sidechain; never default-on.

## Waves collection
Assume a broad Waves collection is available. Priority roles:
- L4 Ultramaximizer: primary final limiter/true-peak/loudness tool.
- L2: classic alternate limiter/color reference.
- F6/C6/C4: dynamic/multiband control.
- API 2500, SSL G-Master, dbx 160, CLA-76/2A/3A, Renaissance Compressor: dynamics with different characters.
- Smack Attack / Trans-X: transient control.
- InPhase: related-signal phase/timing inspection.
- R-Bass / MaxxBass: psychoacoustic bass translation.
- J37 / NLS / Abbey Road Saturator / Magma-style tools: color.
- S1 / Center: stereo utilities.
- H-Delay / H-Reverb / Abbey Road reverbs: space.
- WLM Plus / PAZ: metering/QC.
- OVox: vocoder/vocal resynthesis, MIDI-controlled robotic vocals and external-carrier experiments.
- Vocal Bender: real-time pitch/formant design and Flatten-style robotic effects.
- Waves Tune Real-Time / Waves Tune: transparent-to-hard pitch correction, creative electronic tuning and pre-vocoder pitch control.
- Waves Harmony: generated vocal harmonies/layers when arrangement calls for them.

## Analog Obsession
Use primarily for analog color, bus dynamics and clipping. Priority: RazorClip for peak shaving/character; TheBus/BUSTERse/FET-style compressors for glue/color; KONSOL/PREDD/Rare-style tools for console/preamp/musical EQ character.

## Explicit exclusion
Do not assume FabFilter Pro-L 2 is owned. Use Waves L4/L2 or Ableton Limiter unless the inventory is later updated.
