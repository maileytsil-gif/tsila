# Sound-design engine

## Choose synthesis vs sample/resample
Use synthesis when parameter-level control is the musical advantage. Use sampling/resampling when texture, speed or transformation is the advantage.

## Serum 2 bass architecture
For heavy bass design think in layers/functions:
- SUB: clean, stable fundamental.
- MID BASS: identity and movement.
- UPPER HARMONICS: audibility/aggression.
- ATTACK/NOISE: transient articulation if needed.
Do not force one patch to solve every role.

## Movement
Map movement to a small number of macros: filter, wavetable/oscillator position, FM amount, distortion tone, LFO rate/depth, formant/spectral movement and FX mix. Movement should support phrase rhythm.

## Distortion chain
Create harmonics first, then control harshness only if needed. Example: Serum/Roar/Waves/Analog Obsession color -> soothe3/dynamic EQ if resonances become objectionable.

## Resampling
For Bass House/Techno/experimental textures: design -> automate -> render -> chop/reverse/pitch/stretch -> reprocess. Resampling can produce more distinctive motion than endlessly adding modulators.

## Komplete Kontrol/NKS
Use for fast sound discovery and stable macro semantics. Use a plugin directly in Ableton when deep parameter access is more important than NKS convenience.
