# Low-end engine

## Diagnose in this order
1. Is the kick sample/patch appropriate?
2. Are kick and bass note lengths/tails overlapping unnecessarily?
3. Is the bass note placement musical and rhythmically intentional?
4. Are related layers aligned in time/polarity/phase?
5. Is broad-band sidechain actually needed?
6. Only then reach for dynamic EQ/spectral sidechain or static EQ.

## Time before frequency
A 30-80 ms envelope or note-placement change can solve a conflict that a large EQ cut cannot. Treat kick and bass as time-domain events as well as frequency-domain objects.

## Sidechain choices
- Broad-band compressor: use when audible pumping is part of the groove.
- Dynamic EQ / F6 / Pro-Q: use when conflict is localized.
- soothe3 external sidechain: use for moving/spectral conflict while preserving unrelated bass content.
- Manual envelope/volume shaping: use when maximum precision and repeatability are desired.

## Phase
Use polarity, sample timing and phase tools on related/layered signals. Do not chase static phase alignment between two independent musical signals whose phase changes continuously. Always re-check in mono and by ear.

## Bass translation
Use R-Bass/MaxxBass or controlled saturation to add upper harmonics when small-speaker audibility is the problem. Do not confuse perceived bass with more sub energy.

## Stereo
Keep true sub stable/centered by default. Width can be introduced in upper bass harmonics. Verify correlation and mono.
