# Minimal / Deep Tech DNA

## Four references
- Michael Bibi — Hanging Tree: hypnotic loop, bass/percussion interaction.
- East End Dubs — bRave: bass weight and sparse musical content.
- Archie Hamilton — Mind Blank: long progression from tiny changes.
- Chris Stussy — All Night Long: modern elastic bass, fast groove, open midrange.

## Arrangement DNA
The 'drop' is often the same groove perceived anew after deprivation. Breaks can be 2-8 bars and bridges can be a single bass cut, delay throw, muted kick, alternate percussion or one-bar void. Use probability, microtiming, decay, filter and send changes to build long-form variation.

## Mix priorities
Every sound is exposed. Prioritize source choice, envelope and placement. Avoid over-processing; small timing/velocity moves can outperform EQ/compression.
