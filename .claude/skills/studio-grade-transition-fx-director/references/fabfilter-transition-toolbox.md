# FabFilter — Transition Toolbox

## Timeless 3 [DOC]
Sources :
- https://www.fabfilter.com/help/timeless/using/delaycontrols
- https://www.fabfilter.com/help/timeless/using/effects
- https://www.fabfilter.com/help/timeless/using/modulation

Fonctions utiles : Freeze modulable ; Ping Pong ; tempo sync ; Tape read mode (changement de temps avec fluctuations de pitch) ; Stretch read mode (change le délai en préservant la hauteur) ; pitch shift dans ou hors boucle de feedback ; Diffuse, Lo-Fi, Drive, Dynamics ; modulation par XLFO, EG, EF, MIDI, XY.

Usages `[HEUR]` : freeze throw, pitch-feedback riser, diffuse tail, tape-stop echo.

## Volcano 3 [DOC]
Sources :
- https://www.fabfilter.com/help/volcano/using/modulation
- https://www.fabfilter.com/help/volcano/using/filtercontrols

Filtres modulables ; XLFO tempo-sync, EG, envelope follower, MIDI et XY. Le XLFO peut aussi fonctionner comme séquenceur multi-step.

Usages `[HEUR]` : sweep complexe, resonance rhythm, filter gate.

## Pro-R 2 [DOC]
Sources :
- https://www.fabfilter.com/help/pro-r/using/maincontrols
- https://www.fabfilter.com/help/pro-r/using/decayrateEQ

Freeze, Ducking, Auto Gate, predelay tempo-sync et Decay Rate EQ par bandes.

Usages `[HEUR]` : reverb bloom qui s'efface au drop, gated impact tail, freeze suspendu.
