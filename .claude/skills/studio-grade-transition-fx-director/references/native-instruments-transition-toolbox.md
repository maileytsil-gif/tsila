# Native Instruments — Transition Toolbox

## Guitar Rig — Traktor's Transpose Stretch [DOC]
Source : https://docs.native-instruments.com/ni-tech-manuals/guitar-rig-manual/en/components-reference

Le module capture une boucle et la transforme par granular pitch-shifting/time-stretching. `Amount` peut ralentir jusqu'au freeze sur un grain ; `Size` règle la taille de grain quand Grain est actif ; `Key` transpose les grains.

Usages `[HEUR]` : freeze transition, tape-stop granular, extreme stretch, pitch pull-up/down.

## Maschine/Kontakt
Réutiliser les workflows de sample/stretch déjà documentés dans v14 lorsqu'une transition doit être jouée ou slicée depuis ces environnements. Le Director ne duplique pas les rôles de Simpler/Serum sans raison.
