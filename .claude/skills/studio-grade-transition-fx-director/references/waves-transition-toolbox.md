# Waves — Transition Toolbox

## MetaFilter [DOC]
Sources :
- https://www.waves.com/plugins/metafilter
- https://www.waves.com/1lib/pdf/plugins/metafilter.pdf

LFO, séquenceur 1–16 steps, envelope follower/sidechain, modulation cutoff/resonance/delay, delay, saturation et bitcrushing.

Usage `[HEUR]` : filter build, sequenced resonance, rhythmic gating/tension.

## H-Delay [DOC]
Source : https://www.waves.com/1lib/pdf/plugins/h-delay-hybrid-delay.pdf

Ping Pong, feedback, filtres, tempo sync. Waves documente un feedback au-delà de 100% qui peut construire le niveau rapidement ; traiter comme zone à risque et imprimer/limiter si utilisé `[DOC+TEST]`.

Usage `[HEUR]` : delay throw, self-building tail contrôlé, pre-drop feedback.

## SoundShifter [DOC]
Source : https://www.waves.com/1lib/pdf/plugins/soundshifter.pdf

Time scaling et pitch shifting peuvent être réglés indépendamment ; Graphic SoundShifter permet des changements de ratio dans le temps.

Usage `[HEUR]` : stretched downlifter, accelerating/decelerating audio transition, pitch ramp imprimée.
