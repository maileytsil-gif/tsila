- 13:53 Zone : Key / Velocity / Sample Select ; 14:06 deux samples sur deux plages de touches ; 14:50 Shift + clic droit : tri et « distribute ranges » ; 15:10 Velocity (jouer fort = autre sample) ; Sample Select mappable à un contrôleur MIDI pour changer de sample en live ; 15:31 barre de crossfade au-dessus des zones (comme un chain selector) pour fondre deux samples.
