# Recipe — Neo-Soul / Modern Jazz

`[HEUR]`
- 70–100 BPM ;
- rootless/extended voicings ;
- guide-tone voice leading ;
- bassline moins dense que les keys ;
- phrase mélodique pentatonique + tensions ;
- pocket laid-back testé manuellement ;
- drums légèrement asymétriques plutôt qu'un swing mécanique uniforme.
