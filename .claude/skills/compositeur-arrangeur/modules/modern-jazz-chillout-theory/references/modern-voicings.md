# Modern Jazz Voicings

## [DOC] Guide tones et tensions
Les voicings jazz/pop reposent souvent sur le son de base 3e/7e, puis sur des tensions choisies selon le contexte. Berklee présente aussi quartes, clusters et upper-structure triads comme ressources modernes.
Sources :
- https://online.berklee.edu/takenote/basic-piano-voicing-techniques/
- https://online.berklee.edu/takenote/harmonic-considerations-modal-harmony/

## Familles `[HEUR]`
1. **Shell** : 3–7 (+ mélodie).
2. **Rootless 4 notes** : 3/7 + 9/13 ou variantes.
3. **Quartal** : 3–4 notes en quartes, particulièrement modal.
4. **Cluster** : secondes contrôlées dans le médium/aigu.
5. **Upper structure** : triade supérieure au-dessus d'un guide-tone shell.
6. **Hybrid/slash** : couleur supérieure + basse indépendante.

## Chill
Préférer spacing ouvert : basse seule, médium 3e/7e, extension en haut. Éviter une densité de 6–7 notes dans le bas-médium `[HEUR+TEST]`.
