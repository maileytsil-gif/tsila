# Bass ↔ Keys Interlock

Berklee décrit en R&B/funk l'usage de répétition, syncopation, motifs et approches chromatiques pour donner du mouvement à la basse. Source : https://online.berklee.edu/courses/r-b-bass

## Règle `[HEUR]`
- si la basse est dense, comping keys plus court/sparse ;
- si les keys ont une cellule 16e active, basse plus ancrée ;
- éviter de doubler toutes les syncopes ;
- réserver 1–2 hits d'unisson comme événements ;
- utiliser réponses entre bass et clav/Rhodes.

## Low end
Les accords main gauche doivent éviter de concurrencer la fondamentale/sub : rootless voicing au-dessus d'une basse claire est souvent préférable `[HEUR+TEST]`.
