# Ableton Live Workflow — Jazz/Funk/Chill

## [DOC] Groove Pool
Live permet d'appliquer les grooves à des clips MIDI et audio (pour l'audio, Warp doit être actif) et d'en ajuster les paramètres dans Groove Pool. Source : https://www.ableton.com/en/live-manual/11/using-grooves/

## [DOC] Humanize Live 12
Live 12 possède une fonction Humanize qui introduit une légère variation aléatoire du début des notes. Source : https://www.ableton.com/en/release-notes/live-12/

## Workflow `[HEUR]`
1. Programmer une version strictement lisible.
2. Régler vélocités et longueurs avant le timing.
3. Tester Groove Pool ou déplacer manuellement les phrases importantes.
4. Faire `TIGHT / POCKET / LOOSE`.
5. Ne jamais humaniser le kick/sub de manière aléatoire sans raison.
6. Resampler seulement après validation du groove MIDI si le son final dépend du timing.

## Ableton instruments utiles
- Electric/Rhodes-like ;
- Operator pour EP/FM, basses et leads ;
- Wavetable/Meld pour jazz électronique ;
- Drum Rack + Groove Pool pour pocket ;
- Simpler pour chops/percussion organique.
