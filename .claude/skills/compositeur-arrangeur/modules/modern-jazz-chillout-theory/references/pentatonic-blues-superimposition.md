# Pentatonic / Blues / Superimposition

Berklee place pentatonique, blues, motif, chord tones et chromaticisme au cœur de l'improvisation de base ; son cours Funk/R&B met l'accent sur le vocabulaire pentatonique et le phrasé rythmique. Sources :
- https://online.berklee.edu/courses/basic-improvisation
- https://online.berklee.edu/courses/funk-rock-and-r-b-guitar-soloing

## Ordre de sophistication `[HEUR]`
1. pentatonique de la tonalité ;
2. blue note ponctuelle ;
3. chord tones sur changement ;
4. tensions disponibles ;
5. pentatonique déplacée/superposée seulement si la cible harmonique reste lisible.

Le rythme doit rester reconnaissable même si on remplace toutes les hauteurs par une seule note.
