# Harmony Core — Modern Jazz / Chill

## [DOC] Fondations
Berklee décrit la maîtrise des accords jusqu'à la 13e, des modes, gammes non diatoniques, fonctions harmoniques et techniques de voice leading comme cœur de l'harmonie contemporaine. Source : https://college.berklee.edu/harmony

## Vocabulaire prioritaire `[HEUR]`
- maj7, maj9, 6/9 ;
- m7, m9, m11 ;
- 7, 9, 13, 7sus ;
- m7b5 / altered dominants quand la fonction le justifie ;
- slash chords pour contrôler la basse ;
- add9/sus pour le chill quand une 7e complète alourdit trop.

## Règle
Commencer par **3e + 7e + mélodie/basse**, puis ajouter une tension seulement si elle clarifie la couleur. Un accord riche n'est pas automatiquement meilleur.
