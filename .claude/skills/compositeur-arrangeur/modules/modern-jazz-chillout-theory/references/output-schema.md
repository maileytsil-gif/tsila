# Output Schema

Toujours livrer :

```text
STYLE / BPM / KEY
TIME FEEL: grid + pocket
HARMONY: degrees + chord symbols
VOICINGS: exact notes + MIDI numbers
PHRASE CELL: rhythmic positions
TARGET NOTES: chord tones/tensions
CHROMATIC APPROACH: yes/no + target
ARTICULATION: velocity/length/accent/ghost
BASS-KEYS INTERLOCK
ABLETON IMPLEMENTATION
VARIANTS A/B/C
TESTS
```

Pour un phrasé demandé, fournir d'abord **rythme + cibles**, puis seulement les notes complètes.
