# Système de composition Bass House

## 1. Fiche cible

Avant de générer des notes, écrire : BPM ; tonalité ou centre tonal ; énergie 1–5 ; caractère sombre/clair ; degré de swing ; poids du sub ; agressivité du mid-bass ; présence du vocal/hook ; durée cible ; usage club/stream/DJ ; 1–3 références décrites en attributs.

## 2. Analyse d'une référence [DOC]

Faire des passes séparées :
- **son** : familles de timbres, densité, espace, sec/réverbéré, stable/mouvant ;
- **harmonie** : centre tonal, changements d'accords, pédale ou harmonie implicite ;
- **mélodie** : registre, contour, répétition, intervalles ;
- **rythme** : kick, backbeat, hats, syncopes, durée des notes de basse, silence ;
- **forme** : entrées/sorties, densité, transitions, événements uniques.

Le résultat est un catalogue d'attributs, pas une transcription.

## 3. Drop minimal [HEUR]

Commencer avec quatre fonctions :
1. kick/impulsion ;
2. fondamentale/sub ;
3. mid-bass/hook rythmique ;
4. contraste/espace (silence, percussion ou réponse).

Ajouter ensuite seulement ce qui résout un besoin : haute fréquence, largeur, réponse, texture ou tension.

## 4. Bassline

Écrire le rythme avant la hauteur. Tester trois versions :
- **ancrage** : notes longues ou simples qui consolident la fondamentale ;
- **syncopée** : notes courtes intercalées avec le kick ;
- **question/réponse** : une phrase A et une réponse B avec articulation/registre différents.

La meilleure version est celle qui garde une identité lorsqu'elle est jouée avec un son simple. Si le groove disparaît quand on remplace le preset par une sine/saw basique, le sound design masque probablement une écriture faible.

## 5. Variation [DOC + HEUR]

Créer des générations successives et ne changer qu'un axe significatif par génération : rythme, dernière note, registre, longueur, timbre, harmonie ou densité. Ensuite sélectionner 2–4 variantes complémentaires. Cela évite la « variation aléatoire » qui détruit l'identité.

[HEUR] Dans un drop, une microvariation toutes les 1–2 mesures peut maintenir le mouvement et une variation plus forte à la fin d'une phrase 4–8 mesures peut signaler la structure. Adapter au matériau réel.

## 6. Arrangement par fonction

- **Intro** : information suffisante pour identifier le groove et préparer le mix DJ, sans révéler toute la densité.
- **Break** : contraste de registre/densité ; rappeler le motif ou l'harmonie avec une autre orchestration.
- **Build** : augmenter la tension par densité, registre, accélération, automation ou retrait du grave ; ne pas tout utiliser à la fois.
- **Drop** : résolution rythmique et énergétique ; garder de l'espace entre les gestes de basse.
- **Outro** : retirer des éléments et rendre la sortie exploitable si l'usage DJ est visé.

Ces noms de sections sont des conventions de travail [HEUR] ; les principes de contraste, variation, arc et soustraction sont généraux [DOC].

## 7. Frontières

Choisir une stratégie principale par frontière :
- **soustraction** : enlever kick/sub ou hautes fréquences ;
- **pickup** : note/fill avant le 1 ;
- **silence** : vide bref avant impact ;
- **continuité** : tail/reverb/texture qui traverse la frontière ;
- **événement unique** : impact/fill ponctuel ;
- **mutation** : modifier un motif existant au lieu d'ajouter un nouvel élément.

## 8. Critère de qualité

Le morceau doit pouvoir être décrit en termes de trajectoire : où l'attention monte, se relâche, se déplace et revient. Une structure n'est pas « professionnelle » uniquement parce qu'elle contient 8/16/32 mesures.
