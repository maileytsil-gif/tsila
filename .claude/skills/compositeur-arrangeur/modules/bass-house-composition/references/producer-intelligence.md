# Producer Intelligence — pont vers composition/arrangement

Utiliser le dossier racine `producer-intelligence/` quand l'utilisateur cite une référence ou demande une direction commerciale.

1. Choisir 2–3 vecteurs, pas un artiste à copier.
2. Sélectionner 3 morceaux maximum pour des fonctions distinctes : groove / énergie / vocal / contraste.
3. Appliquer `inspiration-without-copying.md`.
4. Construire le morceau original autour de ses propres notes, rythme de hook et timbre.
5. Utiliser `producer-hybrid-bundles.md` comme raccourci si la cible est Bass House/Future House/Commercial House.
