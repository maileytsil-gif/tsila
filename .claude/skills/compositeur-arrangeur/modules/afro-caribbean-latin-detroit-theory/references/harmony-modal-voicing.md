# Harmony / modal / voicing palette

## Afro House `[HEUR]`
- static minor/modal center ;
- Dorian/Aeolian colors ;
- sus2/sus4/add9 ;
- pedal bass ;
- sparse harmonic rhythm.

## Afro-Cuban / Latin House `[HEUR]`
- triads/7ths with tight voice-leading ;
- dominant motion if the selected style supports it ;
- chord tones organized around syncopated ostinato ;
- chromatic approaches resolve to targets.

## Brazil-informed chill/house `[HEUR]`
- 6/9, maj7/9, m7/9 ;
- chromatic/secondary dominant motion only when musically justified ;
- smooth inner voices.

## Detroit `[HEUR]`
- m7/m9, sus, quartal colors, soulful 7/9 voicings ;
- static/modal harmony with changing top voice ;
- parallel chord color as timbral hook.

Règle : le rythme des accords fait partie du groove. Un voicing sophistiqué joué au mauvais endroit est moins utile qu'une triade bien placée.
