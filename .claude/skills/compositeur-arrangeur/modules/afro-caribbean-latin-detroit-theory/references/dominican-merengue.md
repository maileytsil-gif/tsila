# Dominican merengue / típico study

[DOC] Smithsonian présente le merengue típico du Cibao comme un quintet entraînant centré sur accordion, tambora, güira, saxophone et electric bass ; l'improvisation y est importante.

[ANALYSIS] Concepts transférables :
- high-frequency continuous drive ;
- dialogue drum/rasp ;
- bass propulsion ;
- melodic instrument that can improvise over a repetitive dance engine.

[HEUR] House translation : convertir le rôle de güira en shaker/hat lattice, pas nécessairement sampler une güira réelle.
