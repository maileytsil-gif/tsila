# Percussion role map

Rôles abstraits :
- `CLOCK` — subdivision continue ;
- `TIMELINE` — pattern structurel ;
- `ANCHOR` — poids métrique ;
- `ANSWER` — réponse syncopée ;
- `LEAD_DRUM` — variation/interaction ;
- `LIFT` — densité croissante ;
- `TURNAROUND` — fin de cycle ;
- `AIR` — texture haute fréquence.

[HEUR] Une piste peut remplir deux rôles, mais pas six. Si deux pistes remplissent exactement le même rôle, en supprimer une ou différencier registre/timing/timbre.
