# Rhythm framework: pulse, timeline, interlock

[DOC] Smithsonian Folkways présente les bell/clave-type patterns comme des structures qui tiennent ensemble des couches musicales dans plusieurs traditions ouest-africaines et afro-caribéennes.

[ANALYSIS] Dans un DAW, une bonne traduction consiste à séparer :
- pulse explicite ;
- timeline de référence ;
- low drum ;
- mid drums ;
- high timekeeper ;
- bass ;
- harmonic ostinato ;
- vocal/call-response.

[HEUR] Complexité perçue = interlock de couches simples. Éviter de mettre des syncopes fortes dans toutes les pistes au même instant.

[TEST] Mute test : retirer une couche à la fois. Si la timeline disparaît immédiatement, le groove est trop dépendant d'un seul sample ; si rien ne change, la couche est probablement inutile.
