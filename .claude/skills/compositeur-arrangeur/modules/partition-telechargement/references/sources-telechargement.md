# Où télécharger quoi (état au 14 sept. 2026, testé depuis ce Mac)
| source | contenu | accès direct par script ? | remarques |
|---|---|---|---|
| Mutopia (mutopiaproject.org) | LilyPond, MIDI, PDF ; classique domaine public | **oui** (`ftp/...`) | index par code compositeur (`make-table.cgi?Composer=SatieE`) |
| OpenScore (GitHub OpenScore/Lieder, StringQuartets) | .mscz/.mxl MuseScore, domaine public | **oui** (API + raw GitHub) | Lieder = 142 compositeurs ; quatuors |
| KernScores / craigsapp (GitHub) | **kern (sonates, mazurkas, chorals…) | **oui** | exact, avec numéros de mesure |
| Wikimedia Commons | MIDI, images, PDF de thèmes célèbres | oui (upload.wikimedia.org) | qualité variable |
| IMSLP | PDF scannés (éditions anciennes) | **non** (redirection JS + attente 15 s) | Chrome de l'utilisateur → ~/Downloads, ou lecture à l'écran |
| musescore.com hors OpenScore | partitions d'utilisateurs | non (compte) | souvent protégées |
| piano-midi.de | MIDI d'interprétation | souvent bloqué | rubato : requantifier |
