# Exercice 05 — Call & Response électronique

1. Dessiner 2 mesures en blocs rythmiques A/B sans pitch.
2. Mettre A sur un son court, B sur un son long.
3. Ajouter seulement 2 ou 3 hauteurs de gamme.
4. Introduire un silence complet.
5. Créer une version où B répond une octave plus haut.
6. Vérifier que le dialogue reste compréhensible avec synthés neutres.
