# Vocabulaire d'accords moderne

## Base

- triade majeure : 1–3–5
- triade mineure : 1–♭3–5
- diminuée : 1–♭3–♭5
- sus2 : 1–2–5
- sus4 : 1–4–5
- add9 : triade + 9
- 6 / m6 : triade + 6
- maj7 / m7 / 7 : couleur plus riche ; utiliser selon le style.

## Voicings pratiques Pop/Electro

[HEUR]
- garder la fondamentale à la basse et alléger l'accord au-dessus ;
- doubler une note seulement si cela sert le registre/timbre ;
- open voicing : éloigner certaines voix d'une octave pour dégager le médium ;
- drop voicing : déplacer une voix d'une octave pour élargir ;
- slash chord : utiliser une basse différente pour créer continuité ou tension ;
- pédale : conserver une note pendant plusieurs accords pour cohérence.

## Couleurs modernes

- `add9` : ouverture sans la tension complète d'une 7e ;
- `sus2/sus4` : ambiguïté et mouvement ;
- accords incomplets : peuvent laisser la mélodie définir majeur/mineur ;
- notes communes maintenues : cohésion et fluidité.

[TEST] Les extensions sont particulièrement sensibles au registre. Une 9e jolie au piano peut devenir trouble sur un synthé large dans le bas médium.
