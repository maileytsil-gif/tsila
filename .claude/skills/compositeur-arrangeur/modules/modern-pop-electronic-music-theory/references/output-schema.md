# Schéma de sortie composition

Quand l'utilisateur demande une proposition complète, répondre dans cet ordre :

1. **Cible** — style, émotion, BPM, tonalité, fonction.
2. **Harmonie** — degrés → accords → voicings.
3. **Bassline** — fonction, rythme, notes.
4. **Hook/mélodie** — motif, contour, ambitus, note cible.
5. **Forme** — sections + énergie.
6. **MIDI** — positions, notes/octaves, durées, vélocités si demandé.
7. **Variantes** — au moins 2, en changeant un seul axe principal chacune.
8. **Ableton** — Scale Mode/MIDI tools utiles.
9. **Validation** — écoute A/B, mémorisation, tension/release, espace.
10. **Tags** — signaler `[HEUR]` ou `[TEST]` pour les décisions non documentaires.
