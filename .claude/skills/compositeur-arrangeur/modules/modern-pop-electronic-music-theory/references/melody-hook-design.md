# Mélodie & Hook Design

## Variables fondamentales

- **Contour** : montée, descente, arche, vague, plateau.
- **Ambitus** : distance entre note la plus basse et la plus haute.
- **Rythme** : souvent plus mémorable que les hauteurs seules.
- **Motif** : cellule courte répétée/variée.
- **Point culminant** : note ou rythme le plus saillant.
- **Tension harmonique** : chord tone vs note de couleur/tension.
- **Respiration** : silences et espaces.

## Procédure hook

1. écrire une cellule de 2–5 notes ou un motif rythmique ;
2. répéter une fois presque identique ;
3. varier un axe : fin, hauteur, longueur ou registre ;
4. faire répondre la quatrième phrase ;
5. tester sans production complexe.

## Climax réservé

[ATTRIB] Amy Allen décrit le fait d'éviter que verse/pre-chorus utilisent déjà toutes les notes ou idées qui doivent faire culminer le chorus. [HEUR] Le skill peut donc réserver une note haute, un saut ou une valeur longue au payoff.

## Max Martin : mémorisation

[ATTRIB] Les commentaires attribués à Max Martin mettent l'accent sur une chanson ressentie rapidement, mémorisable après peu d'écoutes, et sur la familiarité mélodique entre sections quand l'énergie change.

[HEUR] Test « deux écoutes » : après deux passages, couper l'audio et tenter de fredonner le motif. Si rien ne reste, simplifier rythme/contour avant d'ajouter des notes.

## EDM

Le hook peut être :
- vocal ;
- synth lead ;
- stab rhythmique ;
- bass phrase ;
- motif de chord ;
- sample transformé.

[HEUR] Un timbre spectaculaire sans phrase identifiable n'est pas automatiquement un hook.
