# MIDI-number convention

- **Canonical identifier:** MIDI note number 0–127.
- Text examples also use **scientific pitch notation** (`C4 = MIDI 60`) for readability.
- Octave labels are not standardized consistently across music software. Therefore, when a note must be reproduced exactly, trust the **MIDI number** first and the host's octave label second.
- When delivering instructions to Ableton Live, write both pitch-class/octave and MIDI number whenever the octave matters.
- For bass/sub design, verify the actual sounding frequency and register in the instrument; do not rely on a label alone.

This convention prevents an octave-label mismatch from becoming a composition error.
