# Melody generation engine

[DOC] Berklee highlights **motif, repetition and contrast** as controllable melody variables. Build melodies from those variables rather than random scale notes.

## 8-step method
1. Pick section role: verse, pre, chorus, drop, break, hook fill.
2. Pick a **rhythmic cell first** (onbeat, offbeat, syncopated, sparse, sustained).
3. Pick 2–5 pitch classes as a motif pool.
4. Anchor structurally important notes to chord tones or intentional tensions.
5. Repeat the motif enough to be recognizable.
6. Change only one feature on the repeat: ending, register, rhythm, or one interval.
7. Reserve a stronger register/longer note/target tone for payoff when desired.
8. Test the melody over a plain sound before production disguises weaknesses.

## Electronic-specific rule
A bass growl, stab sequence or chopped vocal can be the melody if it has pitch/rhythm identity. Treat timbral phrases with the same motif/repetition/contrast discipline.

## Avoid
- filling every gap;
- changing pitch and rhythm on every repetition;
- relying only on scale compliance;
- letting MIDI generation replace selection.

Live 12's Seed/Shape/Connect tools are idea generators [DOC]; curate the result and rewrite it into a motif [HEUR].
