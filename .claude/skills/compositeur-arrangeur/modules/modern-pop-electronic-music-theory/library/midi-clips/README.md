# MIDI starter clips

18 original starter clips are included: `chords.mid`, `bass.mid`, and `motif.mid` for each of six style families.

They are **teaching seeds**, not finished songwriting and not transcriptions. Import the three clips to separate MIDI tracks in Ableton Live, set the documented scale, and then change at least two musical dimensions before treating the result as a composition.

Recommended first edits:
1. change one inversion/top note;
2. alter bass note lengths around the kick;
3. make a two-bar A/B motif;
4. change the last chord or last-bar rhythm;
5. move the motif register for chorus/drop payoff.

MIDI note numbers are canonical; see `../midi-number-convention.md`.
