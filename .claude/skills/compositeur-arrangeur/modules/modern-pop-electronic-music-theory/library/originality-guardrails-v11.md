# Originality guardrails v11

This library is a **compositional grammar**, not a song copier.

- Progressions and scale-degree movements are reusable vocabulary; still avoid recreating a reference's melody, bass rhythm, signature sound and arrangement together.
- If a user names an artist, extract abstract variables: density, contour, harmonic rhythm, energy, groove, voicing strategy.
- Do not transcribe a commercially released melody into the library.
- Do not call a generated chord loop “the progression from” a track unless it was independently verified and the user specifically needs factual analysis.
- MIDI starter clips included here are original generic exercises.
- After loading a starter clip, change at least **two of**: rhythm, register, voicing, bass pattern, motif, section placement, sound design.
