# Recette — Future House mélodique

1. Mode majeur ou mineur émotionnel ; progression courte.
2. Voicings propres et souvent plus hauts que la bassline.
3. Bassline bounce/offbeat définie avant le lead.
4. Hook = stab/pluck/chord motif mémorisable.
5. Break : révéler l'harmonie avec moins de drums.
6. Build : augmenter tension rythmique, réduire sub.
7. Drop : résoudre par retour kick+bass + hook simplifié.

[HEUR] Ajouter une note de couleur (add9/sus) dans le break peut donner plus d'émotion ; vérifier qu'elle ne brouille pas le drop.
