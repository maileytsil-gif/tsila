# Bibliothèque de 60 références — objectifs d'étude

Ne pas analyser les 60 à la fois. Pour un projet, sélectionner 3–5 morceaux maximum : un pour le groove, un pour le contraste, un pour l'identité timbrale, éventuellement un pour le vocal et un pour l'arrangement.

| Martin Garrix | Animals; Forbidden Voices; High On Life; In The Name Of Love; Scared To Be Lonely; Quantum | hook, émotion, contraste, élément signature |

## Règle
Le titre d'un morceau est un **pointeur d'écoute**, pas une preuve technique. Toute mesure précise (BPM, note, LUFS, fréquence, nombre de mesures) reste [TEST] tant qu'elle n'a pas été vérifiée avec l'audio ou une source fiable.
