# Sélecteur de références v7 pour un projet

Répondre d'abord à cinq questions :

1. Le hook principal doit-il être **basse, synthé, vocal, percussion** ou **sound-design gesture** ?
2. Le morceau doit-il privilégier **club**, **festival**, **streaming/pop** ou un hybride ?
3. Le break doit-il être **fonctionnel**, **émotionnel** ou très court ?
4. La densité cible du drop est-elle **minimal**, **medium**, ou **agressive/edited** ?
5. La basse doit-elle être **ronde**, **mélodique/bouncy**, **dark/distorted**, ou **talking/edited** ?

## Mappings

- **Talking/edited bass** → Chicken Soup + The One ; ajouter HOT DRUM pour la percussion.
- **Bouncy Future House** → Gecko + Quantum ; ajouter Adieu pour la profondeur.
- **Minimal club** → Losing It + On My Mind ; ajouter San Frandisco pour le flow DJ.
- **Dark Bass House** → Notorious + Chicken Soup ; ajouter Adieu pour l'espace.
- **Vocal émotionnel + club** → Where You Are + Survive ; ajouter The Business pour la clarté pop.
- **Mainstage impact** → Animals + Quantum ; ajouter Chicken Soup uniquement pour micro-edits, pas pour copier le drop.
- **Percussion-led** → La Danza + HOT DRUM ; ajouter San Frandisco pour l'évolution longue.

Après sélection, prendre **un seul attribut majeur par référence**. Si deux références donnent le même attribut, en retirer une.
