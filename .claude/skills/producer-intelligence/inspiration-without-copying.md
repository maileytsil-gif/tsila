# Protocole d'inspiration sans copie

## Extraction
Pour chaque morceau de référence, relever seulement :
- fonction du hook ;
- densité relative ;
- registre dominant ;
- type de groove ;
- longueur perçue des articulations ;
- trajectoire d'énergie ;
- rôle du vocal ;
- rapport kick/bass ;
- quantité de mouvement timbral ;
- type de contraste aux transitions.

## Transformation obligatoire
Avant de produire :
1. choisir une autre progression/centre tonal ou une autre logique harmonique ;
2. écrire un nouveau contour rythmique ;
3. créer une identité timbrale différente ;
4. modifier la relation call/response ;
5. combiner au moins deux sources d'inspiration abstraites ou une référence + une intention personnelle.

## Interdit dans le workflow
- relever et recopier note par note un hook reconnaissable ;
- reconstruire une bassline distinctive avec le même contour et les mêmes accents ;
- reproduire une chaîne de paramètres seulement pour imiter l'identité d'un producteur ;
- annoncer qu'un preset est « le son exact de » sans preuve de projet/stems.

## Sortie recommandée
Au lieu de « Skrillex bass », écrire : `basse FM/hybride à articulation courte, forte variation de formants, réponses espacées et micro-edits`. Au lieu de « Fisher drop », écrire : `drop minimal à hook vocal court, kick/bass dominant et espace négatif important`.
