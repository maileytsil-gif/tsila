# Deep Track Analysis v7 — mode d'emploi

Ces fiches servent à extraire des **principes de production** de références commerciales sans copier leurs mélodies, lignes de basse, samples, voix, presets ou arrangements reconnaissables.

## Niveaux de confiance

- **[META]** : métadonnée publiée par une source de distribution/référence (BPM, tonalité déclarée, version, durée). Une tonalité automatique peut rester discutable musicalement.
- **[ANALYSIS]** : interprétation de production à utiliser comme hypothèse de travail. Elle ne prétend pas provenir des stems ou du projet original.
- **[HEUR]** : règle de transfert proposée pour un morceau original.
- **[TEST]** : point qui doit être vérifié contre l'audio de référence légalement disponible, le Live Set ou une mesure réelle.

Les positions exactes en mesures, LUFS, fréquences de coupure, notes des lignes de basse et paramètres de plug-ins ne sont **jamais inventés**. Si l'utilisateur fournit l'audio ou un projet, créer ensuite une analyse [OBS] et remplacer les hypothèses par des observations vérifiées.
