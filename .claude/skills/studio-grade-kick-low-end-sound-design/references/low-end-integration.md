# Intégration kick / basse / rumble

## 1. Décider qui possède le sous-grave

Si le kick a un tail à 45–55 Hz et la basse tient en même temps dans la même zone, la compétition est structurelle. Le mixage ne peut pas entièrement réparer un arrangement incompatible [HEUR].

## 2. Phase et timing

Tester :
- polarité du kick ;
- phase/timing du sub ;
- position des notes de basse ;
- longueur de release ;
- phase à chaque retrigger si les synthés ne sont pas déterministes.

Le meilleur réglage est celui qui fonctionne sur plusieurs notes importantes du groove, pas seulement sur une capture d'écran du spectre [TEST].

## 3. Sidechain

Objectif : créer un espace temporel, pas seulement afficher 6 dB de gain reduction.

Point de départ [HEUR] : release proche d'une fraction rythmique (1/16 ou 1/8 selon style), puis ajuster plus court/long en écoutant le rebond. L'attaque peut être très rapide si le kick doit passer immédiatement, mais une attaque trop instantanée peut devenir audible selon la basse.

## 4. Mono

Sous ~100–120 Hz, garder une image contrôlée est souvent utile en club [HEUR]. Ne pas appliquer une coupure stéréo fixe sans écouter ; vérifier plutôt Utility mono et corrélation.

## 5. Rumble techno

Chaîne conceptuelle :
`Send kick → reverb/delay 100% wet → distortion/saturation → EQ/HP/LP → ducking par kick → mono/width control`.

Le filtre et le ducking déterminent si le rumble est une fondation rythmique ou un brouillard.
