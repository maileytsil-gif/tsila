# Plugin role matrix

Le tableau indique **la fonction**, pas une chaîne obligatoire.

| Besoin | Premier choix | Alternatives | Ne pas faire par défaut |
|---|---|---|---|
| Synthèse kick | Serum 2 / Operator | Drum Sampler/Simpler | empiler plusieurs synthés sans fonction |
| Harmoniques sub → petits systèmes | Waves R-Bass | Saturn 2 / Neutron Exciter | booster uniquement 30–50 Hz |
| Saturation body | Saturn 2 / Ableton Roar/Saturator | Trash / J37 / Supercharger GT | saturer fort le sub sans écoute |
| Transient | Drum Buss / Neutron Transient Shaper | NI Transient Master / CLA-76 parallèle | compresser juste pour « faire punchy » |
| EQ | Pro-Q 4 | EQ Eight / Neutron EQ | cuts fixes sans problème audible |
| Duck kick/bass | Pro-C 3 | Ableton Compressor | release copié d'une recette sans écouter |
| Clip/headroom | Neutron Clipper / Ableton saturation-clipping | Pro-L 2 en sécurité | limiter fort chaque kick |
| Phase kick/bass | écoute + Utility + déplacement/édition | Neutron Phase | inverser la phase au hasard |
| Rumble | ValhallaRoom/VintageVerb/Supermassive/Delay + traitement | Hybrid Reverb/Echo | mettre la reverb directement sur le kick sec sans séparation |
| Final safety | Pro-L 2 | limiter Live | confondre mastering et sound design |
