# Validation protocol

## A. Solo
- absence de click numérique non voulu ;
- transient identifiable à faible volume ;
- tail sans wobble de phase imprévu ;
- saturation comparée à niveau égal.

## B. Kick + basse
- écouter en mono ;
- vérifier plusieurs notes de bassline ;
- alterner polarité uniquement comme test ;
- régler sidechain par groove, pas par valeur cible abstraite ;
- vérifier qu'aucun plugin n'ajoute un tail qui empiète sur la note suivante.

## C. Mix complet
- kick perceptible sans simplement le monter ;
- petits haut-parleurs : présence via harmoniques ;
- casque/monitor : pas d'excès 100–250 Hz ;
- niveau club : sub stable et pas de pompage incohérent.

## D. Mesure
- peak/true peak du print ;
- analyse spectrale comme diagnostic, pas comme objectif visuel ;
- A/B référence à niveau égal ;
- si saturation/clipper : vérifier aliasing et oversampling quand disponible.

## E. Décision
Conserver seulement les traitements qui améliorent au moins une fonction sans dégrader une fonction plus importante.
