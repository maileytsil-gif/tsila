# Recipe — Bass House punch kick [HEUR]

**Objectif :** attaque forte, body dense, tail court pour laisser les basses/growls respirer.

- Fundamental/tail : 50–65 Hz.
- Pitch start : +18 à +36 st.
- Pitch drop : 15–45 ms.
- Amp decay : 90–180 ms.
- Click : présent.

Chaîne suggérée :
`Serum 2 → Saturn 2/Trash sur mids en parallèle → Pro-Q 4 → transient shaper si nécessaire → Utility`

Waves CLA-76 peut être utilisé sur un parallèle punch/click plutôt que sur le sub complet.

Règle : si la bassline possède déjà un sub fort, raccourcir le tail avant d'ajouter davantage de sidechain.
