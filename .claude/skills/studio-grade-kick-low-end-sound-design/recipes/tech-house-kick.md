# Recipe — Tech House kick [HEUR]

**Objectif :** compact, sec, lisible, bassline-first.

- Fundamental/tail : 48–60 Hz.
- Pitch start : +12 à +30 st.
- Pitch drop : 25–60 ms.
- Amp decay : 120–250 ms.
- Click : clair sans dureté excessive.

Chaîne suggérée :
`Operator/Serum 2 → Drum Buss Transients léger → Pro-Q 4 → Pro-C 3 sur la basse (sidechain)`

Alternatives : Neutron Transient Shaper à la place de Drum Buss ; R-Bass seulement si nécessaire.
