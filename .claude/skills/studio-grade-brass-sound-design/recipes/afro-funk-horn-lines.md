# Lignes de cuivres afro et funk (afrobeat, afro house, funk, soul)

Le riff de section qui porte le morceau : unisson, réponses, stabs à contretemps. Sources : Wikipédia « Funk », « Afrobeat » (copies lues) [DOC-W], notes Fela Kuti (extraits) [HEUR-extrait], fiches afrobeat/dancehall lues [HEUR-lu], démo afrobeat (riff chiffré) [DOC fichier lu].

## Cible
`HOOK ou LINE / afrobeat 100–130 BPM, afro house 118–125, funk 90–120 / trio bari + tpt + ténor (Fela) ou 2 tpt + sax + tbn (Phenix Horns) / VOICE OWNS HOOK, BRASS ANSWERS (couplet) puis BRASS OWNS HOOK (instrumental)`

## Écriture
- **Funk** : phrases syncopées à contretemps, « displacement » rythmique, stabs courts dans les espaces entre les mots, introduction en cuivres [DOC-W] ; la section est une percussion accordée (James Brown) [HEUR] ; « on the one » : l'accent commun tombe sur le premier temps.
- **Afrobeat** : riff unisson répété, monté à l'octave pour le « shout » ; stabs harmonisés en tierces/quartes ou tierces/sixtes parallèles ; call-and-response avec la voix et l'orgue ; solos de ténor/trompette en section finale [HEUR-extrait/HEUR-lu].
- Riff de démo (mesure, degré en demi-tons, durée en mesure, vélocité) [DOC fichier] : `(0,5, 0, 0,11, 100) (0,625, +3, 0,11, 92) (0,75, +5, 0,11, 96) (0,875, +7, 0,11, 104) (1,0, +10, 0,55, 108)` → quatre doubles-croches montantes 0–3–5–7 (pentatonique mineure) puis tenue sur la septième mineure sur le temps 1 : un « lick » afrobeat type, à transposer dans la tonalité du Set.
- **Afro house / afrobeats / dancehall** : le cuivre est un marqueur de section (entrée de drop, hook), stabs staccato, lignes unisson, call-and-response ; les guides Keinemusik/Black Coffee lus ne mentionnent pas de cuivres : ne pas en mettre par défaut, seulement si le brief le demande [HEUR-extrait].
- Registre : trompette 60–79 pour le riff, ténor à l'octave ou à la tierce dessous, bari sur la fondamentale ou la quinte ; laisser un trou toutes les 2–4 mesures.

## Son
1. Réel : `horn-section-realistic-sampled.md` (Session Horns Pro, Orchestral Brass, Serum 2 Multisample).
2. Synth brass funk : `analog-poly-brass-80s.md` régime stab (Juno A11/B31) ou `fm-brass-dx7-operator.md` BRASS 2 ; unisson 2–3, chorus I, jamais de reverb longue.
3. Hybride : couche réelle + synth brass à −8 dB pour la présence, mêmes notes.

## Processing [HEUR]
Stabs : `REQ 6 HP 150 Hz, +2 dB 2,5 kHz → API-2500 3:1 attaque 10–20 ms release 0,1 s (garde le « blat ») → slapback 60–120 ms mix 10–15 % ou room courte` ; pas d'effets lourds ; présence 2–4 kHz, section 300 Hz–6 kHz [HEUR-lu]. Sur afro house : sidechain léger au kick, envoi delay 1/8 pointé sur la dernière note du riff.
