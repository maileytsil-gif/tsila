# Grilles par genre — notation Producer Pal (pads C1 kick, D1 snare/clap, F#1 hat fermé, A#1 hat ouvert, autres percs selon le kit)

## Deep / minimal house (120 BPM)
```
v104-112 n/8 C1 1|1,2,3,4                      # kick 4 temps, rond
v70-82 n/16 D1 1|2,4                            # clap/rim 2 et 4 (v62-72 en break)
v70-80 n/16 F#1 1|1.5,2.5,3.5,4.5              # hats contretemps
v28-40 n/16 F#1 1|1.75,2.75,3.75               # ghosts (retirer 1 sur 4 mesures)
v58-66 n/16 A#1 1|4.5                          # open hat « et » du 4 (1 mesure sur 2)
@2-8=1  v0 F#1 4|3.75 v100  A#1 8|4.75          # variation mes. 4, fill léger mes. 8
transforms: timing = swing(0.03, n/16)
```
Percs organiques : cabasa 16es v30–45 sur les 3 dernières doubles du temps, conga basse sur 2.5 et 4, conga douce sur 4.25 ; toutes les 8 mesures une réponse en moins.

## Tech house (126 BPM)
Kick idem plus sec ; clap 2/4 v90 ; rim syncopé 1.75, 3.5 ; hats offbeat v85 + 16es fantômes v35 ; open hat 4.5 chaque mesure ; percs (bongo, shaker) en 16es syncopées, swing 0,04. Fill = ratchet sur la dernière double (`4|4.75: ratchet(2)`).

## Techno (130 BPM)
```
v110-118 n/8 C1 1|1,2,3,4
v88-96 n/16 D1 1|2,4                            # clap ; ou snare sur 2.5 pour un décalage
v72-80 n/16 F#1 1|1x16                          # 16es droites (accents [v90 v60 v70 v60])
v60-70 n/8 A#1 1|1.5,2.5,3.5,4.5               # offbeat ouvert / ride
```
Pas de swing (≤ 0,01) ; variations par soustraction (retirer le clap 1 mesure sur 8), rumble = queue du kick réverbérée en envoi, hats filtrés qui s'ouvrent sur 16 mesures.

## Drum & bass (174 BPM, two-step)
```
v110-118 n/16 C1 1|1,3.5                        # kick 1 et « et » de 3 (variante : 1, 2.75)
v100-110 n/16 D1 1|2,4                          # snare 2 et 4
v30-45 n/16 D1 1|1.75,3.25,4.75                # ghosts
v70-84 n/16 F#1 1|1x8@n/8                       # 8es (ou 16es v50 en fantômes)
v60 n/16 A#1 1|2.5
```
Swing 0,02 sur les ghosts seulement ; fill toutes les 8 mesures (snare 4.25, 4.5, 4.75 en montée) ; superposer un break samplé (Amen/Think) découpé, filtré HP 200 Hz, au niveau des ghosts.

## Électro / breaks 808 (128 BPM)
```
v108-116 n/16 C1 1|1,2.5,3.75  2|1,2.5,4        # kick cassé sur 2 mesures
v96-104 n/16 D1 1|2,4                           # snare/clap 808
v66-76 n/16 F#1 1|1x16                          # 16es 808 [v90 v55 v70 v55]
v70 n/8 A#1 1|2.5,4.5                           # ouverts en syncope
v50 n/16 C2 1|3.25                              # cowbell/rim 808 occasionnel
```
Silences voulus (retirer 1 kick sur 4 mesures), tom 808 descendant en fill, swing 0.

## Règles communes
Downbeats exacts (pas d'humanisation du kick sur le 1) ; vélocités en plages (`v70-82`) ; une variation toutes les 4 mesures, une plus grande toutes les 8 ; fill sur la dernière mesure avant un drop ; retirer plutôt qu'ajouter pour créer le contraste ; relire le clip ; kick ≈ −3 dB avant fader, clap ≈ −6, hats ≈ −12, percs ≈ −12 à −15.
