# South-American club adaptation

Ne pas écrire « Latin America = clave ». L'Amérique du Sud contient des familles métriques, timbrales et historiques très diverses.

[HEUR] Processus :
1. nommer le pays/région/style de référence ;
2. identifier 1 principe rythmique documenté ;
3. identifier 1 principe mélodique/harmonique ;
4. traduire chacun dans un rôle électronique ;
5. conserver la house/techno foundation explicite si c'est un hybrid.

Exemples de branches pouvant nécessiter recherche dédiée avant sortie : samba, carimbó, baião, cumbia, champeta, joropo, chacarera, tango/nuevo tango, etc.
