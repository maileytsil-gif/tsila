# Ableton Live workflow

1. `GUIDE` track : clave/timeline/bell pattern ou pulse de référence ;
2. `KICK/LOW` ;
3. `MID PERC A/B` ;
4. `HIGH CLOCK` ;
5. `BASS` ;
6. `CHORD/OSTINATO` ;
7. `VOCAL/CALL` ;
8. `FX`.

[HEUR] Programmer d'abord sans Groove Pool. Une fois le rythme compris, tester groove extraction/apply, microtiming ou velocity humanization.

[HEUR] Créer trois scènes : `GRID`, `POCKET`, `LOOSE`. Ne déplacer que 1–2 classes d'événements à la fois.

[TEST] Les transients de percussion peuvent rendre un groove objectivement plus tôt/tard que son MIDI ; valider à l'oreille et par waveform.

[HEUR] Pour les instruments : Drum Rack/Drum Sampler pour les rôles percussifs, Simpler/Sampler pour organiques, Operator/Drift/Wavetable/Serum 2 pour synth percussion/chords/bass selon le besoin.
