# Source authority

Ordre de préférence :
1. ressources pédagogiques/archives de référence (Smithsonian Folkways, Berklee, institutions historiques) ;
2. témoignages/interviews d'artistes et acteurs de scène ;
3. documentation de plateformes spécialisées pour classifications/évolution de scène (Beatportal/Beatport) ;
4. analyse secondaire ;
5. tutoriels producteurs — seulement comme `[HEUR]`, jamais comme preuve historique.

Toute affirmation sur une tradition doit rester aussi précise que la source : ne pas étendre un cas cubain à « toute la musique latine » ou un cas sud-africain à « toute la musique africaine ».
