# Jamaican reggae / dub-informed electronic composition

[DOC] Smithsonian décrit des liens entre traditions de drumming jamaïcaines, ska, rocksteady et reggae ; les signatures incluent syncopations, interaction basse/guitare et bounce clavier.

[HEUR] Pour House/Downtempo :
- chords courts sur offbeats ;
- basse plus mélodique/longue que le chord stab ;
- grands espaces dans la partie médium ;
- delay/reverb comme événements, pas comme nappage constant ;
- retirer des éléments pour créer le dub space.
