# Outils tiers — références utiles dans le setup

Ce fichier ne rend pas le skill dépendant de ces plug-ins. Il traduit leurs fonctions en décisions.

## FabFilter Pro-Q 4 [DOC]

Modes de traitement documentés : Zero Latency, Natural Phase, Linear Phase. **Linear Phase n'est pas un mode de qualité supérieur universel** ; il répond à des besoins spécifiques et peut changer le comportement temporel. Utiliser le mode le plus simple qui résout le problème.

Dynamic EQ : utile lorsqu'une bande doit agir en fonction du niveau/événement plutôt qu'en permanence. Spectral Dynamics fournit une action plus fine dans une bande selon le contenu. Toujours comparer à la correction statique la plus simple.

Sources :
- https://www.fabfilter.com/help/pro-q/using/processingmode
- https://www.fabfilter.com/help/pro-q/using/dynamic-eq

## FabFilter Pro-C 3 [DOC]

Attack, release et lookahead contrôlent le comportement temporel ; un external sidechain permet un déclenchement externe. Pour du ducking kick/bass, choisir les temps avec la longueur du kick et le groove, pas via une valeur mémorisée.

Sources :
- https://www.fabfilter.com/help/pro-c/using/timecontrols
- https://www.fabfilter.com/help/pro-c/using/sidechain

## Waves CLA-3A [DOC]

Le plug-in reprend une logique de leveler/compressor avec contrôles de gain/peak reduction et options documentées par Waves. L'utiliser lorsqu'une compression/nivellement de caractère est souhaitée, pas comme solution générique à tous les problèmes dynamiques.

Source : https://www.waves.com/1lib/pdf/plugins/cla-3a-compressor-limiter.pdf

## Valhalla [DOC + HEUR]

Les algorithmes/modes de reverb sont des outils d'espace. [HEUR] Dans un mix Bass House, séparer une reverb courte de texture d'une queue plus longue peut garder le groove plus lisible. Le temps de predelay et le decay doivent être ajustés au tempo et au rôle, pas imposés par une recette.

Source produit : https://valhalladsp.com/shop/reverb/valhalla-vintage-verb/
