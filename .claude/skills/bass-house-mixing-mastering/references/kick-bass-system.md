# Kick / Bass — système de diagnostic

## Étape 1 — Timing avant fréquence

Solo kick + sub/mid-bass. Observer/écouter : longueur du kick, début/fin des notes de basse, chevauchement, sensation de trou après ducking. Le conflit peut être temporel même si le spectre semble « propre ».

Tests réversibles :
- raccourcir temporairement le sub ;
- déplacer/écourter une note ;
- bypasser le sidechain ;
- utiliser une source de sub simple ;
- inverser/ajuster phase uniquement si l'outil et le contexte le permettent et comparer à l'oreille/mesure.

## Étape 2 — Rôles

Définir qui fournit :
- impact/transient ;
- poids/fondamentale ;
- harmonique audible sur petits systèmes ;
- mouvement/growl.

Un même son peut cumuler des rôles, mais les conflits doivent rester compréhensibles.

## Étape 3 — Ducking

**Sidechain externe [DOC]** : le kick déclenche un compresseur ou dispositif de gain. Utile quand la réponse doit suivre l'amplitude/événement du kick.

**Courbe synchronisée [HEUR]** : shaper/LFO/automation de volume. Utile quand une forme déterministe est voulue. Ne pas appeler cela sidechain externe si aucun signal externe ne pilote la détection.

Réglage : choisir profondeur, attaque/forme et retour selon la longueur du kick et la sensation rythmique. Une valeur de 4–7 dB peut être un exemple de départ dans certains mixes, pas une cible.

## Étape 4 — Spectre

Après timing :
- repérer les masquages persistants ;
- réduire une zone seulement s'il existe une raison audible/mesurable ;
- traiter éventuellement de façon dynamique si le conflit n'existe qu'à certains moments ;
- vérifier l'effet à niveau compensé.

## Étape 5 — Harmoniques et traduction

Si le sub disparaît sur petits systèmes, créer/équilibrer des harmoniques via saturation, distorsion ou une couche mid-bass. Ne pas augmenter seulement le sub inaudible.

## Étape 6 — Mono

Contrôler le bas en mono et la corrélation/phase si les outils sont disponibles. [HEUR] La stabilité du très grave est généralement plus importante que sa largeur. Si Utility Bass Mono est utilisé, choisir sa fréquence par écoute/mesure plutôt qu'une valeur fixe.
