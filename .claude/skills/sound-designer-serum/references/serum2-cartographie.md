## 1. Architecture et flux du signal

```
MIDI in ──► [KEYBOARD : Transpose · Key · Scale · Swing · OSC Mapping]
        ──► [CLIP player (12 clips)] ──► [ARP (12 slots)] ──► voix de synthèse
        MIDI OUT (Off / Clip Player / On), réglé dans les modules CLIP et ARP (p. 239, 264-265)

Par voix :
  SUB ─┐                                 ┌─► FILTER 1 ─┐
  OSC A ┤  routage par canal :           │             ├─► FILTER 1→2 (série) ou 1 ∥ 2 (parallèle)
  OSC B ┤  Filter (répartition F1/F2)  ──┤             │
  OSC C ┤  Main · Direct · None          └─► FILTER 2 ─┘
  NOISE ┘        │                                     │
                 │ envois BUS 1 / BUS 2 (par osc et par filtre)
                 ▼                                     ▼
Somme des voix ─► rack FX MAIN ─────────────────────► MAIN (bouton MAIN, haut droite) ─► sortie
                  rack FX BUS 1 ─► Main / Direct / Bus 2
                  rack FX BUS 2 ─► Main / Direct / Bus 1
Direct = contourne filtres ET effets.
```

Faits structurants `[DOC]` : 5 sources par voix (SUB, A, B, C, NOISE) `[DOC p. 39]` ; A, B et C ont chacun 5 moteurs (Wavetable, Sample, Multisample, Granular, Spectral), choisis par menu déroulant `[DOC p. 17]` ; 2 filtres par voix, série ou parallèle, un osc peut aller dans l'un, l'autre ou les deux `[DOC p. 16]` ; 4 enveloppes ; 10 LFO ; 8 macros ; 64 slots de matrice ; 13 effets + 3 splitters sur 3 racks (MAIN, BUS 1, BUS 2), plusieurs instances du même effet possibles, ordre libre. Les effets opèrent sur **la somme des voix**, pas par voix (« paraphonique », manuel p. 159). N'importe quel oscillateur ou filtre peut être **source de modulation** (audio-rate) : routage None pour un osc qui ne sert qu'à moduler, warps FM / PD / AM / RM depuis B, C, Noise, Sub, Filter 1, Filter 2 `[DOC p. 31, 54–56]`.

Routage `[DOC p. 31]` : **Filter** = FILTER 1, FILTER 2 ou un dosage des deux ; **Main** = sortie principale, **passe par les effets** ; **Direct** = contourne filtres et effets, joue « clean » à côté du Main ; **None** = aucune sortie (osc utilisé seulement comme modulateur). Par défaut OSC A → FILTER 1, **mais FILTER 1 est éteint dans un preset neuf** ; les autres osc et les filtres → Main. Sortie : bouton **MAIN** en haut à droite, vumètre stéréo à côté `[DOC p. 27]`. Init Preset = OSC A seul (wavetable, la scie par défaut), avec enveloppe et LFO de base déjà assignés `[DOC p. 18, 20]`.

Le fichier d'état `[BIN]` reflète exactement cette structure : 162 sections, `Oscillator0..4` (A, B, C, NOISE = 3, SUB = 4), `VoiceFilter0..1`, `Env0..3`, `LFO0..9`, `Macro0..7`, `ModSlot0..63`, `FXRack0..2`, `RoutingSlot0..6` (5 sources + 2 filtres), `Global0`, `VoicePanel0`, `Arp0`, `ArpClip0..11`, `MidiClip0..11`, `ClipPlayer0`, `PitchQuantizer0`, `RetriggerState0`, `LFOPointModBus0..15`.

## 2. Interface : fenêtre, onglets, zones fixes

### 2.1 Fenêtre `[LOCAL]` `[DOC p. 24–27, 36]` `[EXTRAIT]`

- Redimensionnable : glisser le **coin inférieur droit**, ou clic sur le **logo Serum 2 (haut gauche)** › option de taille ; **Set x% as Default** fait de la taille courante le défaut, **Default (100%)** y revient `[DOC p. 36]`. Jusqu'à 200 % `[EXTRAIT]` (le manuel ne donne pas de plafond). Sur ce Mac, la fenêtre pilotée par clics fait **1190 × 759** ; toutes les coordonnées ci-dessous sont dans cette capture `[LOCAL]`.
- Ce qui passe en arrière-plan depuis Live : **toggles** (SUB, OSC, MONO, LEGATO), **onglets**, **navigateur de presets**, double-clic de preset. Ce qui ne passe pas : saisie d'une valeur (le champ s'ouvre au double-clic mais Entrée n'arrive pas), glisser d'un bouton → le dire à l'utilisateur ou passer en plein écran `[LOCAL]`.
- Undo/redo de presque toute opération (bouton, forme de LFO…) : **boutons undo et redo dans l'en-tête, en haut à droite**, pas dans le menu logo `[DOC p. 27]`. Tooltips au survol ; sur un contrôle modulé, ils listent ses sources de modulation ; il faut la préférence **Help tooltips = SHOW** (page GLOBAL, active par défaut) `[DOC p. 24]`. Clic droit = menu contextuel sur presque tout contrôle `[DOC p. 26]`.

### 2.3 Zones fixes, quel que soit l'onglet

- **Haut** : nom du preset (clic sur « - Init - » = menu des presets) avec flèches ‹ › qui parcourent le sous-dossier du preset courant ; petite barre verte sous le nom pendant le chargement des gros presets (multisamples) `[DOC p. 18]`. Champs **ARTIST** et **DESC** sous le nom (double-clic pour saisir) ; bouton **disquette** à gauche du nom = Save (dialogue, le nom du fichier devient le nom du preset ; **Option/Alt-clic = écrase sans dialogue**) ; bouton **Embed** pour embarquer table ou sample (pas le contenu d'usine) `[DOC p. 21–22]`. Icône liste (1010, 36), à côté du menu principal, ouvre le **navigateur** (arbre Factory › Arp / Bass / Bell / … / Drum, double-clic pour charger) `[LOCAL]` `[DOC p. 18]` ; bouton lecture = pré-écoute du clip embarqué par l'auteur du preset, sinon d'un clip de repli (3 au choix), auto-preview possible `[DOC p. 19]`. **Menu principal** (haut droite) : Init Preset, Save MIDI Map… `[DOC p. 20, 27]` ; **logo Serum 2** (haut gauche) : redimensionnement `[DOC p. 36]` ; préférences et dossier des presets `[EXTRAIT]` (le manuel met les préférences sur la page GLOBAL `[DOC p. 27]`). **Undo / redo** et bouton **MAIN** (volume + vumètre) en haut à droite `[DOC p. 27]`. **Export audio par glisser** : survoler la gauche du logo, glisser l'icône d'onde vers une piste audio = WAV de la dernière note ou du dernier accord (hauteur, vélocité, durée), rendu en silence, copie dans `Serum Presets/Renders` ; Option/Alt-clic sur l'icône ouvre Renders ; Shift-glisser copie le preset sauvé courant vers le Finder `[DOC p. 22–23]`.
- **Bas gauche** : panneau des **enveloppes** (tuiles ENV 1–4 ; lectures ATK / HOLD / DEC / SUS / REL ≈ x 200 / 255 / 308 / 362 / 413, y 593 pour ENV 1) `[LOCAL]`.
- **Bas centre** : panneau des **LFO** (tuiles LFO 1–6 ; **7–10 n'apparaissent qu'après usage du LFO 6**, manuel) `[DOC]`, avec graphe dessinable et ses commandes (§ 7.2).
- **Bas droite** : **MACRO 1–8**, **voicing** (section VOICING `[DOC p. 43]` : MONO (1058, 627), LEGATO (1058, 653), POLY) et **portamento** (PORTA (1081, 720), curve, Always, Scaled) `[LOCAL]` `[DOC]` ; à côté, le panneau **Velocity/Note** (« more modulation options ») et les **molettes** pitch et mod à l'écran `[DOC, What's New p. 4]`.
- **Clavier** en bas avec ses trois modes d'affichage, KEYBOARD / CLIP / ARP (touches vertes = clips, violettes = arps) et ses réglages Transpose · Key · Scale · Swing · OSC Mapping (§ 10) `[DOC]`. Clic sur une touche = joue la note ; le clavier montre aussi les notes reçues (MIDI externe) et celles du clip player et de l'arpégiateur. Libellés : **TRANSPOSE** (demi-tons, sur toutes les notes entrantes et générées), **KEY** (surtout pour CLIP et ARP), **SCALE** (notes hors gamme ramenées dans la gamme), **SWING** (grille des éditeurs CLIP et ARP), **OSC MAPPING** (plages de notes et de vélocités des osc et de l'arpégiateur) `[DOC p. 25]`.
- Sur la page OSC, interrupteurs marche/arrêt : SUB (11, 101), OSC A (86, 101), OSC B (356, 101), NOISE (896, 101), FILTER 1 (996, 101) `[LOCAL]`. OSC C et FILTER 2 : **MUET** sur leurs coordonnées (à relever sur une capture). Osc, SUB, NOISE : clic sur l'étiquette entière (nom + bouton), vert = actif, panneau grisé quand éteint ; **FILTER : clic sur le bouton power lui-même** `[DOC p. 28, 124, 129]`. Bouton de routage en haut à droite de chaque panneau d'osc et de filtre `[DOC p. 31]` : coordonnées **MUET**.

### 2.4 Gestes sur les boutons, menus contextuels, MIDI Learn `[DOC p. 25–36]` `[DOC, manuel web « Using Knobs and Sliders »]`

- Glisser vertical ou horizontal (pop-up de valeur) ; **Shift** = réglage fin ; molette de la souris = ajustement sans pop-up ; **double-clic** = champ texte pour saisir la valeur exacte (préférence GLOBAL : double-clic = reset à la place) ; **⌘-clic** (Ctrl-clic Windows) = **Reset Control** (valeur par défaut) `[DOC p. 25–26]`.
- Menus déroulants (table, sample, bruit, type de filtre, warp) : flèches ‹ › = option précédente / suivante sans ouvrir le menu ; survol + molette = défilement `[DOC p. 29, 40, 49, 129]`.
- **Clic droit** sur presque tout contrôle : choisir une ou plusieurs sources de modulation (ENV 1, LFO 2…), bypass ou retrait d'un modulateur, retrait de tous ; **Reset Control** ; **MIDI Learn** (attend un CC, se désactive dès réception ; l'assignation est sauvée avec le preset mais **ne se recharge que si la préférence « Load MIDI Map from Preset » est activée**, désactivée par défaut) ; **Lock Parameter** (la valeur ne change plus au chargement d'un preset, reste réglable à la main) `[DOC p. 26–27]`. Lock Parameter décrit par le manuel 2.0.18 ; le changelog 2.0.21–2.0.22 a retiré le verrou individuel de la plupart des paramètres (FX, puis osc sauf coarse / pan / level, enveloppes, mixer, portamento, matrice) → verrous par groupe (§ 13, `serum2-automation-et-migration.md`).
- Carte MIDI par défaut : menu principal › Save MIDI Map › `Serum 2 Presets/System/MIDI CC Maps/default.SerumMIDIMap`, chargée à chaque nouvelle instance et à Init Preset, **et à chaque changement de preset quand « Load MIDI Map from Preset » est désactivée** `[DOC p. 27]`. Dans une session DAW, les CC sont sauvés et rappelés avec la session.
- **Menu d'un module** (clic droit sur l'étiquette OSC A/B/C, SUB, NOISE, FILTER) `[DOC p. 33–36]` :
  - **Lock Module** : le module ne change plus au chargement d'un preset ; on peut ensuite déverrouiller des contrôles un par un (ex. WT POS) ; Init Preset lève tous les verrous de module.
  - **Init Module** : remet le module à zéro, **modulations assignées comprises**, sans toucher au reste.
  - **Copy** / **Copy (w/mods)** / **Paste** : presse-papiers interne, marche entre presets et après Init, reste disponible pour plusieurs collages ; **impossible d'une instance de Serum à une autre**.
  - **Enable Pitch Tracking** (on par défaut) ; **Pitch Bend Tracking** (§ 3.1).
- Navigation rapide des presets : survoler le menu des presets et tourner la molette `[DOC, What's New p. 7]`.

### 3.2 Moteur Wavetable `[DOC p. 37–49]` `[BIN]`

- Tables **multi-cycles** ; lecture sans repliement audible jusqu'aux limites de l'oreille, au prix de CPU au chargement et en jeu (optimisations SSE) `[DOC p. 37]`.
- **Table** : menu (usine 288+ tables, dossiers `S2 Tables/…`, `Analog/…`, `Digital/…`, etc. ; « --- » = table éditée non sauvée, icône disquette pour la sauver) ; ‹ › = table précédente / suivante, survol + molette `[DOC p. 40]`. **Embarquement au choix**, pas automatique : bouton Embed à l'enregistrement ou clic sur le nom de la table › **Embed in Preset** ; utile surtout pour partager un preset ; impossible pour le contenu d'usine `[DOC p. 22]`. Jusqu'à **256 frames de 2048 échantillons** en 32 bits (2 Mo exactement) `[DOC p. 38]`. Clic sur la forme d'onde = bascule 2D / 3D : 2D = une frame, montre le warp en temps réel ; 3D = toutes les frames en vert, interpolées en gris, courante en jaune ; numéro de la frame courante en bas à gauche `[DOC p. 39]`. Loupe en haut à droite de l'affichage (grisée tant qu'on ne la survole pas) = éditeur (§ 3.8) `[DOC p. 40]`.
- **WT POS** 1–256 (`kParamTablePos`), la frame audible ; 1 = première frame `[DOC p. 45]` ; clic droit → « Smooth Interpretation » (sic, = interpolation lisse : « smoother waveform transitions without being destructive » `[DOC p. 45]`, « perfect table transitions without morph tables » `[DOC, What's New p. 7]`). Interpolation entre frames : crossfade (mix blend) ou **spectral morphing** (fréquence + phase), choisie dans l'éditeur, calculée au chargement ; le preset embarque le type d'interpolation, pas les frames interpolées `[DOC p. 38]`.
- **WARP 1 et WARP 2** (dual warp, nouveau) : chaque warp = menu (OFF par défaut, clic sur le nom du mode, ‹ › pour changer sans ouvrir) + bouton de quantité 0–1 (`kParamWarp`, `kParamWarp2`) + bouton VAR selon le mode (`kParamWarpVar/2` ; en Sync, fader **WARP Var** sous le menu `[DOC p. 50]`) `[DOC p. 49]`. Liste complète des modes au § 4.
- **PHASE** 0–360° (`kParamInitialPhase`) : position de départ à chaque note, comme un sample start `[DOC p. 41]` ; 0 % et 50 % sont les passages par zéro d'un sinus (sinon clic avec attaque rapide) ; audible aussi entre plusieurs osc sans RAND (annulations de phase) ; en vue 2D, un trait jaune montre le point de départ `[DOC p. 42]`. **RAND** 0–100 % (`kParamRandomPhase`) : décalage aléatoire de PHASE à chaque nouvelle voix, supprime le « zap laser » de l'unisson (disparu à 100 %), varie clic et timbre entre osc superposés `[DOC p. 42–43]`. **Phase Legato** (clic droit sur PHASE) inverse le comportement par défaut, hérité de Serum 1 et anti-clic : phase **non réinitialisée** quand LEGATO est off et qu'une voix est volée, **réinitialisée** quand LEGATO est on en jeu polyphonique (zap audible) `[DOC p. 43]`. Mémoire de phase (menu) : **All Voices** (défaut, PHASE et RAND pour toutes les voix) · **Contiguous** (la note repart de la phase de la précédente) · **Per Voice** (même phase éditable à chaque note ; choisi pendant qu'une note sonne, capture la phase de la plus récente) `[DOC p. 44]` ; internes `kParamPhaseMemory` `kPerVoice` / `kContiguous` ; « Mem » dans Serum 1 à 100 %.
- `kParamXfadeMode`, `interpolateAfterLoad` 0–2 : mode d'interpolation embarqué dans le preset `[BIN]`.

### 3.3 Moteur Sample `[DOC]` `[EXTRAIT]` `[BIN]` `[USINE]`

Lecteur d'un fichier, avec slicing relié au module CLIP et conversion en wavetable `[DOC p. 68]`.

- **Chargement** : en-tête de l'osc › Sample `[DOC p. 69]` ; menu déroulant = samples d'usine tonals et non tonals (dossiers `Samples/Factory/…` et `Factory Non-Tonal/…`), **tables Serum chargeables comme samples**, **Load Sample** (dialogue) ; une fois chargé, le même menu montre le fichier sur le disque ou le recharge `[DOC p. 70]`. Glisser-déposer : un fichier audio lâché sur l'affichage de forme d'onde offre la zone **Switch OSC type** (import direct en Sample, Granular ou Spectral, sans créer de wavetable) `[DOC p. 291, 294]`. **Un seul sample pour Sample, Granular et Spectral** : passer d'un de ces moteurs à l'autre garde le fichier `[DOC p. 69, 86, 105]`.
- **Formats** : FLAC/WAV ; le manuel donne des exemples en `.flac` et lit la hauteur dans le chunk instrument d'un WAV `[DOC p. 68]` ; liste complète des formats audio acceptés : **MUET**.
- **Note racine** : C3 par défaut (convention MIDI 69 = A3 = 440 Hz) ; sinon nom de note **en fin de nom de fichier**, précédé d'un **espace ou d'un souligné** (aucun autre séparateur), dièse ou bémol (`Morning Bass F2.flac` ; `Ashes Piano Eb3.flac` = `Ashes Piano D#3.flac`) ; Serum lit aussi la hauteur du chunk instrument d'un WAV `[DOC p. 68]`. Base note / gain / trim head-tail stockés avec le fichier `[BIN]` ; key tracking (§ 3.1).
- **Start / End** (0–100 %, accolade bleue `[EXTRAIT]`) : survoler le sample, glisser l'un des deux marqueurs, à gauche ou à droite `[DOC p. 71]` ; le manuel ne dit « bleus » que les marqueurs de boucle `[DOC p. 77]`.
- **Menu clic droit sur le sample** (le même en Granular et Spectral) `[DOC p. 71–73]` : **Show Marker Animation** (start, end, loop start, loop end bougent avec leurs modulations ; on ne peut plus les glisser) · **Zoom to Start and End** (bascule ; coché = sample entier, zoom souris bloqué ; décoché = glisser haut/bas zoome, gauche/droite fait défiler) · magnétisme des points start/end/boucle **Snap Off · Snap to Zero** (passages par zéro, anti-clic) **· Snap to Beats** (grille du tempo du morceau) **· Snap to Loop** (start/end aimantés aux points de boucle déjà définis) — c'est la « détection de boucle snap » `[EXTRAIT]` d'avant, pas une détection automatique · **Fade Edges** (None, 1 à 128 ms) · **Normalize** · **Reverse** · **Trim** (coupe aux marqueurs start/end) · **Slicing Off / Slice Auto / Slice Manual**. Fade Edges, Normalize, Reverse et Trim **non destructifs** : boutons undo/redo ; **Reload Sample** (menu du sample) efface toutes les opérations `[DOC p. 73]`.
- **Menu de boucle** (le même en Granular et Spectral) `[DOC p. 77–78]`, `kParamLoopMode` `[BIN]` : **One-shot** (lecture avant pendant la durée de la note) · **Fwd Loop** (`kForward` : start → loop end, puis boucle depuis loop start) · **Rev Loop** (`kReverse` : arrivé à loop end, repart en arrière et boucle à l'envers) · **Fwd/Rwd Loop** (`kPingPong` : aller-retour ; lecture continue depuis start jusqu'à la boucle) · **Tailed** (`kTailed` : la queue, de la moitié à la fin du sample, est bouclée pendant la décroissance). Options du même menu : **Relative Loop** (la boucle suit le marqueur start ; pour moduler le start), **Link Loop Length** (loop end suit loop start, longueur constante ; pour moduler loop start), **Exit Loop on Release** (ex-« loop ends at release » : en phase de release, sort de la boucle et joue jusqu'à la fin du sample).
- **Loop Start / End** : marqueurs **bleus** en haut de l'affichage (glisser entre les deux = déplacer la boucle) ou champs **LS** / **LE** (glisser ; double-clic = saisie) ; réglables pendant que la note boucle ; modificateur de reset (⌘/Ctrl-clic ou double-clic selon GLOBAL) entre les marqueurs = boucle ramenée aux marqueurs start/end ; au glisser, la boucle ne sort pas de start/end, mais par glisser, automation ou modulation **loop end avant loop start inverse le sens de la boucle** `[DOC p. 79]`.
- **Loop crossfade** (0–63 % observé `[USINE]`) : bouton dédié, glisser vers le haut ; courbe bleu clair `[DOC p. 79]`.
- **SCAN** (ex-« Rate » : vitesse et sens de lecture ; tape-stop, lecture inversée) `[DOC p. 80]` ; son menu : **Range** ±200 % (défaut) · ±400 % · ±800 % ; **Reverse** (sens inversé, automatisable et modulable) ; **Lock Scan Rate (to Tempo)** ; **Sample Length to BPM** (longueur calée sur le tempo de l'hôte, SCAN devient **RATE**, réglé en temps et mesures) `[DOC p. 80]`. Pas de Key Track cité ici, contrairement à Granular et Spectral `[DOC p. 80, 100, 116]`. **Base tempo** (`kParamBaseTempo`, 138–156 observé `[USINE]`).
- **Slicing** (même procédé en Sample, Granular et Spectral) `[DOC p. 74–76]` : **Slice Auto** = ligne horizontale **jaune** du seuil de sensibilité (plus bas = plus de tranches ; `kParamAutoSliceThreshold` `[BIN]`), survoler une tranche affiche sa note, glisser haut/bas ou molette = zoom, gauche/droite = défilement. **Slice Manual** = découpe automatique puis poignées à déplacer ; **Option/Alt-clic** ajoute une tranche, sur une tranche existante la supprime ; zoom à la molette seulement. Options : **Play Slice to End** (joue jusqu'à la fin du sample, sinon arrêt au marqueur suivant) ; **Play Single Slice** (une seule tranche pour toute note, vitesse selon la note ; la destination de modulation « single slice » choisit la tranche ; avec Play Slice to End = tout le sample sur n'importe quelle note) ; **Root Note** (note de la 1re tranche, un C de C-1 à C8 ; `kParamSlicingRootNote`) ; **Send to Selected Clip (x)** (tranches envoyées au clip sélectionné du module CLIP, Clip 1 par défaut, notes successives depuis la Root Note) ; **Auto-Sync to Clip** (idem, et le clip se met à jour quand le découpage change).
- **Unison** (volet propre) `[DOC p. 81–83]` : MODE, STACK, WIDTH, RANGE comme § 3.1, plus **START** (décalage **aléatoire** du point de départ pour chaque voix d'unison) et **SPAN** (décalage **fixe** du départ par voix), WARP 1 / WARP 2 (étalement du warp par voix) ; DETUNE et BLEND sur le panneau.
- **Random start** (0–100 %) : absent du manuel 2.0.18 ; peut-être le START d'unison `[HEUR]`.
- **Reverse** : opération non destructive du menu clic droit `[DOC p. 73]` ou Reverse du menu SCAN, modulable `[DOC p. 80]`.
- **Warps** (§ 4) : WARP 1 et 2, menu (OFF par défaut), flèches ‹ › pour changer de mode sans ouvrir le menu, bouton = profondeur ; le manuel renvoie à la liste générale (p. 49), sans liste propre au Sample `[DOC p. 83]`.
- **Switch to Wavetable** (menu Sample › survoler) : mêmes options que l'import audio → table, **DYNAMIC PITCH - ZERO SNAP** · **DYNAMIC PITCH - FOLLOW** · **FREQUENCY ESTIMATION** · **Constant framesize (PITCH AVERAGE)** (« If in doubt, try this one first! ») · **FFT 256/512/1024/2048** ; l'osc passe en Wavetable avec la table convertie `[DOC p. 84, 292–294]`. Une wavetable n'est pas un sampler : pour du réaliste, rester en Sample `[DOC p. 291]`.
- Officiel `[DOC, What's New p. 8]` : points start/end et loop start/end **modulables**, crossfade aux points de boucle, slicing Auto/Manual « with advanced options », modes de lecture, **« forward-reverse looping tails for real time stretching »**, warps FM et PM ; les mêmes fonctions existent en Granular et en Spectral.

### 3.4 Moteur Multisample `[DOC]` `[BIN]` `[USINE]`

Charge un **SFZ** (`sfzPathRelative`, usine `Multisamples/Factory/{Synth, Strings, Keys, Choir, Mallet, Plucked, Winds, Brass…}/*.sfz` ; texte SFZ embarqué dans le preset, 4 à 234 fichiers FLAC par instrument). Serum choisit le sample d'après **la hauteur et la vélocité** de la note `[DOC p. 58]`.

- **Chargement** : en-tête de l'osc › Multisample ; affichage vide tant qu'aucun instrument ; menu déroulant = instruments d'usine, ou **Load SFZ** `[DOC p. 58–59]`. SFZ = fichier texte qui mappe des samples (WAV…) sur notes, vélocités et autres paramètres MIDI, avec couches dynamiques, key switches, round robins, articulations ; Serum lit les **paramètres d'enveloppe SFZ** `[DOC p. 59]`. **SF2 non pris en charge** : le convertir en SFZ avec un outil tiers `[DOC p. 59]`.
- **Affichage** : les samples de l'instrument ; la note jouée surligne son sample (hauteur × vélocité) ; clic dans l'affichage = forme d'onde de la dernière note `[DOC p. 60]`.
- **Enveloppe propre** (bouton du volet ; volet désactivé au départ) : **OVERRIDE** (« Env Override ») active le graphe et **remplace l'enveloppe du fichier SFZ** (définie par note, par groupe ou globale) `[DOC p. 61]`. Le manuel ne dit pas qu'elle remplace ENV 1 : lien avec ENV 1 **MUET**. Boutons **DELAY** (ms ; clic droit › **BPM Sync** = en temps et mesures), **A**, **H**, **D**, **S**, **R** ; points aussi déplaçables dans le graphe `[DOC p. 61–62]`.
- **VEL TRACK** (0–100 % + override `[BIN]`) : sensibilité à la vélocité ; activer d'abord le suivi, puis glisser dans le champ `[DOC p. 62]`.
- **RAND** (Random phase) : phase initiale aléatoire du sample, comme dans les autres modes `[DOC p. 62]`.
- **TIMBRE** (`kParamTimbreShift` −18…+64 `[BIN]`) : sur un multisample à zones, inverse le rapport entre note jouée et sample mappé (une note plus aiguë déclenche un sample mappé plus grave, et inversement), d'où un timbre inhabituel `[DOC p. 63]` ; « adjust and modulate the timbre » `[DOC, What's New p. 9]`. Il décale donc la **zone de clavier** utilisée (pas une « couche » de vélocité) ; « sans changer la hauteur » n'est pas écrit dans le manuel `[HEUR]`.
- **Unison** (volet) : MODE, STACK, WIDTH, RANGE, WARP 1 / WARP 2 (ni START ni SPAN ici) ; DETUNE, BLEND sur le panneau `[DOC p. 63–66]`.
- **Warps** (§ 4) : menu (OFF par défaut), flèches ‹ ›, bouton de profondeur ; renvoi à la liste générale p. 49 `[DOC p. 66]`. PAN, LEVEL `[DOC p. 66]`.
- **Switch to Single Sample** (menu Multisample, après avoir joué une note) : l'osc passe en **Sample** avec la dernière note jouée ; ensuite Switch to Wavetable possible (§ 3.3) `[DOC p. 67]`.
- Vu par la presse comme « un peu gadget », mais c'est le moteur des 155 presets d'usine « Multisample » `[USINE]`.

### 3.5 Moteur Granular `[DOC]` `[BIN]` `[USINE]`

Jusqu'à **256 grains** `[DOC, What's New p. 9]`. « Granular synthesis can be CPU intensive », surtout face aux modes Wavetable, Sample et Multisample `[DOC p. 85]`.

- **Chargement, start/end, opérations** : comme Sample (§ 3.3), sample partagé avec Sample et Spectral `[DOC p. 85–88]`.
- **Menu de boucle** : la plupart des options du Sample `[DOC p. 89]`, plus **Loop Grains** (la lecture des grains respecte les marqueurs de boucle) et **Manual** (la tête de lecture devient un point rouge **X|Y**, SCAN règle sa position horizontale, la note ne balaie plus le sample ; glisser une source de modulation sur le point module la position ou le paramètre de l'axe Y ; **pas de slicing en Manual**) `[DOC p. 89]`. LS / LE comme Sample `[DOC p. 90]`. **Crossfade** : appliqué à la lecture de chaque grain, **sans effet si Loop Grains n'est pas coché** `[DOC p. 90]`.
- **SCAN** (vitesse de la tête : élevé = départs de grains étalés, moins de recouvrement ; bas = étirement, drone ; négatif = inversé, 0 = figé) `[DOC p. 99]` ; menu : **Range** ±200 % (défaut) · ±400 % · ±800 %, **Reverse** (modulable), **Key Track** (vitesse proportionnelle à la hauteur de la note), **Lock Scan Rate (to Tempo)**, **Sample Length to BPM** (SCAN → RATE en temps et mesures) `[DOC p. 100]` ; `kParamScanRate`, `kParamScanRange` ; sync BPM `kParamScanBPMRate/Divide/TempoLock`.
- **DENS** (cadence de génération des grains ; 0–800 ; `kParamDensity`, `kParamDensityMode`), modes au clic droit : **Free** (Hz) · **BPM Sync** (+ options **Triplet**, **Dotted**) · **Grains** (cadence calculée pour qu'un nombre constant de grains, fixé par le bouton, joue en permanence) ; **Jump Start** (plusieurs grains dès l'attaque, pleine densité tout de suite ; désactivé = une seule génération puis montée progressive, attaque plus douce) ; **Max Grains** (plafond de grains simultanés, voix d'unison comprises ; au plafond, la génération attend qu'un grain finisse : garde-fou CPU) `[DOC p. 101]`.
- **LENGTH** (0–10 s ; `kParamGrainLength`, `kParamLengthMode`), clic droit : **Free** (s ou ms) · **BPM Sync** (+ Triplet, Dotted) · **Percent** (pourcentage de la période de densité ; **indisponible si DENS = Grains**) `[DOC p. 101–102]`. Grains courts = nets, rythmiques ; longs = tenues lisses `[DOC p. 101]`.
- **Fenêtre** (bouton ; **Option/Alt-glisser** le bouton règle amount et skew sans ouvrir le volet) `[DOC p. 91]` : **AMOUNT** (influence de la courbe) et **SKEW** (−100…+100 `[BIN]`), chacun avec sa randomisation par grain ; **SHAPE**, 10 formes `[DOC p. 91–93]` : **Hann** (cosinus, doux), **Welch** (parabolique, centré), **Gaussian** (cloche), **Blackman-Harris** (bords très atténués, moins de fuite spectrale), **Sinc** (queues oscillantes, plus riche), **Tukey** (plat au centre, bords adoucis), **Triangle**, **Trapezoid** (rampe, plateau, rampe), **ExpDec** (attaque franche, chute exponentielle : percussif), **Exp Dec Rev** (montée exponentielle : swell). Internes vus : `kWindowTukey`, `kWindowExpDec`, `kWindowTriangle`, `kWindowBlackmanHarris`, `kWindowGaussian`.
- **Randomisation par grain** (rangée du bas) : **OFFSET · DIR · PITCH** (0–12 st) **· RAND (LENGTH) · RAND (PAN) · RAND (LEVEL)** `[DOC p. 102]` ; clic droit sur DIR › **Reverse Grains** (bascule, automatisable et modulable : inverse tous les grains d'un coup) `[DOC p. 103]` ; Window amount/skew randomisés dans le volet fenêtre `[DOC p. 91]` ; Warp 1/2 randomisables (Rand Warp, Rand Warp 2, cibles d'axe Y `[DOC p. 97]`).
- **Unison** (volet) : MODE, STACK, DETUNE, BLEND, WIDTH, RANGE, START, SPAN, et **SPAWN PATTERN** (ex-« Unison trig pattern », `kParamUnisonTrigPattern`) : **Together** (défaut, toutes les voix d'unison génèrent leurs grains ensemble) · **Even** (réparties régulièrement) · **Exp** (écart croissant) · **Random**, dans la période avant la génération suivante `[DOC p. 94–95]`.
- **X|Y Control** (menu contextuel ; point rouge dans l'affichage) : paramètre de l'axe Y (`kParamYAxisAssignment` ; le volume vu en usine = Level) : None, Level, Warp, Warp 2, Density, Grain Length, Window Amt, Window Skew, Rand Offset, Rand Dir, Rand Pitch, Rand Length, Rand Pan, Rand Gain, Rand Window, Rand Skew, Rand Warp, Rand Warp 2 ; puis une entrée de menu choisit la façon de moduler l'axe Y (options non détaillées) `[DOC p. 96–98]`.
- **Warps** (§ 4) : bouton qui affiche ou masque le volet warp ; menu (OFF par défaut), flèches ‹ ›, bouton de profondeur ; renvoi à la liste générale p. 49 `[DOC p. 99]`.
- **Switch to Wavetable** (menu Granular) : comme § 3.3 `[DOC p. 103]`.

### 3.6 Moteur Spectral `[DOC]` `[EXTRAIT]` `[BIN]` `[USINE]`

Resynthèse additive en temps réel d'un sample : analyse du spectre, décomposition en partiels, traitement par blocs FFT `[DOC p. 104, 117]` ; « can be CPU intensive » `[DOC p. 104]`. Image **PNG** comme source (2048 × 256 recommandé) `[EXTRAIT]` : **non confirmé** ; le manuel 2.0.18 ne décrit l'import PNG que vers un osc **Wavetable** (PNG 8 bits, largeur en pixels = nombre de frames, 256 max) `[DOC p. 300]` `[TEST]`.

- **Chargement, start/end, opérations** : comme Sample (§ 3.3), sample partagé avec Sample et Granular `[DOC p. 104–106, 108]`. Affichage spectral : glisser haut/bas = zoom ; dézoom complet quand start et end sont tous deux visibles au survol `[DOC p. 106]` ; clic droit › **Show Waveform Display** = forme d'onde sous le spectre `[DOC p. 108]`.
- **FREQ LO / HI** (plage retenue, Hz) : marqueurs à droite du spectrogramme (Lo en bas, Hi en haut) ; clic droit dans le volet : **Smooth** (Butterworth d'ordre 4 aux bornes, bords adoucis ; `kParamLoHiIsSmooth`) et **Post Warp** (filtrage lo/hi appliqué **après** les warps spectraux) ; glisser une ENV ou un LFO sur un marqueur le module `[DOC p. 107, 115]`.
- **Menu de boucle** : la plupart des options du Sample, plus **Manual** (point X|Y, SCAN = position horizontale, pas de balayage, pas de slicing) `[DOC p. 109]` ; LS / LE et crossfade de boucle comme Sample `[DOC p. 110]`.
- **SCAN** : même menu qu'en Granular (Range ±200/400/800 %, Reverse, Key Track, Lock Scan Rate (to Tempo), Sample Length to BPM → RATE) `[DOC p. 116]` ; Sample Length to BPM cale une boucle de batterie sur le tempo de l'hôte, qu'on transpose alors au clavier sans changer le tempo `[DOC p. 117]`.
- **Phase Lock** : ajuste les phases FFT pour limiter les sauts audibles entre blocs, son moins « smeared », plus fidèle ; samples tonals. **Transients** : préserve les transitoires que la FFT étalerait (façon time-stretch avancé) ; percussions, boucles de batterie `[DOC p. 117]`.
- **Filtre spectral** `[DOC p. 117–121]` : **CUT** = coupure du filtre (probablement `kParamSpecFltShift` −100…+100 `[BIN]` `[HEUR]`) ; **FILTER** : clic = éditeur de masque **dessinable** en fenêtre (double-clic ajoute ou retire un point ; glisser un point ; glisser un point de courbe pour courber ; **Option/Alt-glisser** un point = aimanté à la grille, un point de courbe = toutes les courbes à la fois ; cliquer-glisser = sélection multiple ; champ **GRID** = nombre de divisions) ; **presets de filtre** d'usine (ex « types de série » ; bouton de l'éditeur), modifiables et sauvegardables, **Default** = courbe de départ ; clic droit sur FILTER › une **wavetable** comme filtre (vignette, **non éditable**), **Curve Filter** pour revenir à la courbe ; **MIX** = wet/dry (`kParamSpecFltWetDry`).
- **Unison** (volet) : MODE, STACK, DETUNE, BLEND, WIDTH, RANGE, SPAN, START, WARP 1 / WARP 2 `[DOC p. 111–113]`.
- **X|Y Control** (menu contextuel ; point rouge) : axe Y = None, Level, Warp, Warp 2, Spec Flt Cutoff, Spec Flt Wet/Dry, Freq Lo, Freq Hi, puis choix du mode de modulation `[DOC p. 114–115]`.
- **Warps** : menu (OFF par défaut), flèches ‹ ›, bouton de profondeur ; **warps spectraux** propres (§ 4.3) ; le manuel renvoie seulement à la liste générale p. 49 `[DOC p. 121]`.
- **Switch to Wavetable** (menu Spectral) : comme § 3.3 `[DOC p. 122]`.

### 3.7 SUB et NOISE `[DOC p. 123–132]` `[BIN]`

**SUB** (11, 101) : oscillateur sous les osc principaux, formes simples, fondation propre pour sub, basse, pad `[DOC p. 123]`. Activation : clic sur l'en-tête (nom + bouton), vert = actif `[DOC p. 124]`. Forme (icônes) **Sine · Rounded Rect · Triangle · Saw · Square · Pulse** `[DOC p. 125–126]` (`kParamShape`, `kRoundRect` pour Rounded Rect ; 6 entrées dans le binaire) : Sine = sub pur ; Rounded Rect = carrée aux fronts adoucis, entre sinus et carrée ; Triangle = un peu d'impaires, plus de grain qu'un sinus ; Saw = agressif, peut envahir le mix ; Square = impaires, percutant, parfois dur dans le grave ; Pulse = carrée asymétrique `[DOC p. 125–126]`. Hauteur par **OCT** et **CRS** (demi-tons continus, sans cran ; **coarse modulable**, nouveau Serum 2) `[DOC p. 124]`. **PHASE** (`kParamInitialPhase`), point de départ ; clic droit › **Contiguous** = la note reprend la phase de la précédente (phase continue, `kParamContiguousPhase`) `[DOC p. 127]`. **PAN**, **LEVEL** `[DOC p. 127]`. Routage et envois comme les autres `[DOC p. 31]` ; source des warps FM / PD / AM / RM (Sub) `[DOC p. 54–56]`. Un sinus SUB seul, MONO + LEGATO, release ≈ 90 ms : sub validé sur ce Mac (≈ −4 dB avant fader avec Utility à 0) `[LOCAL]`.

**NOISE** (896, 101) : lecteur de sample stéréo haute qualité (interpolation temps réel, SSE2 ; un fichier mono coûte moins de CPU, ne pas exporter un bruit mono en stéréo) `[DOC p. 128, 131]`. Activation : clic sur l'en-tête `[DOC p. 129]`. Menu de bruits (clic sur le nom, ‹ › pour défiler `[DOC p. 129]` ; 200+ ; dossiers `Noises/Analog`, `Organics`, `Attacks_Misc`, `S2 Noises`…). **Load Sample** (menu NOISE) ou glisser un WAV mono ou stéréo depuis le Finder sur l'affichage `[DOC p. 130]`. **Les bruits utilisateur ne sont pas embarqués par défaut** : menu NOISE › **Embed in Preset** les embarque `[DOC p. 130]`. **Bruits de couleur** (catégorie à part du menu) White · Pink (−3 dB/oct) · Brown (−6 dB/oct) · Geiger (clics aléatoires) (`kParamNoiseType`) `[DOC p. 129–130]` : ils font apparaître **STEREO** (0 = mono, 100 = gauche et droite décorrélées) et **FILTER** (passe-haut ou passe-bas) `[DOC p. 129]`. **COLOR** 0–1 (`kParamColor`) `[BIN]`, probablement ce FILTER `[HEUR]`. **PITCH** (50 % = hauteur d'origine du fichier, key track off `[DOC p. 132]` ; avec **Key track** le bouton passe en demi-tons), **FINE** (cents), **PAN**, **LEVEL** `[DOC p. 132]`. **START** (libellé affiché, interne `kParamInitialPhase`) : point de départ en %, glisser ou double-clic pour saisir, automatisable en « scratch » lo-fi `[DOC p. 131]`. **RAND** : départ aléatoire, pour que les notes d'un accord ne jouent pas le même bruit `[DOC p. 131]`. **One Shot / Looping** : boucle par défaut ; bouton one shot = s'arrête en fin de fichier, pour un transitoire d'attaque `[DOC p. 131]`. Modulateur : le NOISE peut moduler des paramètres (une boucle de batterie donne des résultats intéressants) et sert de source aux warps FM / PD / AM / RM des trois osc ; baisser alors son LEVEL `[DOC p. 128]`. **Import audio → wavetable** `[DOC p. 291–301]`

- Principe : Serum découpe le son en cycles uniques, la hauteur disparaît (un pitch bend est perdu) ; source monophonique, une note plutôt qu'un accord ; pour jouer le son tel quel, moteur Sample (§ 3.3) `[DOC p. 291]`.
- **Multi-cycle** : glisser le fichier (Finder, Explorateur ou navigateur de fichiers de l'hôte ; pas depuis la timeline dans la plupart des hôtes) sur l'affichage d'onde de l'oscillateur ; **stéréo : canal gauche dans OSC A et OSC C, canal droit dans OSC B** `[DOC p. 291]`. L'endroit où l'on lâche choisit la méthode `[DOC p. 292–294]` : DYNAMIC PITCH - ZERO SNAP (carte de hauteur + passages par zéro ; sons simples avec vibrato ou pitch bend) · DYNAMIC PITCH - FOLLOW (segment de taille variable selon la hauteur, sans passage par zéro ; sons complexes, chorus, bruit de fond) · FREQUENCY ESTIMATION (fondamentale + harmoniques ; leads, basses, voix tenues, plucks, FM) · **Constant framesize (PITCH AVERAGE)** (« If in doubt, try this one first! » ; son à hauteur fixe ; la taille de frame trouvée s'affiche dans le champ de formule) · FFT 256 / 512 / 1024 / 2048 (import spectral, « blurred averaging » ; boucles de batterie, voix ; plus grand = meilleure résolution fréquentielle) · **Switch OSC type** (charge en Sample, Granular ou Spectral, sans wavetable).
- **Taille de cycle imposée** : taper dans le champ de formule, avant l'import, un nombre de 1 à 4 chiffres (ex. 1024) ou un nom de note MIDI (B0, C#2… ; calcul supposant 44,1 kHz) `[DOC p. 294]` ; ou **fichier texte d'override** : `son.txt` à côté de `son.wav`, sinon `FolderInfo.txt` pour tout le dossier ; ligne 1 `[n]` = échantillons par cycle, **32 à 9999** ; ligne 2 facultative `[interp]` (défaut, crossfade) ou `[no interp]` `[DOC p. 295]`.
- Serum travaille en interne à **2048 échantillons par cycle**, taille idéale d'un son préparé pour l'import (aucun rééchantillonnage) ; taper 2048 affiche « split at: 2048 samples (22 Hz, note: F1 and -22 cents) » ; 256 cycles au plus, soit 11,6 s à 22 Hz ; variante plus simple : C grave à 44,1 kHz = 33 Hz, 1349 échantillons `[DOC p. 295, 298–299]`.
- Après import : X-Fade Edges (16 Samples) ou (Grid Size) contre le bourdonnement de bord, Remove: selected->end pour les frames vides de fin, écoute en balayant WT POS `[DOC p. 294, 300]`.
- **Single-cycle** : glisser un fichier sur une **vignette** = remplace cette frame seule ; glisser **plusieurs fichiers ensemble** sur l'affichage d'onde = nouvelle table faite de ces fichiers `[DOC p. 296–297]`.
- **Image** : glisser un **PNG 8 bits** (couleur ou niveaux de gris) sur un oscillateur wavetable ; **largeur en pixels = nombre de frames (256 au plus)** ; luminance → amplitude (0 = silence, 255 = maximum) ; résultat imprévisible, à retravailler (Normalize, X-Fade, Filter) puis à balayer par un LFO en rampe sur WT POS `[DOC p. 300–301]`. Le PNG du moteur Spectral est un autre usage (§ 3.6).

**Formula parser** `[DOC p. 304–311]`

- Champ « (enter formula) », Entrée pour calculer ; menu de presets : **Singles** (sans y ni z : remplace la frame courante) · **Multis** (avec y ou z : remplace toute la table) · **User Singles** · **User Multis** ; Save Formula range la formule dans User Singles ou User Multis selon son type `[DOC p. 307–308]`. Fichiers `FormulaUserSingles.txt` et `FormulaUserMultis.txt` dans `Serum 2 Presets/System/`, une ligne `[formule][nom]` par preset, supprimer = effacer la ligne ; exemples dans `FormulaFactorySingles.txt` / `FormulaFactoryMultis.txt`, à ne pas éditer (écrasés à la mise à jour) `[DOC p. 308–309]`.
- Fonctions à 1 argument : sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, asinh, acosh, atanh, log2, log10, log (base 10 selon le manuel), ln, exp, sqrt, sign, rint, abs ; à nombre variable d'arguments : min, max, sum, avg `[DOC p. 304–305]`.
- Opérateurs (priorité) : `&&` 1 · `||` 2 · `<=` `>=` `!=` `==` `>` `<` 4 · `+` `-` 5 · `*` `/` 6 · `^` 7 ; les exemples emploient aussi `?:` et `%` `[DOC p. 287, 305, 310]`.
- Variables `[DOC p. 306]` : `x` temps −1…1 · `w` temps 0…1 (= (x+1)/2) · `y` n° de frame 0…1 · `z` n° de frame −1…1 (= y·2−1) · `q` n° de bin 1…512, la formule écrit alors dans la **zone FFT** · `in` valeur actuelle de la frame calculée · `sel` valeur de la frame sélectionnée au départ (fixe) · `rand` −1…1, même valeur pour toutes les frames · constantes `pi`, `e`. **y ou z présent = toutes les frames de l'oscillateur régénérées.**
- Exemples `[DOC p. 309–311]` : `q<17` (16 premières harmoniques) · `q<z*256` (256 frames, une harmonique de plus par frame) · `(1/q)^0.25` (scie plus brillante, −3 dB/oct ; 0.5 = scie normale, 0.75 = plus sourde) · `(1/q)^z` (256 frames) · `((q%2)==1)?in:0` (garde les harmoniques impaires : une scie devient un carré ; preset **Proc:Squarify**).

## 4. Les modes de warp, liste complète

Chaque oscillateur principal a **deux** slots de warp (WARP 1, WARP 2), chacun avec un menu, un bouton de quantité et, selon le mode, un VAR `[DOC]`. Menu : OFF par défaut, clic sur le nom du mode affiché à côté du bouton, ‹ › pour passer au mode voisin sans ouvrir le menu, le bouton règle la profondeur ; en vue 2D, l'effet est visible pour Sync, Alt Warp et Distortion `[DOC p. 49]`. Catégories du tableau du manuel : **Off · Sync · Alt Warp · Filter · Distortion · FM · PD · AM · RM**, plus l'entrée **Swap Warps**, qui échange les modes de WARP 1 (gauche) et WARP 2 (droite) `[DOC p. 50–56]`. ### 4.2 Warps de modulation croisée, de filtrage et de distorsion `[DOC p. 52–56]` `[BIN]`

- **FM / AM / RM / PD** depuis **OSC** (l'autre osc principal), **OSC2** (le troisième), **SUB**, **NOISE**, **FILT1**, **FILT2** : `kFM_OSC`, `kFM_OSC2`, `kFM_SUB`, `kFM_NOISE`, `kFM_FILT1/2`, `kAM_*`, `kRM_*`, `kPD_*` ; **PD (Self)** (`kSelfPD`). Libellés affichés `[DOC p. 54–56]` : lettre de l'autre osc, ex. sur OSC A **FM (B)**, **FM (C)**, puis **FM (Noise)**, **FM (Sub)**, **FM (Filter 1)**, **FM (Filter 2)** ; même série pour **PD** (+ **PD (Self)**), **AM** et **RM**. La source doit être activée, son niveau peut être à zéro `[DOC p. 54–56]`. Dans Serum 1, un seul sens A→B ou B→A à la fois ; Serum 2 a trois oscillateurs et des filtres comme sources. PD = distorsion de phase (nouveau) : comme la FM, mais c'est la phase qui est modulée `[DOC p. 55]` ; AM = amplitude `[DOC p. 56]`.
- **Types de FM** listés dans la catégorie FM `[DOC p. 54–55]` : **Thru-Zero** (porteuse poussée sous 0 Hz : elle inverse sa phase et continue au lieu de s'arrêter ou de rebondir ; riche, métallique, cloches) · **Exp** (courbe exponentielle : petite variation du modulateur = grand écart de fréquence ; spectre plus large, plus brillant ou dur) · **Linear** (proportionnel, garde la hauteur même très modulé : cloches, pads, timbres stables ; « linear FM is thru-zero but with a clamp at zero », la FM classique qui ne traverse pas zéro). Le manuel ne dit pas comment un type se combine à une source. Variantes internes `kFMX_*` et `kFMP_*` observées dans les presets d'usine (FM « modulaire » selon la presse) : sans doute deux de ces trois types, `kFM_*` étant le troisième `[HEUR]` ; laquelle est laquelle : **MUET**, `[TEST]`.
- **Filter** au niveau de l'oscillateur : LPF, HPF (`kFilterLPF`, `kFilterHPF`), passe-bas, passe-haut `[DOC p. 52]`.
- **Distortion** par oscillateur `[DOC p. 52–54]` : Tube (`kDistTube`), Soft Clip, Hard Clip, Diode 1, Diode 2, Linear Fold, Sine Fold, Zero-Square, Asym, Rectify, Sine Shaper, Stomp Box, Tape Sat., Soft Sat. (`kDistSoftClip`, `kDistHardClip`, `kDistDiode1/2`, `kDistLinFold`, `kDistSinFold`, `kDistZeroSquare`, `kDistAsym`, `kDistRectify`, `kDistSineShaper`, `kDistStompBox`, `kDistTapeSat`, `kDistSoftSat`). Repères : Tube = lampe, chaud ; Soft Clip = compression douce ; Hard Clip = écrêtage net ; Diode 1 = écrêtage à diodes de pédale ; **Diode 2 = courbe sinusoïdale qui écrête de plus en plus dur avec le drive** ; Linear Fold = repli, métallique ; Sine Fold = repli sinusoïdal, plus rond ; Zero-Square = met à zéro sous un seuil, déforme au-dessus ; Asym = traite différemment les deux alternances ; Rectify = retourne ou supprime une alternance ; Sine Shaper = modelage par sinus, rond ; Stomp Box = pédale d'overdrive ; Tape Sat. = saturation de bande ; Soft Sat. = saturation légère.
- **Swap Warps** : échange les modes de WARP 1 et WARP 2 `[DOC p. 56]`.

Usage réel `[USINE]` sur 894 presets : PD OSC 138, Sync 118, FM OSC 81, PD SUB 72, Tube 55, FM SUB 53, Bend + 52, PWM 47 ; Remap 1–4 quasi inutilisés (1 chacun).

## 5. Page MIX : le mixer et le routage `[DOC]` `[BIN]`

Détail complet dans `serum2-fx-clip-arp.md` § A. L'essentiel :

- Canaux : SUB, OSC A, B, C, NOISE, FILTER 1, FILTER 2, BUS 1, BUS 2, plus les niveaux MAIN et DIRECT `[DOC p. 144, 151]` ; seuls les éléments actifs s'affichent (Init : OSC A seul) ; **cliquer l'en-tête active l'oscillateur ou le filtre dans tout Serum** `[DOC p. 145]`.
- Routage par défaut : **OSC A → FILTER 1** ; OSC B, OSC C, SUB, NOISE → MAIN `[DOC p. 145]` ; FILTER 1 et 2 → MAIN `[DOC p. 148]` ; BUS 1 et 2 → MAIN `[DOC p. 150]`.
- Glisser l'étiquette d'un canal osc sur une autre : sans modificateur = **échange** des deux osc, modulations comprises · Option/Alt = copie sans modulations · Shift-Option / Shift-Alt = copie avec modulations `[DOC p. 145]`.

### 7.4 Page MATRIX : les 64 slots `[DOC p. 209–214]` `[BIN]`

Chaque ligne, dans l'ordre des colonnes `[DOC p. 210–212]` : **SOURCE** · **CRV** (courbe de la source ; 50 % = linéaire, grise = bypassée ; double-clic ou clic droit › Editable Curve = éditeur de courbe, avec **RISE** et **FALL** = limiteur de pente sur la source) · **AMOUNT** −100…+100 (`kParamAmount` ; négatif = source inversée ; ⌘/Ctrl-clic = 0) · **POL** bipolaire / unipolaire (`kParamBipolar` ; réglage de la matrice, pas du LFO) · **DESTINATION** (module + paramètre) · **OUT** (graphe de la forme de sortie) · **AUX SOURCE** (seconde source multipliée avec la première, qui met la profondeur à l'échelle : même sens, inversée, ou bypass ; ex. LFO 1 × Mod Wheel = rien tant que la molette est à 0) · **INV** (aux inversée : pleine modulation molette à 0, aucune molette au maximum) · **CRV** de l'aux · **OUTPUT** (mise à l'échelle finale, `kParamOut` 0–100 %) · **Bypass** par ligne (flèche à droite, `kParamBypass`) · suppression de la ligne. Internes : courbes `kParamCurveIn/Out`, `kParamMainCurveData`, `kParamAuxCurve`, `kParamAuxInverted` ; **Smooth** rise/fall liés ou non (`kParamSmoothRise/Fall`, `kParamSmoothLink`) ; **Delay** avec sync (`kParamDelayOffset`, `kParamDelayBeatSync` ; non décrit par le manuel 2.0.18). Lignes réordonnables par poignées `[DOC p. 213]`, suppression en un clic, valeurs animées en temps réel, vue étendue (bouton ou Option/Alt-F `[DOC p. 212]`), **courbes de source et d'aux source éditables** `[DOC, What's New p. 15]`. Glisser une source sur un bouton crée la ligne ; l'arc autour du bouton règle la profondeur.

**Menu de la matrice** (bouton en haut à droite) `[DOC p. 214]` : Sort by Source · Sort by Destination · **Lock Matrix (Keep Assignments on Preset Change)** (garde les assignations au changement de preset et à l'Init) · **Create Vibrato (Unused LFO->Pitch via Wheel)** (le LFO libre suivant vers « Main Tuning », dosé par la Mod Wheel) · **Create Velo->Amp Assignment** · **Apply and Delete Macros** (§ 7.3).

**Profondeur depuis le bouton** `[DOC p. 195–196]` : halo bleu autour du bouton = profondeur de la source sélectionnée ; petit halo en haut à gauche avec flèche haut/bas à glisser ; raccourci Option/Alt-glisser le bouton lui-même ; halo gris = modulation d'une source non sélectionnée ; bleu clair = profondeur négative. Au dépôt, la polarité dépend du bouton : centré (DETUNE) → bidirectionnelle, sinon (RES) → unidirectionnelle ; Shift-Option/Alt-clic sur le bouton modulé la bascule sans ouvrir la matrice. Préférence **Limit Mod depth on drop** : au dépôt, la profondeur est réduite pour ne pas dépasser le maximum (LEVEL à 75 % → 25 %) `[DOC p. 314]`.

**Clic droit sur un contrôle** `[DOC p. 200–201]` : Mod Source › · Aux Source › · Edit Custom Curve · Bypass Modulator (halo gris) · Remove Modulator · Remove All Modulators · Reset Control (= ⌘/Ctrl-clic) · MIDI Learn (CC sauvé avec le preset) · Remove MIDI cc · Lock Parameter (verrou du paramètre ou du module au chargement des presets, en 2.0.18 ; grain fin retiré en 2.0.21–2.0.22, § 13).

**Les 59 sources, dans l'ordre du menu** `[BIN, table du binaire]` : Mod Wheel · Env 1–4 · LFO 1–10 · Velo · Note# · Aftertouch · Poly Aftertouch · Noise OSC (audio) · NoteOn Rand 1, Rand 2 · NoteOn Alt., Alt. 2 · Macro 1–8 · Pitch Bend · Expr X (Pan), Expr Y (Timbre), Expr Z (Press.) (MPE) · Release Velo · Fixed · LFO 1–10 **Y** (sortie Y des LFO Path) · OSC A, OSC B, OSC C, SUB OSC (audio-rate) · Filter 1, Filter 2 (audio-rate) · Active Voices · Voice Mod 1, Voice Mod 2 · Voice Index · NoteOn Rand (Discrete). Le manuel 2.0.18 annonce « 64 modulation matrix slots … with 49 different modulation sources » `[DOC p. 209]` : 59 moins les 10 sorties Y donne 49, le manuel ne compte probablement pas les sorties Y `[HEUR]`. Usage d'usine `[USINE]` : Macros et Mod Wheel dominent (≈ 1000 slots chacune), LFO 1 (901), Velo (697), Env 2 (567) ; Poly Aftertouch, Pitch Bend, Filter 1/2, Active Voices, Voice Mod : 0.

Définitions `[DOC p. 210–211]` (le manuel range ces sources parmi celles « only available to set using the modulation matrix », non glissables ; sa liste y mêle Oscillators et Filters, pourtant glissables par leur étiquette p. 208) : **Active Voices** = voix actives ÷ réglage POLY ; **Note-On Alt. 1/2** = bascule 0/1 à chaque note-on, Alt 2 = inverse d'Alt 1 ; **Note-on Rand 1 et 2** = deux aléas par note-on, même valeur pour toutes les destinations d'une source ; **Note-On Rand (Discrete)** = valeur différente pour chaque destination ; **Release Velocity** ; **Voice Index** = index courant du « Voice panel » (volet VOICE CONTROL, § 9) ÷ nombre de pas actifs ; **Voice Mod 1/2** = valeur du pas courant de Mod 1/2 dans ce panneau ; **Expression/MPE X/Y/Z** = Note Expression ou MPE ; **Oscillators** (y compris NOISE et SUB) et **Filters** = sortie audio ; **Aftertouch** = channel pressure ; Poly Aftertouch ; Pitch Bend ; Mod Wheel ; **Fixed** = valeur fixe dosée par la profondeur.

**Oscillateurs et filtres comme sources** : glisser l'étiquette du module (OSC A, FILTER 1…) sur un contrôle `[DOC p. 208]`.

**VELO et NOTE** `[DOC p. 201–205]` : onglets à **courbe dessinable** (défaut : diagonale) qui remappent vélocité et numéro de note avant de moduler ; gestes : double-clic = ajouter/enlever un point, glisser un point de courbe, Option/Alt-glisser un point de courbe = toutes les courbes ; glisser l'onglet VELO ou NOTE sur un bouton (ex. VELO → CUTOFF, NOTE → RES) ; clic droit sur l'onglet : **Legato (Portamento Time)** (la valeur glisse au temps de portamento quand une note arrive sur une note tenue) et **Init Graph**.

Destinations : « nearly every knob », y compris la plupart des paramètres d'effets (§ 8, avec la réserve « par voix ») et les macros. Si une destination manque dans le menu, cliquer le contrôle sur la page principale la fait apparaître `[DOC]`.

## 10. Clavier, OSC Mapping, CLIP, ARP `[DOC p. 219–273]` `[BIN]` `[USINE]` `[EXTRAIT]`

Le clavier du bas joue à la souris, montre les notes MIDI (clavier MIDI ou d'ordinateur), celles du clip player et de l'arpégiateur, et porte les réglages `[DOC p. 25, 267]` :

- **TRANSPOSE** : demi-tons, toutes notes entrantes et générées `[DOC p. 25, 268]`, **sur deux octaves** `[DOC, What's New p. 19]`, soit **−24…+24** `[DOC p. 267]` ; glisser, flèches (±1), molette au survol (±12).
- **KEY** et **SCALE** : appliqués, avec TRANSPOSE, **à l'entrée MIDI et à la sortie des modules CLIP et ARP** ; les notes hors gamme sont ramenées dans la gamme `[DOC p. 25, 220, 268]` ; `PitchQuantizer0` `[BIN]`. Liste des gammes « very thorough », donnée seulement en image : **MUET** en texte. Dans le piano roll : tonique surlignée, gamme sur fond gris, hors gamme sur gris plus sombre `[DOC p. 268]` ; servent à Conform to Scale et au Fold.
- **SWING** : global, OFF par défaut, champ de division qui apparaît dès qu'on quitte OFF (glisser, molette, flèches) ; plage selon l'hôte, Serum imite sa convention : **Live 12,5–87,5 %**, FL −150…+150 % `[DOC p. 269]` ; agit sur « the timing of the grid in the CLIP and ARP editors » `[DOC p. 25]` et sur les LFO en BPM (clic droit sur RATE › Swing) `[DOC p. 192]`. Divisions : **MUET**.
- **OSC MAPPING** : éditeur des **plages de notes et de vélocité des oscillateurs et de l'arpégiateur** (« define and limit the range to which both respond ») `[DOC, manuel web et What's New p. 19]` `[DOC p. 269]` ; bouton OSC MAPPING, ou clic droit sur l'en-tête d'un oscillateur › **Edit Note Ranges** ; sélecteur MAPPING en bas à gauche : **KEY** (notes) ou **VEL** (vélocités 1–127) ; glisser un bord = régler, glisser la plage = la déplacer, double-clic = saisir (notation du clavier) ; case **FOLD** : notes hors plage ignorées (décochée) ou repliées dans la plage (cochée : un sub reste dans une octave grave quelle que soit l'octave jouée) ; case **WARP** : l'oscillateur continue de servir de source de warp hors de sa plage (ex. OSC A en FM from B, B restreint) `[DOC p. 270–273]`. Usages : splits et couches, registres d'un instrument acoustique, timbre par registre `[DOC p. 271–272]` ; par exemple SUB + A dans le grave, B au médium, C au-dessus de C5 ; c'est `kParamKeyZoneMin/Max`, `kParamVelocityZoneMin/Max` par oscillateur `[BIN]`. Tag d'usine « KB-Span » (17 presets) `[USINE]` ; le manuel n'emploie « KB SPAN » que pour le réglage de clip (p. 234) : lien du tag avec OSC Mapping non établi.
- Trois modes d'affichage du clavier : KEYBOARD, **CLIP** (touches vertes, indicateur en bas à droite qui clignote au rythme des notes, absent si le clip est vide ; re-presser arrête, une autre touche lance l'autre clip) et **ARP** (touches violettes, re-presser relance) ; les slots sont disposés comme un clavier `[DOC p. 236, 264]`.

**Chaîne MIDI** : entrée MIDI → CLIP → ARP (s'il est actif) → moteur ; un clip qui joue alimente l'arp, l'arrêter arrête l'arp `[DOC p. 239, 264]`. Lancement par MIDI : **MIDI Input Trigger Octave** (menu de chaque module) = octave dont les notes lancent clips ou arps, ou Off ; **défaut : l'octave la plus basse de la plage MIDI** `[DOC p. 241, 266]`. Lancement aussi au clavier d'ordinateur `[DOC p. 235, 263]` ; Serum ne répond au clavier d'ordinateur que si la préférence GLOBAL « Keyboard shortcuts » est ON (l'éteindre l'empêche de voler le focus clavier du DAW) `[DOC p. 314]`.

Détail, procédures et citations : `serum2-fx-clip-arp.md` § D–E. Carte complète ci-dessous.

**CLIP** : 12 slots par banque (`MidiClip0..11`, `ClipPlayer0` `[BIN]`) `[DOC p. 224, 235]`.

- **Contenu** : clip MIDI interne qui joue le patch courant ; notes (hauteur, longueur, position, vélocité, expression) et données de contrôleur `[DOC p. 219, 233]` ; notes avec `expressionEvents` (MPE), automation `kAutoDest_*` (ex. `kAutoDest_ChanPressure`) `[BIN]`. Volets : GLOBAL · slots · CLIP SETTINGS · clé/gamme · piano roll · macros · MIDI OUT `[DOC p. 220]`.
- **GLOBAL** `[DOC p. 221–223]` : **BANK** (banques d'usine et utilisateur, dossier `Clip Banks` `[DOC p. 344]` ; Init ne réinitialise que les clips ; Save Clip Bank ; `*` = banque modifiée) · **TRIGGER MODE** MONO (un clip à la fois) / POLY (plusieurs ensemble) · **EDIT ALL** (ou Option/Alt pendant l'édition) : les réglages s'appliquent aux 12 clips.
- **Slots** `[DOC p. 233, 235–236]` : nommés 1 à 12 ; bouton play → stop ; clic droit : Rename Clip · Copy Clip (notes + réglages + nom ; **impossible d'une instance à une autre**) · Paste Clip · Erase Clip · **Set as Preview Clip** (sinon le navigateur joue le clip « fallback » choisi dans ses options `[DOC p. 335]`) ; champ CLIP : charger, sauver, renommer **un** clip ; clip muet alors qu'il a des notes : vérifier que la lecture des clips est activée.

Divisions de RATE, LAUNCH QUANT et tranches : **MUET**.
- **Piano roll** `[DOC p. 224–233]` : grille 1/16 par défaut (bouton à glisser, clic droit = menu) ; double-clic = ajouter (dernière note en orange) ou supprimer ; sélection au lasso, Shift pour ajouter ; glisser sur le fond sans note = **plage de temps** (notes coupées au bord ; coller une plage **écrase** la destination) ; bouton casque = entendre la note sélectionnée ; zoom (bouton, Shift-Option-glisser, marquee Shift-⌘-glisser, Option/⌘ + molette), défilement (⌘-Option-glisser, molette, Shift + molette) ; **Fold** (notes utilisées ; notes de la gamme si clé/gamme choisies ; ⌘-clic = gamme + notes utilisées, fond bleu dans la gamme, gris hors gamme) ; drapeaux de début et de fin (longueur) ; **marqueur de start offset** (point de départ au lancement, modulable), clic droit : **Wrap Clip to Begin Here** (ramène l'offset au début en déplaçant notes et automation ; ce qui précédait passe à la fin) · **Quantize** (quantifie le marqueur modulé et fixe le pas de KB SPAN Offset) ; `kParamRegionOffsetQuantize` `[BIN]`.
- **Raccourcis** `[DOC p. 226–227, 352–353]` : ↑↓ demi-ton · Shift ↑↓ octave · ←→ un pas de grille · Shift ←→ raccourcir / allonger · ⌘X / ⌘C / ⌘V · ⌘D Duplicate (à la fin de la sélection) · Backspace Delete · ⌘U Chop · ⌘K Conform to Scale · ⌘L Legato · 0 Mute (notes grises) · ⌘Q Quantize (sur la grille) · ⌘R Reverse · / et * Scale Time 50 % / 200 % (longueur du clip inchangée) · ⌘E Double Entire clip · Scale Entire clip 50 % / 200 % (menu seulement) · ⌘A Select All ; tout aussi au clic droit. **Conditions** : focus clavier sur la grille ou la lane d'automation (icône clavier en haut à droite) **et** préférence GLOBAL « Keyboard shortcuts » sur ON `[DOC p. 227]`.
- **Enregistrement** `[DOC p. 237–238]` : **OVERDUB** (boucle entre les marqueurs, ajoute à chaque passage) / **EXTEND** (allonge la timeline), commutables en cours ; métronome ; notes jouées en rouge, commit → vert, undo de la dernière prise non validée ; à l'arrêt tout est validé **mais le clip continue** : stop du slot. `kParamRecordMode` (`Extend`), `kParamMetronomeEnabled` `[BIN]`.
- **Macros** `[DOC p. 241–243]` : volet macros dans le module ; glisser le sélecteur de macro sur un contrôle (« + » = destination valide, toutes ne le sont pas) ; chiffre à côté de MACRO n = nombre de destinations, survol = liste (ex. « Clip 1 Rate ») ; on enregistre l'automation d'une macro dans un clip en tournant son bouton.

### 11.3 Formats de fichier `[BIN]` `[DOC p. 324–345]`

- **`.SerumPreset`** : en-tête `XferJson\0` + longueur + JSON (fileType, hash md5 du flux, presetName, presetAuthor, presetDescription, product `Serum2` ou `Serum2FX`, productVersion, tags, version 3.0–6.0) + taille + `2` + **flux zstd contenant une carte CBOR** de 175 clés (`Oscillator0`…, `plainParams` = `"default"` ou seulement les paramètres qui diffèrent du défaut, **valeurs en unités réelles** : secondes, Hz, dB, %). L'état VST3 est le même conteneur en deux parties (processor, edit controller, version 9.0).
- **Preset par défaut** : menu principal › **Save as Default Preset** écrit `Serum 2 Presets/Presets/User/default.SerumPreset` ; depuis Serum FX, `defaultFX.SerumPreset`, et Serum FX retombe sur `default.SerumPreset` s'il ne trouve pas le sien `[DOC p. 324]`.
- **`.fxp`** Serum 1 : 299 paramètres float normalisés 0–1 dans l'ordre VST + blocs (matrice, LFO, switches, ordre des FX) ; s'ouvre dans Serum 2 (mode S1), **jamais l'inverse**.
- **Wavetables** : WAV mono float32 avec chunk `clm` `<!>2048 01000000 wavetable (www.xferrecords.com)` (« special Serum-saved WAV files » `[DOC p. 345]`). Les formes de base (Sine, Triangle, Square…) vivent dans le plug-in, pas sur le disque.
- **Autres fichiers** `[DOC]` : `<pack-name>.SerumPack` (pack d'artiste) `[DOC p. 339]` ; `.XferShape` (forme de LFO, format LFOTool) `[DOC p. 345]` ; `.SerumMIDIMap` (carte MIDI CC ; `Default.SerumMIDIMap` chargée par défaut) `[DOC p. 315, 325]` ; `.tun` (accordage) `[DOC p. 320]` ; WAV du dossier Renders `[DOC p. 23]` ; `Serum2Prefs.json` (préférences, JSON en texte brut, chaque ligne finit par une virgule, recréé s'il manque : le supprimer rend les préférences d'usine) `[DOC p. 340]`.
- **Clés utiles de `Serum2Prefs.json`** `[DOC p. 340–343]` : `"Default Author"` (auteur des presets créés depuis l'Init) · `"Enable CCForRockers"` 0 (off) / 1 (CC MIDI) / 2 (notes MIDI) · `"CCForRocker Preset +"`, `"CCForRocker Preset -"` (preset suivant / précédent ; −1 = non assigné, sinon numéro de CC ou de note) · `"CCForRocker OSC A +"`, `"CCForRocker OSC A -"`, idem OSC B, OSC C et OSC N (bruit) ; un CC ≥ 64 déclenche, il faut repasser sous 64 avant le suivant.
- **Pas de compatibilité ascendante** : un preset ou un Set sauvé par une version plus récente se recharge en **Init silencieux** avant 2.0.19, avec message ensuite ; noter la version exacte dans la mémoire de projet.

## 12. Serum 2 vu depuis Ableton Live `[DOC]` `[LOCAL]` `[FORUM]`

Détail et procédure dans `serum2-automation-et-migration.md` ; l'essentiel :

- **Chargement** : `lom.py load "<piste>" "Serum 2"` (règle anti hot-swap, VST3 et AU coexistent → préciser) ; fenêtre par `ppal-select openPluginWindow: true`, sinon bouton « fenêtre » du device (≈ 29, 479 sur capture 1568 px de Live) `[LOCAL]`.
- **API Live** : `device.parameters` = `[Device On]` tant que rien n'est configuré, parce que Live ne peuple pas le panneau des plug-ins de plus de 64 paramètres. Les pages OSC, filtres, mixer, LFO, enveloppes, matrice sont exposées statiquement ; **les paramètres FX ne le sont qu'après clic droit → Automate** dans Serum (parfois bypass/unbypass du device). Le manuel 2.0.18 est muet sur ce point : son menu contextuel des contrôles (p. 200–201) ne liste pas « Automate », la source reste le staff Xfer sur le forum. Plafond 128 paramètres par instance (`-_PluginAutoPopulateThreshold=128` dans Options.txt, effet sur VST3 non confirmé).
- **Configure** : l'ordre choisi dans le panneau Configure est l'index API ; **« Save as Default Configuration »** rend cet index stable pour toutes les instances futures (fonction de Live, absente du manuel Serum ; à ne pas confondre avec **Save as Default Preset** du menu principal de Serum, qui fixe l'état de départ du plug-in, § 11.3). Pièges d'index documentés par le changelog (2.0.17, 2.0.18, 2.0.21).
- **Format** : VST3 de préférence (corrections d'abord côté VST3 ; AU a eu ses propres bugs : CC/aftertouch non transmis avant 2.0.19, crash 2.0.23). MPE : en VST3, MPE désactivé, Serum répond aux VST3 Note Expression des hôtes qui les gèrent ; le manuel cite Bitwig, Cubase et Nuendo, pas Live `[DOC p. 325]`.
- **Reproductibilité** : version exacte, S1 Compatibility, Quality verrouillé ou non, Disable Smoothing, fichiers embarqués, état des verrous (Quality, Tuning, Lock Matrix, Lock FX Bus). S'y ajoutent trois réglages documentés : préférence **Use Ultra quality when rendering** (rendu hors ligne en Ultra `[DOC p. 315]` ; un export de Live peut alors différer de la lecture en Draft ou High `[HEUR]`) ; **MTS-ESP actif par défaut** (un maître MTS-ESP présent dans le Set réaccorde Serum ; un .tun chargé prime) `[DOC p. 321]` ; **Load MIDI Map from Presets**, off par défaut : les CC appris dans un preset ne reviennent pas au chargement du preset, mais les assignations CC sont sauvées et rappelées avec la session du DAW `[DOC p. 27, 315]`.
- **Clavier de l'ordinateur** : préférence **Keyboard shortcuts** ; la désactiver empêche Serum de voler le focus clavier de Live `[DOC p. 314]` ; les raccourcis du piano roll exigent ON (§ 11.5).
- **Transport** : **Silence note + FX tails when host transport stops** coupe notes tenues et queues d'effets à l'arrêt de Live `[DOC p. 315]`.
- **Audio vers Live** : glisser l'**icône d'onde** (à gauche du logo) sur une piste audio = WAV de la dernière note ou du dernier accord, rejoué en silence à la même hauteur, vélocité et durée, et copié dans `Serum 2 Presets/Renders` ; ⌥/Alt-clic sur l'icône ouvre ce dossier `[DOC p. 22–23]`.
- **MIDI d'un clip ou de l'arp vers une autre piste** : MIDI OUT sur Clip Player ou On `[DOC p. 239]` ; la procédure du manuel est écrite pour Logic `[DOC p. 240]`, celle de Live est **MUET**.
- **Pilotage par clics** : § 2 ; un preset chargé suit la hauteur (clips KICK en C1 → transposer ou macro Pitch) `[LOCAL]`.
