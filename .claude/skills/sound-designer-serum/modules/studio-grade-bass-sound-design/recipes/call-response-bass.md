# Call-Response / Multi-Bass

## Intention
Une phrase A appelle une phrase B, typique de bass music/Bass House.

## Architecture [HEUR]
- SUB commun qui suit la ligne globale, OU sub inclus dans chaque patch mais jamais superposé.
- Bass A : rôle principal, spectre ou mouvement 1.
- Bass B : réponse avec contour/spectre différent.
- Option C : fill seulement en fin de 4/8 mesures.

## Technique
Utiliser macros communes `Tone/Motion/Bite` pour que les patches restent contrôlables. Resampler A/B si automations complexes.

## Processing
Ne pas mettre la même distortion/FX sur toutes les réponses. Un bus commun léger peut donner cohésion ; conserver contrastes.

## Test
Écouter uniquement le rythme des envelopes/volumes : si le call-response ne groove pas sans effets, retravailler le MIDI [TEST].
