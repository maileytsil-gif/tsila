# Clean Sine Sub

## But
Fondamentale stable sous une bassline ou un growl.

## Serum 2 [HEUR]
- SUB ou OSC simple sine ; 1 voix ; unison 0.
- ENV amp : A 0–5 ms ; sustain adapté à la note ; R 20–80 ms.
- Glide : 20–100 ms seulement si notes legato voulues.
- Route Direct si les FX du patch doivent épargner le sub [DOC].
- Macro Weight = niveau sub dans plage limitée.

## Ableton [HEUR]
Operator sine ou Wavetable Sub Tone 0%. Utility Bass Mono si nécessaire [DOC].

## Processing
1. R-Bass ou MaxxBass **optionnel** pour traduction petits HP.
2. Pro-C 3/Ableton Compressor pour ducking kick.
3. Pro-Q 4 seulement si correction réellement nécessaire.

## Tests
Kick+bass, mono, note la plus basse, petit haut-parleur.
