# Matrice de rôle des plugins

| Besoin | Premier choix | Alternatives | À éviter |
|---|---|---|---|
| sub pur | Serum 2 / Operator / Wavetable | Massive X | multiband FX inutile |
| harmonics small-speaker | Waves R-Bass / MaxxBass | saturation légère Saturn/Neutron | booster massivement 30–50 Hz |
| saturation ciblée | Saturn 2 | Neutron Exciter, Roar, Trash | saturer le sub sans A/B |
| growl / destruction | Serum 2 + Trash/Roar | Saturn 2 | chaîne de 4 distortions non contrôlées |
| ducking kick | Pro-C 3 / Ableton Compressor | Glue | release copié sans écouter |
| résonance variable | Pro-Q 4 spectral/dynamic | Neutron EQ | notch fixe trop profond |
| attaque pluck/donk | Smack Attack / Transient Master | Neutron Transient Shaper | compresseur uniquement par habitude |
| poids/densité | Supercharger GT / Neutron Density | saturation douce | écraser le groove |
| phase/kick-bass | Neutron Phase + écoute/oscillo | Utility phase controls | correction automatique aveugle |
| width upper bass | chorus/unison/delay upper only | ValhallaDelay | stéréo sur sub fondamental |
| tail/space | ValhallaDelay/Supermassive/Room | Ableton Echo/Reverb | reverb full-range non duckée |

## Règle

Avant d'ajouter un plugin, écrire : `PROBLÈME → OUTIL → PARAMÈTRE PRINCIPAL → TEST A/B`. Si le problème n'est pas défini, ne pas insérer le plugin.
