## Ableton Live 12 [DOC]
- Instrument Reference : Operator, Wavetable, Meld, Analog, etc.  
  https://www.ableton.com/en/manual/live-instrument-reference/
- Audio Effect Reference : Compressor/Glue, Saturator, Roar, Utility, etc.  
  https://www.ableton.com/en/manual/live-audio-effect-reference/

Points importants : Operator = quatre oscillateurs + FM + enveloppes individuelles + pitch envelope. Wavetable = sub oscillator dont Tone=0% produit une sine ; Utility dispose d'un Bass Mono réglable ; Saturator propose notamment Bass Shaper et contrôle `Amt Lo`; Roar propose jusqu'à trois étages de saturation et plusieurs routages.

## Règle d'utilisation

Les valeurs de cutoff, ADSR, sidechain, distorsion ou largeur proposées dans les recettes sont **[HEUR]** sauf si une valeur est explicitement présentée comme plage d'un contrôle constructeur. Le résultat doit toujours être validé dans le vrai Set **[TEST]**.
