# Format de réponse obligatoire

## 1. Cible
`Style / BPM / tonalité / rôle / pattern`

## 2. Ownership
`Kick owns sub / Bass owns sub / Alternating / Kick+rumble`

## 3. Architecture
- SUB
- BODY
- ATTACK
- MOTION
- AIR/SPACE

## 4. Moteur
Serum 2 ou Ableton + raison.

## 5. Patch
Oscillateurs/sources, pitch, envelopes, filters, LFO/modulation, voicing, glide.

## 6. Macros
4–8 macros avec plages sûres.

## 7. Processing
Chaque ligne = `plugin → raison → réglage de départ [HEUR] → test`.

## 8. Kick integration
Sidechain, timing, phase, registre.

## 9. Validation [TEST]
Au moins 4 tests, dont mono et kick+bass.

## 10. Variante
Une variation plus clean ou plus agressive, sans dupliquer le patch entier.
