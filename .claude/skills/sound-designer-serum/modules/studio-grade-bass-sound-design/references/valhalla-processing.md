# Valhalla DSP — espace et mouvement des basses

## Principe
Valhalla traite de préférence la **couche upper/body** ou un **send**, pas le vrai sub [HEUR].

## ValhallaDelay [DOC]
- delay sync/ms ;
- modulation ;
- modes avec pitch shifting / reverse pitch ;
- EQ low/high ;
- certains modes proposent ducking.

Usages [HEUR] :
- slap très court sur upper bass ;
- ghost/pitch texture ;
- call-response généré puis resamplé ;
- délai ducké derrière la note sèche.

## Supermassive [DOC]
Delay, Warp, Feedback, Density, modulation, High/Low Cut. Peut aller d'échos à longues reverbs.

Usages [HEUR] : techno tail, transition, drone upper-bass, FX de fin de phrase. Toujours filtrer et ducking si le retour empiète sur kick/sub.

## Room / VintageVerb
Utiliser pour profondeur et texture sur layer filtré. Éviter une queue large sous le registre où le mix doit rester mono/solide [HEUR].
