# Ableton Live 12 — Bass Design

## Operator [DOC]
Operator combine quatre oscillateurs, FM, synthèse soustractive/additive, filtre, LFO, enveloppes d'oscillateurs et pitch envelope.

Usages [HEUR] :
- sine sub ;
- FM metallic/donk ;
- bass pluck très précise ;
- basses techno percussives.

## Wavetable [DOC]
Wavetable possède deux oscillateurs principaux + un Sub. `Tone=0%` sur le Sub produit une sine pure ; augmenter Tone ajoute des harmoniques. Les filtres permettent LP/HP/BP/notch/morph.

Usage [HEUR] : garder le Sub propre et faire vivre les oscillateurs principaux.

## Meld [DOC]
Deux moteurs indépendants, chacun avec filtre/enveloppes/LFO/matrice. Idéal pour BODY + texture ou deux comportements complémentaires.

## Saturator [DOC]
Waveshaping avec plusieurs courbes, dont Bass Shaper. `Amt Lo` ajuste le degré de saturation des basses fréquences. Les filtres Color peuvent préaccentuer avant shaping et compenser après.

Usage [HEUR] : saturer les harmoniques utiles sans écraser systématiquement la fondamentale.

## Roar [DOC]
Jusqu'à trois étages de saturation, filtres, feedback, compression et routages série/parallèle/Mid-Side/Feedback/Delay. Peut recevoir sidechain audio/MIDI.

Usage [HEUR] : pour BODY/MOTION agressif, resampling, feedback tonal, upper-bass stéréo. Éviter les routages feedback extrêmes sur le sub direct sans contrôle.

## Utility [DOC]
`Bass Mono` convertit les fréquences sous une fréquence réglable en mono. Le contrôle va de 50 à 500 Hz.

Usage [HEUR] : choisir le seuil d'après le son et non « toujours 120 Hz ».

## Sidechain [DOC]
Compressor/Glue peuvent être déclenchés par une source externe. Ableton présente explicitement le ducking kick→bass comme usage dance.
