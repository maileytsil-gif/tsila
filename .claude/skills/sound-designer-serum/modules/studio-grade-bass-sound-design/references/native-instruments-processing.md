# Native Instruments — bass design

## Massive X [DOC]
Synthé semi-modulaire : deux oscillateurs wavetable, noise, filtres, inserts, PM Aux bus et effets stéréo. Le routage permet wavetable, phase modulation, feedback/cross-modulation et waveshaping. Les trois `Performers` sont des séquenceurs de modulation pour mouvements rythmiques complexes.

Usage [HEUR] : alternative à Serum 2 lorsque la modularité/Performers/PM donne un avantage précis. Ne pas doubler Serum et Massive X sans rôle distinct.

## Transient Master [DOC]
Attack et Sustain modifient le contour des transients plutôt qu'un seuil absolu de niveau.

Usage [HEUR] : bass pluck/donk, resample percussif, réduction d'une attaque trop dure.

## Supercharger GT [DOC]
Compression à caractère + saturation Mild/Moderate/Hot ; sidechain externe ; HP detector 100/300 Hz disponible.

Usage [HEUR] : body, glue, bass bus caractère. Vérifier que la compression ne suit pas uniquement le sub et n'étouffe pas les harmoniques ; le detector HP peut aider selon le signal [TEST].
