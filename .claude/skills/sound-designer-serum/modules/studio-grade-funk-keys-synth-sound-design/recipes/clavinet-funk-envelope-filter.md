# Clavinet funk avec envelope filter (« Higher Ground », « Superstition », « Use Me »)

## Cible
`COMPING rythmique en doubles-croches / Eb mineur penta ≈ 101 BPM pour « Superstition » / F2–C5 / possède le médium : la guitare rythmique joue d'autres doubles-croches`

## Faits [DOC-W, DOC secondaire, HEUR-extrait]
60 cordes F1–E6 frappées par un pad caoutchouc (hammer-on), **étouffées par un fil au relâchement**, deux pickups ; C = un pickup, D = les deux, A/B = lequel ou phase (étiquetage contradictoire) ; hors phase = fin et nasal ; chute de 3 st au relâchement ; « Higher Ground » **à travers un Mu-Tron III** (Gain, Peak, Range, Mode LP/BP/HP, Direction) ; « Superstition » : **plusieurs Clavinets**, deux pannés extrême G/D, phaser, wah, distorsions.

## Moteur
1. **Pack Clav** (Hohner D6 samplé) [DOC-EXTRAIT] — premier choix.
2. **Tension** [HEUR/TEST] : Exciter **Hammer** (ou Plectrum), Stiffness haut, Position 5–12 %, **Fix. Pos on** ; **Damper on, Gated on**, Mass et Velocity élevées, Position proche de 0 ; String Decay moyen, Inharm faible, Damping élevé (brillant) ; **Pickup on, Position 10–20 %** (brillant, « bridge ») ou 30–40 % (« neck ») ; **Body off** ; attention aux niveaux (« très facile de produire un son extrêmement fort » [DOC]).
3. DX7 **CLAV 1** dans Operator (`../references/dx7-fm-keys-bass.md`) ; NI Scarbee Clavinet ; hard sync (SS43).

## Chaîne
`Clav → Auto Filter (Band-pass 12 dB, circuit MS2 ou PRD, Frequency 400–700 Hz, Resonance 30–45 %, Envelope +60 à +80 %, Attack 5–8 ms, Release 120–180 ms, Drive léger) → Phaser-Flanger (Phaser, 4 notches, 0,5 Hz) → Pedal (Overdrive, Gain 20–30 %, Mid 1 kHz) ou Saturator → Compressor Peak 4:1 attaque 3–5 ms` [presets de recréation Mu-Tron : « Higher Ground » attaque 5 ms, release 120 ms ; « Classic Funk » 8 / 180 ms — HEUR]. Pas de reverb, ou room < 0,4 s.

## Jeu
Grille « lattice » (`../references/playing-voicings-midi.md`) : accents 110–118, pushes 90–100, ghosts 20–35, clics étouffés 15–30 à gate 15–25 % ; doublage : second clip complémentaire panné à l'opposé, autre filtre. Stabs coupés 150–250 Hz pour la basse.

## Tests [TEST]
Le filtre suit chaque note (attaque ≤ 10 ms) · aucune note tenue · deux Clavs : pas de flam involontaire · mono : un Clav reste lisible · guitare et Clav sur des doubles-croches différentes.
