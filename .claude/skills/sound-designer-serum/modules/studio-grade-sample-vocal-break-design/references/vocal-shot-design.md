# Vocal Shot Design for Breaks

## Rôles
- `ANCHOR` : élément mémorable du break.
- `PICKUP` : mot/syllabe juste avant une nouvelle phrase.
- `ANSWER` : réponse à un synthé ou à un autre vocal.
- `MOTIF` : 2–5 chops forment un motif répétable.
- `TENSION_MARKER` : shot répété/accéléré vers le build.
- `TEXTURE` : voyelle étirée, granulée, réverbérée.
- `PAYOFF_CUE` : dernier fragment qui annonce le drop.

## Pitch / formant
- Pitch = hauteur musicale.
- Formant = caractère/résonances perçues de la voix.

### [DOC] Waves Vocal Bender
Pitch + Formant sont séparés ; le plugin est monophonique, temps réel et offre LFO, séquenceur, amplitude et pitch modulators.

### [HEUR] Couples efficaces
- octave -12 + formant légèrement bas = support sombre ;
- octave +12 + formant ajusté = ear-candy haut ;
- pitch inchangé + formant déplacé = variation de personnage sans changer la note ;
- automation courte de pitch = pickup/throw.

## Break pattern [HEUR]
A : shot principal clair.
A' : même shot raccourci ou inversé.
B : réponse pitchée/formantée.
Silence.
A : retour du motif.
Pré-drop : dernier phonème + tail/reverse coupé avant le kick.

## Nettoyage
- clip gain avant compression ;
- de-ess uniquement si nécessaire ;
- HPF des FX returns ;
- préserver les consonnes si intelligibilité importante ;
- contrôler la stéréo des couches non principales.
