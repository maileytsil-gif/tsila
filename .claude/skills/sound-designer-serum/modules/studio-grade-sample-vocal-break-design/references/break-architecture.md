# Break Architecture: Sample & Vocal

## 5 étapes
1. **FOCUS** — introduire le shot/motif principal presque nu.
2. **SPACE** — ouvrir delay/reverb mais garder le centre lisible.
3. **MOTION** — ajouter reverse, filters, grain, stutter, pitch ou pan.
4. **LIFT** — augmenter registre, densité ou répétition vers le build.
5. **VACUUM** — retirer sub/queues avant le downbeat du drop.

## Longueur [HEUR]
- 4–8 mesures : break court club.
- 8–16 : break émotionnel/mainstream.
- plus long : seulement si le développement harmonique/vocal le justifie.

## Vocal shot dans le break
Le shot peut être traité différemment par sous-section :
- début : dry/near ;
- milieu : stereo delay + room/plate ;
- fin : chops accélérés, reverse, freeze ou granular tail ;
- avant drop : stop net ou delay throw contrôlé.

## Anti-clutter
Si le shot porte le hook, retirer les synthés qui occupent exactement son registre et son rythme. Ne pas résoudre un arrangement surchargé par un EQ chirurgical uniquement.
