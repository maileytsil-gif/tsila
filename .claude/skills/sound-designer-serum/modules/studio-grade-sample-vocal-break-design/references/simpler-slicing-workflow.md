# Simpler: One-Shot & Slicing Workflow

## [DOC] Modes
- Classic : instrument échantillonné mélodique/polyphonique avec ADSR et loop.
- One-Shot : lecture monophonique de hits ou phrases courtes.
- Slicing : découpe non destructive en slices jouables.

## [DOC] Slice By
Simpler peut découper par :
- Transient ;
- Beat ;
- Region ;
- Manual.
Le mode Transient peut générer jusqu'à 64 slices.

## Vocal chop [HEUR]
Pour une phrase de break :
1. Slicing → Transient ou Manual ;
2. garder 3–7 fragments vraiment distinctifs ;
3. mapper un motif rythmique simple ;
4. transposer uniquement les fragments porteurs de hauteur ;
5. laisser respirer certaines consonnes ;
6. créer une variation B avec reverse, octave ou espace plus long.

## Breakbeat [HEUR]
Transient slicing → conserver kick/snare/ghost hits → réarranger sans perdre l'ancrage métrique → resampler → appliquer traitement créatif sur la copie.
