# Recettes validées (deep chill minimal house, fa mineur, 120 BPM)

- **Sub** (Operator ou Serum) : sinus, mono/legato, glide 40–50 ms, attaque 4 ms, release 90 ms, volume −8 à −11 dB → Utility mono → EQ 24–130 Hz → sidechain kick (ratio 4, attaque 0,1–1 ms, release 110 ms). Notes F0 = 43,6 Hz.
- **Kick** : Serum « DR - Kick Minimal » (2 sinus, decay 294 ms, release 27 ms) ou Drum Rack sample ; EQ HP 28 Hz / LP 9 kHz → Saturator doux ; crête ≈ −3 dB avant fader.
- **Basse syncopée** : Wavetable/Serum saw+square filtrés LP 2–3,5 kHz (automation d'ouverture sur les drops), unisson léger, mono, notes F1 courtes sur les syncopes → Auto Filter → EQ 55 Hz–6 kHz → sidechain → Saturator « Warmth ».
- **Accords** : Electric (E-Piano) adouci ou Wavetable saw dual LP 2,5 kHz, decay 180–600 ms, voicings ouverts, Chorus léger.
- **Pad** : Wavetable 2 osc détunés, filtre LP 600–2 200 Hz automatisé, attaque 300 ms, release 1,2 s, largeur 100–160 %.
- **Hook / pluck** : Operator FM (ratio 2–3, index modulé par l'enveloppe), decay 250 ms, LP 6 kHz, delay ping-pong en envoi.
- **Texture** : bruit filtré (Wavetable noise ou Serum NOISE), LP 400 Hz → 5 kHz automatisé, largeur stéréo automatisée, −20 à −32 dB.
- **Cordes** : racks natifs « Ac Strings Orch », « Ac Strings Pizz Basic », « Childhood Home Piano » (piano feutré) chargés par `app.browser.sounds`.
Toujours mesurer la crête avant fader après remplacement et compenser sur l'instrument/Utility (faders souvent automatisés).
