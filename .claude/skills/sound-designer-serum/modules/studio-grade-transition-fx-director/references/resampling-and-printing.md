# Resampling & Printing

## Quand imprimer [HEUR]
- feedback proche de l'instabilité ;
- freeze/spectral/granular gesture difficile à reproduire ;
- automate 4+ paramètres interdépendants ;
- besoin de reverse/crop/warp précis ;
- besoin de garder une version stable avant le mix.

## Nommage
`TYPE_STYLE_BARS_BPM_KEY_VERSION`
Ex. `RISER_BASSHOUSE_4B_126_Fm_v03.wav`.

Conserver :
- dry source ;
- processed print ;
- note sur la chaîne ;
- headroom suffisant ;
- tails non tronquées sauf choix musical.
