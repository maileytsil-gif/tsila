# Pre-Drop Fill & Vacuum

## Ordre [HEUR]
1. Choisir le dernier événement mémorable : vocal, snare, bass fill, reverse, glitch ou silence.
2. Retirer les informations graves qui pourraient masquer le downbeat.
3. Décider si la reverb/delay doit **s'arrêter**, **être duckée**, ou **déborder volontairement**.
4. Réserver le premier transient du drop.

## Techniques
- hard mute sur la dernière fraction de mesure ;
- HP sweep + reduction du stereo low-end ;
- reverb throw juste avant vacuum ;
- stutter rate qui accélère puis s'arrête ;
- micro fill qui termine avant le kick.

La durée du vacuum dépend du groove `[TEST]`. Ne pas utiliser une valeur universelle.
