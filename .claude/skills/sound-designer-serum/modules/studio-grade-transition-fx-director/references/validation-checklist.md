# Validation Checklist

- [ ] La frontière A→B est plus claire avec la transition qu'en bypass.
- [ ] Le downbeat B conserve son transient principal.
- [ ] Aucun layer grave de transition ne concurrence kick/bass/rumble.
- [ ] Feedback et freeze ont un point de sortie défini.
- [ ] Les queues de reverb/delay sont coupées ou duckées intentionnellement.
- [ ] Le centre/mono reste stable.
- [ ] Les automations reviennent à l'état prévu.
- [ ] La transition fonctionne à volume égal ; ce n'est pas seulement un gain lift.
- [ ] En resampling, la version dry est conservée.
- [ ] Les effets tiers ont chacun une fonction nommée.
