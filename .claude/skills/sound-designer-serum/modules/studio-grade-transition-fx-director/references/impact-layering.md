# Impact Layering

Architecture `[HEUR]` :
- `TRANSIENT` : click/noise/hit très court ;
- `BODY` : punch 100–500 Hz selon contexte ;
- `SUB` : sine/boom court si le kick ne possède pas déjà cette fonction ;
- `TONAL` : note/intervalle si le passage exige une identité harmonique ;
- `TAIL` : reverb/delay/noise decay ;
- `DEBRIS` : petits éléments métalliques/granulaires.

## Priorité low-end
Le layer SUB doit respecter la décision de propriété du grave. Si le kick ou le rumble est déjà le protagoniste sous 80–100 Hz, réduire le sub impact avant d'utiliser une EQ corrective `[HEUR+TEST]`.

## Validation
Écouter l'impact avec et sans kick. S'il devient impressionnant seulement parce qu'il double le sub du kick, reconfigurer les couches.
